## 第 2-10 题：证明 rank[A B]=n 是可控性的必要非充分条件

### 题目

试证 $`\mathrm{rank}[A\ B]=n`$ 是时不变系统 $`(A,B,C)`$ 可控的必要条件，并举例说明它不是充分条件。

### 1. 必要性的证明

设系统可控。其可控性矩阵为

```math
\mathcal C=[B\ AB\ \cdots\ A^{n-1}B].
```

由 Kalman 判据，

```math
\mathrm{rank}\,\mathcal C=n.
```

另一方面，输入矩阵的各列属于 $`\mathrm{Im}[A\ B]`$。对于其余各块，由

```math
A^kB=A(A^{k-1}B),\qquad k\ge1,
```

可知其每一列都是系统矩阵各列的线性组合，故

```math
\mathrm{Im}(A^kB)\subseteq\mathrm{Im}\,A\subseteq\mathrm{Im}[A\ B].
```

于是

```math
\mathrm{Im}\,\mathcal C\subseteq\mathrm{Im}[A\ B].
```

比较维数得到

```math
n=\mathrm{rank}\,\mathcal C\le\mathrm{rank}[A\ B]\le n.
```

因此

```math
\boxed{\mathrm{rank}[A\ B]=n.}
```

必要性得证。

### 2. 另一种必要性证明：左零空间

若 $`\mathrm{rank}[A\ B]\lt n`$，则存在非零向量，使

```math
q^TA=0,\qquad q^TB=0.
```

对任意输入，状态组合满足

```math
\frac d{dt}(q^Tx)=q^TAx+q^TBu=0.
```

因此该组合恒定。取初态 $`x(t_0)=q`$，有 $`q^Tx(t_0)=q^Tq\gt0`$，不可能在有限时间将状态驱到零。因此系统不可控。取逆否命题，亦得必要性。

### 3. 反例说明不充分

取一阶系统

```math
A=[2],\qquad B=[0],\qquad C=[1].
```

显然

```math
\mathrm{rank}[A\ B]=\mathrm{rank}[2\ 0]=1=n.
```

但系统方程为

```math
\dot x=2x,
```

输入不起作用，其非零初态响应为

```math
x(t)=e^{2(t-t_0)}x(t_0),
```

不能在任何有限时刻变成零。等价地，一阶系统的可控性矩阵就是零矩阵，秩为零。因此系统不可控。

若希望反例中输入矩阵非零，也可取

```math
A=I_2,\qquad B=\begin{bmatrix}1\\0\end{bmatrix}.
```

此时拼接矩阵秩为 2，但

```math
[B\ AB]=\begin{bmatrix}1&1\\0&0\end{bmatrix}
```

的秩只有 1，同样不可控。

故该条件是必要条件，而不是充分条件。它相当于仅检查 PBH 判据在检验参数为零时的条件，不能替代全部特征值处的检查。

## 第 2-11 题：输出矩阵 C 与 CᵀC 的可观测性等价

### 题目

证明系统

```math
\dot x=Ax,\qquad y=Cx
```

可观测，当且仅当系统

```math
\dot x=Ax,\qquad\widetilde y=C^TCx
```

可观测。

### 1. 证明两个输出矩阵具有相同核空间

对任意向量，若 $`Cv=0`$，则显然有 $`C^TCv=0`$。

反之，若 $`C^TCv=0`$，则

```math
0=v^TC^TCv=(Cv)^T(Cv)=\|Cv\|^2.
```

范数平方为零意味着 $`Cv=0`$。因此

```math
\boxed{\ker(C^TC)=\ker C.}
```

这里不能用“约去转置矩阵”解释，因为它未必可逆；真正的理由是上述范数平方性质。

### 2. 比较两个系统的可观测性矩阵

令 $`Q=C^TC`$。两个系统的可观测性矩阵分别是

```math
\mathcal O_C=\begin{bmatrix}C\\CA\\\vdots\\CA^{n-1}\end{bmatrix},\qquad
\mathcal O_Q=\begin{bmatrix}Q\\QA\\\vdots\\QA^{n-1}\end{bmatrix}=\begin{bmatrix}C^TC\\C^TCA\\\vdots\\C^TCA^{n-1}\end{bmatrix}.
```

对任意向量和任意 $`k=0,\ldots,n-1`$，将第一步结论应用于向量 $`A^kv`$，得到

```math
QA^kv=0\iff C^TCA^kv=0\iff CA^kv=0.
```

因此

```math
\mathcal O_Qv=0\iff\mathcal O_Cv=0,
```

从而

```math
\ker\mathcal O_Q=\ker\mathcal O_C.
```

两个矩阵虽然行数可能不同，但列数都是 n。由秩—零度定理，

```math
\mathrm{rank}\,\mathcal O_Q=n-\dim\ker\mathcal O_Q=n-\dim\ker\mathcal O_C=\mathrm{rank}\,\mathcal O_C.
```

所以它们同时满列秩。由可观测性秩判据，

```math
\boxed{(A,C)\text{ 可观测}\iff(A,C^TC)\text{ 可观测}.}
```

证毕。

### 3. 从输出轨迹理解这一证明

任意初态产生的两种输出为

```math
y(t)=Ce^{A(t-t_0)}x_0,\qquad\widetilde y(t)=C^TCe^{A(t-t_0)}x_0.
```

第一步说明，任意时刻前一个输出为零当且仅当后一个为零。因此两系统具有完全相同的不可观测初态集合。

新输出满足 $`\widetilde y=C^Ty`$，虽然转置矩阵不一定可逆，但它在原输出实际所在的空间 $`\mathrm{Im}\,C`$ 上是单射：若 $`y=Cv`$ 且 $`C^Ty=0`$，则 $`\|y\|^2=0`$，故 $`y=0`$。

因此这个特殊输出变换不会丢失原输出的区分能力。并非任何输出左乘变换都保持可观测性。

### 4. 一个具体例子

取

```math
A=\begin{bmatrix}-1&0\\0&-2\end{bmatrix},\qquad C=\begin{bmatrix}1&1\end{bmatrix}.
```

原可观测性矩阵为

```math
\mathcal O_C=\begin{bmatrix}1&1\\-1&-2\end{bmatrix},\qquad\det\mathcal O_C=-1\ne0.
```

新的输出矩阵为

```math
Q=\begin{bmatrix}1&1\\1&1\end{bmatrix},
```

虽然它本身秩为 1，但

```math
\mathcal O_Q=\begin{bmatrix}1&1\\1&1\\-1&-2\\-1&-2\end{bmatrix}
```

仍有秩 2，因此新系统也可观测。新输出只是把原输出重复两次，并没有损失信息。

**适用范围：**本题按实矩阵证明。对于一般复矩阵，正确对应形式是 $`C^*C`$，其中星号为共轭转置。不能把复数情形的普通转置乘积当作范数平方。

## 第 2-20 题：对称传递函数矩阵的不可简约实现

### 题目与记号说明

设 $`(A,B,C)`$ 是对称传递函数矩阵 $`G(s)`$ 的不可简约实现，证明其转置对偶实现也是同一传递函数矩阵的不可简约实现，并存在唯一的非奇异对称矩阵，使

```math
PAP^{-1}=A^T,\qquad PB=C^T,\qquad CP^{-1}=B^T.
```

**原图记号说明：**按照三元组依次表示系统、输入、输出矩阵的标准约定，转置对偶实现应为

```math
\boxed{(A^T,C^T,B^T).}
```

图片第一行将后两项写成了另一顺序；这与矩阵尺寸以及题目随后给出的变换等式不一致。下面按这些等式要求的正确顺序证明。

设输入、输出维数均为 m，则

```math
A\in\mathbb R^{n\times n},\quad B\in\mathbb R^{n\times m},\quad C\in\mathbb R^{m\times n}.
```

对称的含义是 $`G(s)^T=G(s)`$。不可简约实现即最小实现，在有限维 LTI 情形等价于同时可控和可观测。

### 1. 转置对偶实现仍实现同一传递函数矩阵

原传递函数为

```math
G(s)=C(sI-A)^{-1}B.
```

取转置，利用逆矩阵转置公式：

```math
\begin{aligned}
G(s)^T&=B^T\bigl((sI-A)^{-1}\bigr)^TC^T\\ &=B^T(sI-A^T)^{-1}C^T.
\end{aligned}
```

由传递函数对称，

```math
G(s)=B^T(sI-A^T)^{-1}C^T.
```

所以 $`(A^T,C^T,B^T)`$ 确为同一传递函数的实现。

若模型还含直接项，则对称性同时要求直接项为对称矩阵，动态部分的下述论证不变；原题三元组不含直接项。

### 2. 转置对偶实现也不可简约

原实现不可简约，故

```math
\mathrm{rank}[B\ AB\ \cdots\ A^{n-1}B]=n,
```

```math
\mathrm{rank}\begin{bmatrix}C\\CA\\\vdots\\CA^{n-1}\end{bmatrix}=n.
```

对偶实现的可控性矩阵为

```math
[C^T\ A^TC^T\ \cdots\ (A^T)^{n-1}C^T]=\begin{bmatrix}C\\CA\\\vdots\\CA^{n-1}\end{bmatrix}^{T}.
```

其秩为 n，因此对偶实现可控。

对偶实现的可观测性矩阵为

```math
\begin{bmatrix}B^T\\B^TA^T\\\vdots\\B^T(A^T)^{n-1}\end{bmatrix}=[B\ AB\ \cdots\ A^{n-1}B]^T.
```

其秩也为 n，因此对偶实现可观测。故对偶实现同样不可简约。

### 3. 非奇异变换矩阵的存在性

使用最小实现的相似等价定理：同一传递函数的两个最小实现之间存在非奇异状态变换。

把原实现变换为上述对偶实现，就存在非奇异矩阵 P，使

```math
PAP^{-1}=A^T,\qquad PB=C^T,\qquad CP^{-1}=B^T.
```

等价地，

```math
PA=A^TP,\qquad PB=C^T,\qquad C=B^TP.
```

下面分别证明该矩阵唯一且对称，不将这两点混入存在性结论。

### 4. 唯一性

设两个矩阵 $`P_1,P_2`$ 都满足上述等式，令

```math
S=P_1-P_2.
```

则

```math
SA=A^TS,\qquad SB=0.
```

由归纳可知

```math
SA^kB=(A^T)^kSB=0,\qquad k=0,1,\ldots,n-1.
```

所以

```math
S[B\ AB\ \cdots\ A^{n-1}B]=0.
```

原系统可控，可控性矩阵的列张成整个状态空间，因此 S 对每个状态向量的作用都是零，故

```math
S=0,\qquad P_1=P_2.
```

唯一性得证。

### 5. 对称性

已知

```math
PA=A^TP,\qquad PB=C^T,\qquad C=B^TP.
```

对第一式取转置，整理得到

```math
P^TA=A^TP^T.
```

对第三式取转置，得到

```math
P^TB=C^T.
```

对第二式取转置，得到

```math
C=B^TP^T.
```

又因为 P 非奇异，其转置也非奇异。因此转置矩阵同样满足全部相似变换条件。由上一节的唯一性，必有

```math
\boxed{P^T=P.}
```

所以存在唯一的非奇异对称矩阵 P，使题目三个等式成立。证毕。

注意，非奇异对称不等于正定，本题并未要求或保证该矩阵正定。

### 6. 可选补充：不直接引用最小实现相似定理的存在性构造

由传递函数在无穷远处的展开及其对称性，对每个非负整数都有

```math
CA^kB=B^T(A^T)^kC^T.
```

原系统可控，任意向量可写成有限和

```math
x=\sum_{k=0}^{N}A^kBu_k.
```

定义映射

```math
Px=\sum_{k=0}^{N}(A^T)^kC^Tu_k.
```

先证明定义与表示方式无关。若左侧的状态和为零，记右侧和为 v，则对每个非负整数 l，

```math
\begin{aligned}
B^T(A^T)^lv&=\sum_{k=0}^{N}B^T(A^T)^{l+k}C^Tu_k\\ &=\sum_{k=0}^{N}CA^{l+k}Bu_k\\ &=CA^l\sum_{k=0}^{N}A^kBu_k\\ &=0.
\end{aligned}
```

对偶实现可观测，因此 v 必为零。故该线性映射定义良好。

对偶实现可控，向量 $`(A^T)^kC^Tu_k`$ 的有限和能够覆盖整个状态空间，因此 P 是满射。它是同维有限维空间间的线性映射，故非奇异。

由定义直接得到

```math
PB=C^T,\qquad PA=A^TP.
```

并且对任意状态的上述表示，

```math
B^TPx=\sum_{k=0}^{N}B^T(A^T)^kC^Tu_k=\sum_{k=0}^{N}CA^kBu_k=Cx.
```

因此 $`B^TP=C`$，三个要求的等式全部成立。这也完成了存在性的直接证明。

## 第 2-21 题：按可控性分解并求可控子系统

### 1. 题目及可控性矩阵

给定

```math
A=\begin{bmatrix}1&2&0\\0&1&0\\0&2&1\end{bmatrix},\qquad B=\begin{bmatrix}0\\1\\0\end{bmatrix},\qquad C=\begin{bmatrix}1&1&1\end{bmatrix}.
```

计算

```math
AB=\begin{bmatrix}2\\1\\2\end{bmatrix},\qquad A^2B=\begin{bmatrix}4\\1\\4\end{bmatrix}.
```

所以

```math
\mathcal C=[B\ AB\ A^2B]=\begin{bmatrix}0&2&4\\1&1&1\\0&2&4\end{bmatrix}.
```

第一行与第三行相同，秩不超过 2；前两列线性无关，故

```math
\mathrm{rank}\,\mathcal C=2\lt3.
```

系统不是完全可控的。取第二个基向量为 $`(AB-B)/2`$，可控子空间写成

```math
\mathscr R=\mathrm{span}\left\{\begin{bmatrix}0\\1\\0\end{bmatrix},\begin{bmatrix}1\\0\\1\end{bmatrix}\right\}.
```

### 2. 选基并构造非奇异变换

取

```math
q_1=\begin{bmatrix}0\\1\\0\end{bmatrix},\quad q_2=\begin{bmatrix}1\\0\\1\end{bmatrix},\quad q_3=\begin{bmatrix}1\\0\\-1\end{bmatrix}.
```

前两个向量构成可控子空间的基，第三个向量补成状态空间的基。令

```math
T=[q_1\ q_2\ q_3]=\begin{bmatrix}0&1&1\\1&0&0\\0&1&-1\end{bmatrix},\qquad\det T=2.
```

于是

```math
P=T^{-1}=\begin{bmatrix}0&1&0\\\frac12&0&\frac12\\\frac12&0&-\frac12\end{bmatrix}.
```

采用变换

```math
z=Px,\qquad z_1=x_2,\quad z_2=\frac{x_1+x_3}{2},\quad z_3=\frac{x_1-x_3}{2}.
```

### 3. 计算变换后的系统

由基向量关系

```math
Aq_1=q_1+2q_2,\qquad Aq_2=q_2,\qquad Aq_3=q_3,
```

可直接读出新系统矩阵的各列，得到

```math
\bar A=PAP^{-1}=\begin{bmatrix}1&0&0\\2&1&0\\0&0&1\end{bmatrix}.
```

同时

```math
\bar B=PB=\begin{bmatrix}1\\0\\0\end{bmatrix},\qquad\bar C=CP^{-1}=\begin{bmatrix}1&2&0\end{bmatrix}.
```

因此系统变为

```math
\begin{cases}\dot z_1=z_1+u,\\\dot z_2=2z_1+z_2,\\\dot z_3=z_3,\\y=z_1+2z_2.\end{cases}
```

第三个状态不受输入影响，前两个状态构成可控部分。本题恰好得到块对角结构；一般可控性分解只保证块三角结构。

### 4. 可控子系统及验证

令 $`z_c=(z_1,z_2)^T`$，可控子系统为

```math
\boxed{\dot z_c=\begin{bmatrix}1&0\\2&1\end{bmatrix}z_c+\begin{bmatrix}1\\0\end{bmatrix}u,\qquad y=\begin{bmatrix}1&2\end{bmatrix}z_c.}
```

其可控性矩阵为

```math
[B_c\ A_cB_c]=\begin{bmatrix}1&1\\0&2\end{bmatrix},\qquad\det[B_c\ A_cB_c]=2\ne0.
```

故该二维子系统完全可控。它与原系统具有相同传递函数：

```math
G(s)=\frac1{s-1}+\frac4{(s-1)^2}=\frac{s+3}{(s-1)^2}.
```

原方程中的差值满足 $`\frac d{dt}(x_1-x_3)=x_1-x_3`$，这也直接解释了第三个新坐标为什么不可控。

## 第 2-22 题：按可观测性分解并求可观测子系统

### 1. 题目及可观测性矩阵

给定

```math
A=\begin{bmatrix}2&0&0\\0&2&0\\0&3&1\end{bmatrix},\qquad B=\begin{bmatrix}0\\1\\1\end{bmatrix},\qquad C=\begin{bmatrix}1&1&1\end{bmatrix}.
```

计算

```math
CA=\begin{bmatrix}2&5&1\end{bmatrix},\qquad CA^2=\begin{bmatrix}4&13&1\end{bmatrix}.
```

于是

```math
\mathcal O=\begin{bmatrix}1&1&1\\2&5&1\\4&13&1\end{bmatrix}.
```

第三行等于三倍第二行减去两倍第一行，即

```math
CA^2=3CA-2C.
```

前两行独立，因此

```math
\mathrm{rank}\,\mathcal O=2\lt3.
```

系统不是完全可观测的。

### 2. 求不可观测子空间

解前两行对应的方程：

```math
v_1+v_2+v_3=0,\qquad2v_1+5v_2+v_3=0.
```

第二式减两倍第一式，得到 $`v_3=3v_2`$，进一步有 $`v_1=-4v_2`$。故

```math
\boxed{\mathscr N=\ker\mathcal O=\mathrm{span}\left\{\begin{bmatrix}-4\\1\\3\end{bmatrix}\right\}.}
```

该向量同时是特征值 2 的特征向量，并被输出矩阵映射为零，与不可观测模态的解释一致。

### 3. 选独立行构造变换矩阵

从可观测性矩阵取前两行，再补充 $`[1\ 0\ 0]`$，令

```math
P=\begin{bmatrix}1&1&1\\2&5&1\\1&0&0\end{bmatrix},\qquad\det P=-4.
```

其逆矩阵为

```math
P^{-1}=\begin{bmatrix}0&0&1\\-\frac14&\frac14&-\frac14\\\frac54&-\frac14&-\frac34\end{bmatrix}.
```

这里选独立行直接构造的是 P；上一题选列基构造的是逆变换矩阵。两种方法都采用相同的状态变换约定：

```math
z=Px,\quad z_1=x_1+x_2+x_3,\quad z_2=2x_1+5x_2+x_3,\quad z_3=x_1.
```

逆矩阵的第三列是不可观测基向量的非零倍数，说明第三个新坐标方向确实对应原空间中的不可观测方向。

### 4. 计算变换后的系统

由定义，

```math
\dot z_1=CAx+CBu=z_2+2u.
```

利用前面得到的行关系以及 $`CAB=6`$，有

```math
\dot z_2=CA^2x+CABu=-2z_1+3z_2+6u.
```

又有

```math
\dot z_3=2z_3.
```

因此

```math
\bar A=PAP^{-1}=\begin{bmatrix}0&1&0\\-2&3&0\\0&0&2\end{bmatrix},\quad\bar B=PB=\begin{bmatrix}2\\6\\0\end{bmatrix},\quad\bar C=CP^{-1}=\begin{bmatrix}1&0&0\end{bmatrix}.
```

输出只依赖第一个新状态；第三个新状态既不直接进入输出，也不影响前两个状态，所以属于不可观测部分。

### 5. 可观测子系统及验证

令 $`z_o=(z_1,z_2)^T`$，则

```math
\boxed{\dot z_o=\begin{bmatrix}0&1\\-2&3\end{bmatrix}z_o+\begin{bmatrix}2\\6\end{bmatrix}u,\qquad y=\begin{bmatrix}1&0\end{bmatrix}z_o.}
```

其可观测性矩阵为

```math
\begin{bmatrix}C_o\\C_oA_o\end{bmatrix}=\begin{bmatrix}1&0\\0&1\end{bmatrix},
```

满秩，因此该二维子系统完全可观测。

相应传递函数为

```math
G(s)=\frac{2s}{s^2-3s+2}=\frac{2s}{(s-1)(s-2)}.
```

不可观测部分的特征值是 2，但可观测部分仍有另一个特征值 2。因此不能说数值 2 在传递函数中完全消失；被隐藏的是不可观测状态对应的那部分内部动态。

## 第 2-23 题：子空间交集与标准四部分分解

### 题目

给定

```math
A=\begin{bmatrix}1&0&0&0\\0&2&0&0\\-6&-2&3&0\\-3&-2&0&4\end{bmatrix},\quad B=\begin{bmatrix}1\\0\\3\\2\end{bmatrix},\quad C=\begin{bmatrix}-4&-3&1&1\end{bmatrix}.
```

第一问要求求出可控子空间、不可观测子空间，以及它们和正交补之间的四个交空间，讨论能否从这些交空间的直和中取到整个状态空间的基。

第二问要求按定理 2-16 选取四个子空间并作标准结构分解。

本文记

```math
\mathscr R=\langle A\mid B\rangle,\qquad\mathscr N=\eta.
```

正交补均采用标准欧氏内积。

### 1. 计算可控子空间

依次计算

```math
AB=\begin{bmatrix}1\\0\\3\\5\end{bmatrix},\quad A^2B=\begin{bmatrix}1\\0\\3\\17\end{bmatrix},\quad A^3B=\begin{bmatrix}1\\0\\3\\65\end{bmatrix}.
```

因此

```math
\mathcal C=\begin{bmatrix}1&1&1&1\\0&0&0&0\\3&3&3&3\\2&5&17&65\end{bmatrix}.
```

前两列独立，且

```math
A^2B=5AB-4B,\qquad A^3B=21AB-20B.
```

故可控性矩阵秩为 2。

由

```math
e_4=\frac{AB-B}{3},\qquad v_1=B-e_4=\begin{bmatrix}1\\0\\3\\1\end{bmatrix},
```

得到较方便的一组基：

```math
\boxed{\mathscr R=\mathrm{span}\{v_1,e_4\}.}
```

其一般向量也可写为

```math
\mathscr R=\left\{\begin{bmatrix}r\\0\\3r\\s\end{bmatrix}:r,s\in\mathbb R\right\}.
```

### 2. 计算不可观测子空间

依次计算

```math
CA=\begin{bmatrix}-13&-10&3&4\end{bmatrix},
```

```math
CA^2=\begin{bmatrix}-43&-34&9&16\end{bmatrix},\qquad CA^3=\begin{bmatrix}-145&-118&27&64\end{bmatrix}.
```

所以

```math
\mathcal O=\begin{bmatrix}-4&-3&1&1\\-13&-10&3&4\\-43&-34&9&16\\-145&-118&27&64\end{bmatrix}.
```

前两行独立，并有

```math
CA^2=7CA-12C,\qquad CA^3=7CA^2-12CA.
```

故可观测性矩阵秩为 2。

求核空间只需解

```math
-4x_1-3x_2+x_3+x_4=0,
```

```math
-13x_1-10x_2+3x_3+4x_4=0.
```

第二式减三倍第一式得

```math
-x_1-x_2+x_4=0,
```

所以 $`x_4=x_1+x_2`$。代回第一式得 $`x_3=3x_1+2x_2`$。

令

```math
v_2=\begin{bmatrix}0\\1\\2\\1\end{bmatrix},
```

则

```math
\boxed{\mathscr N=\ker\mathcal O=\mathrm{span}\{v_1,v_2\}.}
```

其一般向量为

```math
\mathscr N=\left\{\begin{bmatrix}\alpha\\\beta\\3\alpha+2\beta\\\alpha+\beta\end{bmatrix}:\alpha,\beta\in\mathbb R\right\}.
```

### 3. 求两个正交补

向量属于可控子空间的正交补，当且仅当它同时与两个基向量正交：

```math
x^Tv_1=0,\qquad x^Te_4=0.
```

即

```math
x_1+3x_3+x_4=0,\qquad x_4=0.
```

因此

```math
\boxed{\mathscr R^\perp=\left\{\begin{bmatrix}-3\gamma\\\delta\\\gamma\\0\end{bmatrix}:\gamma,\delta\in\mathbb R\right\}=\mathrm{span}\left\{\begin{bmatrix}0\\1\\0\\0\end{bmatrix},\begin{bmatrix}-3\\0\\1\\0\end{bmatrix}\right\}.}
```

同理，向量属于不可观测空间的正交补，当且仅当

```math
x_1+3x_3+x_4=0,\qquad x_2+2x_3+x_4=0.
```

令 $`x_3=\gamma,x_4=\delta`$，得到

```math
\boxed{\mathscr N^\perp=\left\{\begin{bmatrix}-3\gamma-\delta\\-2\gamma-\delta\\\gamma\\\delta\end{bmatrix}:\gamma,\delta\in\mathbb R\right\}.}
```

一组基为

```math
\begin{bmatrix}-3\\-2\\1\\0\end{bmatrix},\qquad\begin{bmatrix}-1\\-1\\0\\1\end{bmatrix}.
```

### 4. 求四个交空间

#### 4.1 不可观测空间与可控空间的交

不可观测空间的一般向量为

```math
x=\begin{bmatrix}\alpha\\\beta\\3\alpha+2\beta\\\alpha+\beta\end{bmatrix}.
```

要同时属于可控空间，必须第二分量为零，即 $`\beta=0`$；其余条件随之满足。因此

```math
\boxed{\mathscr N\cap\mathscr R=\mathrm{span}\left\{\begin{bmatrix}1\\0\\3\\1\end{bmatrix}\right\}=\mathrm{span}\{v_1\}.}
```

该空间是一维。

#### 4.2 不可观测空间与可控空间正交补的交

对上述一般向量，属于可控空间正交补要求

```math
\alpha+\beta=0,\qquad\alpha+3(3\alpha+2\beta)=0.
```

由第一式 $`\beta=-\alpha`$，代入第二式得到

```math
4\alpha=0.
```

所以两个参数均为零，故

```math
\boxed{\mathscr N\cap\mathscr R^\perp=\{0\}.}
```

#### 4.3 不可观测空间正交补与可控空间的交

从可控空间取一般向量

```math
x=\begin{bmatrix}r\\0\\3r\\s\end{bmatrix}.
```

属于不可观测空间正交补要求

```math
10r+s=0,\qquad6r+s=0.
```

相减得到 $`4r=0`$，进而 $`s=0`$。因此

```math
\boxed{\mathscr N^\perp\cap\mathscr R=\{0\}.}
```

#### 4.4 两个正交补的交

属于可控空间正交补要求

```math
x_4=0,\qquad x_1=-3x_3.
```

再要求属于不可观测空间正交补，得到

```math
x_2=-2x_3.
```

故

```math
\boxed{\mathscr N^\perp\cap\mathscr R^\perp=\mathrm{span}\left\{\begin{bmatrix}-3\\-2\\1\\0\end{bmatrix}\right\}.}
```

该空间是一维。

### 5. 能否在这四个交空间的直和中取到状态空间的一组基

四个交空间的维数依次为

```math
1,\quad0,\quad0,\quad1.
```

两个非零交空间相互正交，因为

```math
\begin{bmatrix}1&0&3&1\end{bmatrix}\begin{bmatrix}-3\\-2\\1\\0\end{bmatrix}=0.
```

所以四者之和确为直和，但其维数只有

```math
1+0+0+1=2\lt4.
```

因此答案是

```math
\boxed{\text{不能从这四个交空间的直和中取到整个四维状态空间的一组基。}}
```

两个子空间及各自正交补构成的四个交，并不必然覆盖全空间。故标准四部分分解不能机械地把这四个正交交集当作所需四部分。

### 6. 按定理 2-16 选择四个子空间

按课件的编号，先取

```math
X_2=\mathscr R\cap\mathscr N=\mathrm{span}\{v_1\}.
```

在可控空间中选择补空间，使 $`\mathscr R=X_1\oplus X_2`$。可取

```math
X_1=\mathrm{span}\{e_4\}.
```

在不可观测空间中选择补空间，使 $`\mathscr N=X_2\oplus X_4`$。可取

```math
X_4=\mathrm{span}\{v_2\}.
```

最后补足整个状态空间，选择

```math
X_3=\mathrm{span}\{e_3\}.
```

得到

```math
\boxed{X_1=\mathrm{span}\{e_4\},\quad X_2=\mathrm{span}\{v_1\},\quad X_3=\mathrm{span}\{e_3\},\quad X_4=\mathrm{span}\{v_2\}.}
```

这里选择的是直和补空间，不要求是正交补。例如本题 $`\mathscr N^\perp\cap\mathscr R=\{0\}`$，但所选的可控可观部分依然是一维，两者并不是同一个对象。

### 7. 构造并计算状态变换

按上述编号的顺序拼接基向量：

```math
T=[e_4\ v_1\ e_3\ v_2]=\begin{bmatrix}0&1&0&0\\0&0&0&1\\0&3&1&2\\1&1&0&1\end{bmatrix}.
```

其行列式为 1，因此这些向量确实构成四维空间的一组基。逆矩阵为

```math
P=T^{-1}=\begin{bmatrix}-1&-1&0&1\\1&0&0&0\\-3&-2&1&0\\0&1&0&0\end{bmatrix}.
```

于是新坐标为

```math
z=Px,\qquad\begin{cases}z_1=-x_1-x_2+x_4,\\z_2=x_1,\\z_3=-3x_1-2x_2+x_3,\\z_4=x_2.\end{cases}
```

计算基向量在系统矩阵作用下的结果：

```math
Ae_4=4e_4,\qquad Av_1=v_1,\qquad Ae_3=3e_3,\qquad Av_2=2v_2.
```

因此

```math
\bar A=PAP^{-1}=\begin{bmatrix}4&0&0&0\\0&1&0&0\\0&0&3&0\\0&0&0&2\end{bmatrix}.
```

又因为

```math
B=e_4+v_1,
```

所以

```math
\bar B=PB=\begin{bmatrix}1\\1\\0\\0\end{bmatrix}.
```

分别计算各基向量的输出：

```math
Ce_4=1,\qquad Cv_1=0,\qquad Ce_3=1,\qquad Cv_2=0.
```

得到

```math
\bar C=CP^{-1}=\begin{bmatrix}1&0&1&0\end{bmatrix}.
```

### 8. 写出标准结构分解

最终系统为

```math
\boxed{\begin{cases}\dot z_1=4z_1+u,\\\dot z_2=z_2+u,\\\dot z_3=3z_3,\\\dot z_4=2z_4,\\y=z_1+z_3.\end{cases}}
```

四部分的含义为：

| 新状态 | 所属子空间 | 可控性 | 可观测性 | 对应特征值 |
|---|---|---|---|---|
| 第一分量 | $`X_1`$ | 可控 | 可观测 | 4 |
| 第二分量 | $`X_2`$ | 可控 | 不可观测 | 1 |
| 第三分量 | $`X_3`$ | 不可控 | 可观测 | 3 |
| 第四分量 | $`X_4`$ | 不可控 | 不可观测 | 2 |

其中，输入同时作用于前两个状态；它们对应不同特征值，其二阶可控性矩阵行列式为 -3，故该二维部分完全可控。输出观测第一、第三状态，它们对应不同特征值，其二阶可观测性矩阵行列式为 -1，故该二维部分完全可观测。

本题选择的基恰好由特征向量构成，所以标准分解成为对角形式；一般的标准分解允许若干非零耦合块，不应要求所有系统都能得到这样的对角形式。

### 9. 可控可观测部分与传递函数

可控可观测部分是第一维：

```math
\dot z_1=4z_1+u,\qquad y_m=z_1.
```

零初态下第三、第四状态恒为零，第二个状态虽然由输入激励，但不进入输出。因此原系统的传递函数为

```math
\boxed{G(s)=\frac1{s-4}.}
```

最小实现维数也可由子空间维数算出：

```math
n_{\min}=\dim\mathscr R-\dim(\mathscr R\cap\mathscr N)=2-1=1.
```

非零初态时，第三个状态仍可能向输出贡献 $`e^{3(t-t_0)}z_3(t_0)`$，所以相同传递函数不表示所有初态响应都相同。
