# 第 2-2 题：可控性与任意状态转移——前置知识与详细解答

> 对应课程讲义：[线性系统可控性与可观测性：初学者讲义](../课程讲义/线性系统可控性与可观测性_初学者讲义.md)，重点阅读第 4 章的 4.1、4.2、4.4 节。
>
> 本文讨论有限维连续时间线性系统，输入不附加幅值约束。矩阵系数及输入满足保证方程解存在且唯一的通常条件，例如适当的连续性或分段连续性。
>
> 公式采用 GitHub 支持的 `math` 围栏代码块与受代码跨度保护的行内公式，以避免 Markdown 改写矩阵换行、括号和下标。

## 一、题目与证明目标

**题目（依原题整理）：**证明，当且仅当对于任何初始状态 $`x(t_0)`$ 和目标状态 $`x^1`$，存在有限时间 $`t_1\gt t_0`$ 和一个容许输入 $`u_{[t_0,t_1]}`$，能在 $`t_1`$ 时刻将状态 $`x(t_0)`$ 转移到 $`x(t_1)=x^1`$，线性动态方程在 $`t_0`$ 时刻可控。

考虑系统

```math
\dot x(t)=A(t)x(t)+B(t)u(t).
```

其中，状态 $`x(t)\in\mathbb R^n`$、输入 $`u(t)\in\mathbb R^p`$；矩阵 $`A(t)`$ 描述系统自身动态，$`B(t)`$ 描述输入作用于状态的方式。

课件对“系统在 $`t_0`$ 时刻可控”的定义是：

> 对任意初态 $`x_0=x(t_0)`$，都存在有限时刻 $`t_1\gt t_0`$ 和容许输入，使状态在终止时刻恰好等于零。

而题目中的性质是：

> 对任意初态 $`x_0`$ 和任意目标状态 $`x^1`$，都存在有限时刻及容许输入，使状态在终止时刻恰好等于目标状态。

注意，$`x^1`$ 是目标状态的记号，不是状态的第一分量，也不是导数。

我们要证明

```math
\boxed{\text{任意初态都能到零}\iff\text{任意初态都能到任意目标}.}
```

“任意初态到任意目标”看起来要求更高。两者之所以等价，关键在于**线性叠加性和状态转移矩阵的可逆性**。

## 二、前置知识 1：状态响应由两部分组成

### 2.1 先看一维方程

对标量系统

```math
\dot x=ax+bu,\qquad x(t_0)=x_0,
```

其解为

```math
x(t)=e^{a(t-t_0)}x_0+\int_{t_0}^{t}e^{a(t-\tau)}bu(\tau)\,d\tau.
```

第一项是初态自身演化的贡献，第二项是输入带来的贡献。

即使不施加输入，初态也可能随时间变化；输入是在自然演化结果的基础上，再增加一个可调节的部分。

### 2.2 多维时变系统的解

一般线性系统的解是

```math
\boxed{x(t)=\Phi(t,t_0)x_0+\int_{t_0}^{t}\Phi(t,\tau)B(\tau)u(\tau)\,d\tau.}
```

其中 $`\Phi(t,s)`$ 是状态转移矩阵。

- $`\Phi(t,t_0)x_0`$：零输入响应，由初始状态引起。
- 积分项：零状态响应，由控制输入引起。

在固定终止时刻 $`t_1`$，记

```math
F=\Phi(t_1,t_0),\qquad L(u)=\int_{t_0}^{t_1}\Phi(t_1,\tau)B(\tau)u(\tau)\,d\tau.
```

原来的状态响应公式就变成

```math
\boxed{x(t_1)=Fx_0+L(u).}
```

这里 $`L`$ 是一个线性映射：它把整段输入函数映射到输入在终点产生的状态变化量。它不是单个时刻的输入矩阵 $`B(t)`$。

若希望到达目标 $`x^1`$，就必须实现

```math
\boxed{L(u)=x^1-Fx_0.}
```

右边的意义是：**目标状态减去自然演化能够到达的状态，就是需要输入补上的差额。**

## 三、前置知识 2：状态转移矩阵为什么可逆

状态转移矩阵满足

```math
\Phi(t,s)\Phi(s,r)=\Phi(t,r),\qquad \Phi(t,t)=I.
```

因此

```math
\Phi(t_1,t_0)\Phi(t_0,t_1)=I,
```

即

```math
\boxed{\Phi(t_1,t_0)^{-1}=\Phi(t_0,t_1).}
```

直观上，没有输入时，给定初态能够唯一确定终态；给定终态，也能够沿同一动态方程反向唯一确定初态。这是方程解的数学关系，不是要求实际控制过程倒着运行。

对于 LTI 系统，有

```math
\Phi(t_1,t_0)=e^{A(t_1-t_0)},\qquad \Phi(t_0,t_1)=e^{-A(t_1-t_0)}.
```

即使 $`A`$ 本身不可逆，矩阵指数仍然可逆。不要把 $`A`$ 是否可逆与状态转移矩阵是否可逆混为一谈。

**本题为什么要用可逆性？**因为 $`F`$ 可逆，当辅助初态 $`z_0`$ 遍历整个状态空间时，向量 $`-Fz_0`$ 也能遍历整个状态空间。

如果输入能够抵消任意初态的自然响应，即能够产生所有的 $`-Fz_0`$，那么它实际上就能够产生任意终点变化量。这是整个证明的核心。

## 四、前置知识 3：线性叠加原理

假设两个轨迹分别满足

```math
\dot x_a=Ax_a+Bu_a,\qquad \dot x_b=Ax_b+Bu_b.
```

相加后得到

```math
\frac{d}{dt}(x_a+x_b)=A(x_a+x_b)+B(u_a+u_b).
```

因此，两条状态轨迹相加，对应的初态也相加，输入也相加。

更一般地，轨迹 $`\alpha x_a+\beta x_b`$ 对应初态

```math
\alpha x_a(t_0)+\beta x_b(t_0)
```

和输入

```math
\alpha u_a+\beta u_b.
```

特别地，在零初态下，把输入取反，输入产生的状态响应也会取反。

这一性质依赖系统线性，也依赖容许输入集合允许这些线性组合。若有幅值饱和、输入只能为正等约束，本文的结论不能不加检查地套用。

## 五、容易忽略的严谨性问题：统一终止时刻

可控性的定义允许不同初态对应不同终止时间。例如，初态 $`x_a`$ 可能在 $`T_a`$ 被驱到零，初态 $`x_b`$ 可能在 $`T_b`$ 被驱到零。

后续证明要使用固定的 $`F=\Phi(T,t_0)`$，所以需要先证明：**能够找到一个共同的有限终止时刻，使所有初态都可以在这一时刻被驱到零。**

### 5.1 只需考虑有限个基向量

取状态空间的一组标准基

```math
e_1,e_2,\ldots,e_n.
```

例如二维空间中

```math
e_1=\begin{bmatrix}1\\0\end{bmatrix},\qquad e_2=\begin{bmatrix}0\\1\end{bmatrix}.
```

系统在 $`t_0`$ 可控，因此对每个初态 $`e_i`$，存在容许输入 $`u_i`$，使它在有限时刻 $`T_i\gt t_0`$ 到零。

### 5.2 取所有终止时刻的最大值

令

```math
T=\max\{T_1,\ldots,T_n\}.
```

只有有限个基向量，所以 $`T`$ 仍然有限。

如果第 $`i`$ 条轨迹提前在 $`T_i`$ 到零，就将输入延拓为

```math
u_i(t)=0,\qquad T_i\lt t\le T.
```

零状态、零输入满足

```math
\dot x=A(t)0+B(t)0=0,
```

所以轨迹在到零后可以一直保持零。这样，每个基向量都能在共同终止时刻 $`T`$ 到零。

### 5.3 用叠加覆盖任意初态

任意初态都可以写成

```math
z_0=\sum_{i=1}^n a_i e_i.
```

选择输入

```math
u_z(t)=\sum_{i=1}^n a_i u_i(t).
```

由线性叠加，对应轨迹的终态满足

```math
z(T)=\sum_{i=1}^n a_i\,0=0.
```

由此得到

```math
\boxed{\text{存在共同有限时刻 }T\gt t_0\text{，使任意初态都能在 }T\text{ 到零}.}
```

这并不意味着一个固定输入能把所有初态都驱到零。共同的是终止时刻，输入仍随初态而变化。

另外，对于一般时变系统，这里只证明**存在一个共同的终止时刻**，没有证明任意正长度时间区间都可控。

## 六、正式证明：两个方向分别完成

为方便表达，记：

- 性质 A：任意初态都能在有限时间到零，即可控性。
- 性质 B：任意初态都能在有限时间到任意目标状态。

### 6.1 性质 B 推出性质 A

假设任意初态都能到任意目标。特别地，取

```math
x^1=0.
```

那么任意初态都能在有限时间内转移到零。按照定义，系统在 $`t_0`$ 时刻可控。

这一方向直接由定义成立。

### 6.2 性质 A 推出性质 B

#### 第一步：固定共同终止时刻

由第五节的结论，存在有限时刻 $`T\gt t_0`$，使任意初态都能在 $`T`$ 被驱到零。

在以下推导中，统一记

```math
F=\Phi(T,t_0),\qquad L(u)=\int_{t_0}^{T}\Phi(T,\tau)B(\tau)u(\tau)\,d\tau.
```

任意辅助初态 $`z_0`$ 都存在输入 $`u_z`$，使

```math
0=Fz_0+L(u_z).
```

所以

```math
\boxed{L(u_z)=-Fz_0.}
```

#### 第二步：明确需要输入产生的贡献

给定任意实际初态 $`x_0`$ 与目标 $`x^1`$，需要

```math
x^1=Fx_0+L(u),
```

即

```math
L(u)=x^1-Fx_0.
```

#### 第三步：构造辅助初态

我们已知输入能够产生形如 $`-Fz_0`$ 的贡献。因此希望选取 $`z_0`$，使

```math
-Fz_0=x^1-Fx_0.
```

利用 $`F`$ 可逆，解得

```math
\boxed{z_0=x_0-F^{-1}x^1=x_0-\Phi(t_0,T)x^1.}
```

辅助初态并不是凭空猜出来的，而是由“需要输入补上多少差额”反推得到的。

#### 第四步：把同一个输入施加到实际初态

可控性保证存在输入 $`u_z`$，把辅助初态 $`z_0`$ 在时刻 $`T`$ 送到零，所以

```math
L(u_z)=-Fz_0.
```

将同一个输入施加到实际初态 $`x_0`$，则

```math
\begin{aligned}
x(T)&=Fx_0+L(u_z)\\ &=Fx_0-Fz_0\\ &=F(x_0-z_0)\\ &=F\left[x_0-\left(x_0-F^{-1}x^1\right)\right]\\ &=FF^{-1}x^1\\ &=x^1.
\end{aligned}
```

所以任意初态都能在有限时间内转移到任意目标状态。两个方向均成立，命题得证。

## 七、怎样直观理解辅助初态

选取

```math
z_0=x_0-\Phi(t_0,T)x^1,
```

那么原初态与辅助初态之差为

```math
x_0-z_0=\Phi(t_0,T)x^1.
```

对两条轨迹施加相同输入，做差后输入项抵消：

```math
\frac d{dt}(x-z)=A(t)(x-z).
```

所以轨迹之差只做自然演化：

```math
x(T)-z(T)=\Phi(T,t_0)(x_0-z_0).
```

代入初态差得到

```math
x(T)-z(T)=\Phi(T,t_0)\Phi(t_0,T)x^1=x^1.
```

而我们选了使辅助轨迹满足 $`z(T)=0`$ 的输入，因此实际轨迹必然满足 $`x(T)=x^1`$。

直观地说，就是**找一条能被送到零的辅助轨迹，让它与实际轨迹的终点差恰好等于目标状态**。

## 八、完整数值例子

考虑积分器

```math
\dot x=u.
```

设

```math
t_0=0,\qquad T=2,\qquad x_0=3,\qquad x^1=7.
```

没有输入时，状态保持不变，所以 $`\Phi(T,0)=1`$。

### 8.1 构造辅助初态

```math
z_0=x_0-\Phi(0,T)x^1=3-7=-4.
```

### 8.2 将辅助初态送到零

选择常输入

```math
u(t)=2,\qquad 0\le t\le2.
```

从辅助初态出发，有

```math
z(2)=-4+\int_0^2 2\,dt=0.
```

### 8.3 对实际初态使用同一个输入

从初态 3 出发，施加同样的输入：

```math
x(2)=3+\int_0^2 2\,dt=7.
```

恰好达到目标。两条轨迹之间的差始终为 7，当辅助轨迹到零时，实际轨迹就到达 7。

## 九、另一种解法：Gram 矩阵给出显式输入

前面的证明只用系统解、可逆性和叠加性，适合看清命题的逻辑。若已学过可控性 Gram 判据，还可以直接构造一个可行输入。

固定第五节得到的共同终止时刻 $`T`$。定义终点可达 Gram 矩阵

```math
W_r=\int_{t_0}^{T}\Phi(T,\tau)B(\tau)B(\tau)^T\Phi(T,\tau)^T\,d\tau.
```

可控性保证该矩阵可逆。若课件给出的判据使用初点形式

```math
W_c=\int_{t_0}^{T}\Phi(t_0,\tau)B(\tau)B(\tau)^T\Phi(t_0,\tau)^T\,d\tau,
```

则二者满足

```math
W_r=\Phi(T,t_0)W_c\Phi(T,t_0)^T.
```

因为状态转移矩阵可逆，所以两者是否非奇异完全一致。

令

```math
d=x^1-\Phi(T,t_0)x_0.
```

选择

```math
\boxed{u(t)=B(t)^T\Phi(T,t)^TW_r^{-1}d.}
```

尺寸上，$`B(t)^T`$ 为 $`p\times n`$，后面的矩阵为 $`n\times n`$，$`d`$ 为 $`n\times1`$，因此结果确实是 $`p\times1`$ 的输入向量。

代入终点积分：

```math
\begin{aligned}
L(u)&=\int_{t_0}^{T}\Phi(T,t)B(t)u(t)\,dt\\ &=\left[\int_{t_0}^{T}\Phi(T,t)B(t)B(t)^T\Phi(T,t)^T\,dt\right]W_r^{-1}d\\ &=W_rW_r^{-1}d\\ &=d.
\end{aligned}
```

于是

```math
x(T)=\Phi(T,t_0)x_0+d=x^1.
```

两种解法的区别是：

- 辅助初态法：利用可控性证明所需输入存在，不必显式计算它。
- Gram 矩阵法：进一步写出一个可行输入，但需要计算状态转移矩阵和矩阵积分。

如果题目出现时尚未学过 Gram 判据，使用辅助初态法更直接，也能避免引用后面才证明的定理。

## 十、可直接用于作业的证明

**证明：**

若对任意初态 $`x_0`$ 和任意目标状态 $`x^1`$，都存在有限时间及容许输入使系统从 $`x_0`$ 转移到 $`x^1`$，则取 $`x^1=0`$，由定义即知系统在 $`t_0`$ 可控。

反之，设系统在 $`t_0`$ 可控。对状态空间的一组基 $`e_1,\ldots,e_n`$，分别选取将其驱到零的控制及有限终止时刻 $`T_1,\ldots,T_n`$。令

```math
T=\max_iT_i.
```

将各控制在到零后延拓为零，由线性叠加可知，任意初态均可在共同终止时刻 $`T`$ 被驱到零。

现任取初态 $`x_0`$ 和目标状态 $`x^1`$，定义辅助初态

```math
z_0=x_0-\Phi(t_0,T)x^1.
```

根据可控性，存在容许输入 $`u`$，使

```math
0=\Phi(T,t_0)z_0+\int_{t_0}^{T}\Phi(T,\tau)B(\tau)u(\tau)\,d\tau.
```

对原初态 $`x_0`$ 施加同一输入，则

```math
\begin{aligned}
x(T)&=\Phi(T,t_0)x_0+\int_{t_0}^{T}\Phi(T,\tau)B(\tau)u(\tau)\,d\tau\\ &=\Phi(T,t_0)(x_0-z_0)\\ &=\Phi(T,t_0)\Phi(t_0,T)x^1\\ &=x^1.
\end{aligned}
```

故任意初态都能在有限时间内转移到任意目标状态。命题得证。

## 十一、常见疑问与证明漏洞

### 11.1 能否只说“先到零，再从零到目标”？

不能直接这样证明。已知条件只保证能到零，而“零能到任意目标”正是需要推导的结论，不能先当作已知条件使用。

对于时变系统，还有另一个问题：将第一段控制结束时刻当作第二段的起始时刻，系统的可控性未必仍然成立。本题的证明始终保持同一个起始时刻，避免了这个问题。

### 11.2 能否一开始就任取终止时刻？

对一般时变系统不能。定义只保证存在某个适当的有限终止时刻。应先用有限维基向量和叠加性证明存在共同终止时刻。

对于完全可控的 LTI 系统，才可以进一步使用“任意正长度区间上都完全可控”的特殊结论。

### 11.3 辅助初态是否需要等于实际初态？

不需要。辅助初态只是证明中构造的数学对象，用于找到一段具有适当终点作用的输入。真正的系统仍从原初态出发，施加同一输入即可。

### 11.4 为什么没有出现输出矩阵？

本题研究的是完整状态能否被控制到指定值，属于状态可控性，只涉及 $`A(t),B(t)`$。是否能从输出观测状态是另一个问题。

### 11.5 这与“从过去的零状态到达当前状态”是同一概念吗？

不是同一个时间设定。课件的可达性定义以当前时刻为终点，使用过去的控制区间；本题从固定的 $`t_0`$ 出发，在未来区间中完成任意状态转移。

对于一般 LTV 系统，应明确区间，不能因为名称相近就直接交换这些性质。

### 11.6 最值得记住的两行公式

```math
x(T)=\Phi(T,t_0)x_0+L(u),
```

```math
z_0=x_0-\Phi(t_0,T)x^1.
```

第一行说明终态由自然响应与输入响应相加得到；第二行告诉我们如何把“到任意目标”的任务，转化为已知能完成的“把辅助初态送到零”的任务。
