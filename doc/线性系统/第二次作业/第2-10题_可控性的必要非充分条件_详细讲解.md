# 第 2-10 题：rank[A B]=n 为什么是可控性的必要条件而非充分条件

> 对应课程讲义：[线性系统可控性与可观测性：初学者讲义](../课程讲义/线性系统可控性与可观测性_初学者讲义.md)，重点参考第 1.3、5.1、5.2、5.4、8.1 节。
>
> 本题讨论有限维连续时间线性时不变系统。矩阵默认为实矩阵，输入不附加幅值约束。

## 一、题目与证明目标

**题目：**试证

```math
\mathrm{rank}[A\ B]=n
```

是时不变系统 $`(A,B,C)`$ 可控的必要条件，并举例说明它不是系统可控的充分条件。

设系统为

```math
\dot x=Ax+Bu,\qquad y=Cx,
```

其中

```math
A\in\mathbb R^{n\times n},\qquad B\in\mathbb R^{n\times p}.
```

这里 $`[A\ B]`$ 表示按列横向拼接，尺寸为 $`n\times(n+p)`$。它不是矩阵乘积，也不是可控性矩阵。

题目包含两个任务：

1. 证明系统完全可控时，该矩阵一定满行秩。
2. 找到满足该秩条件、却不完全可控的反例。

需要证明的逻辑关系是

```math
\boxed{\text{完全可控}\Longrightarrow\mathrm{rank}[A\ B]=n,}
```

但逆向推理一般不成立。

因此，该秩不足可以直接否定可控性；该秩等于状态维数，则还需要进一步判断。

## 二、前置知识

### 2.1 必要条件与充分条件

若性质 P 成立一定能推出性质 Q，就说 Q 是 P 的必要条件；也说 P 是 Q 的充分条件。

这里 P 是“系统完全可控”，Q 是“拼接矩阵满行秩”。我们要证明 P 推出 Q，并给出 Q 成立而 P 不成立的例子。

反例只需一个，但必须核实：它确实满足秩条件，同时确实不完全可控。

### 2.2 状态可控性不取决于输出矩阵

虽然题目写出三元组 $`(A,B,C)`$，状态可控性却只由 $`(A,B)`$ 决定。更换传感器不会改变执行器能够影响哪些状态方向。

因此证明中不需要输出矩阵；反例中可任取尺寸合适的输出矩阵，例如单位矩阵。

### 2.3 Kalman 可控性判据

定义

```math
\mathcal C=[B\ AB\ A^2B\ \cdots\ A^{n-1}B].
```

则

```math
\boxed{\text{系统完全可控}\iff\mathrm{rank}\,\mathcal C=n.}
```

必须区分两个矩阵：

| 矩阵 | 含义 |
|---|---|
| $`[A\ B]`$ | 收集自然动态映射与直接输入映射的列方向 |
| $`\mathcal C`$ | 收集输入直接作用及经动态传播后的可控方向 |

题目条件比 Kalman 判据弱。自然动态能够映射到某个方向，不表示输入能够独立操纵这个方向。

### 2.4 像空间与秩

矩阵的像空间就是列向量张成的空间：

```math
\mathrm{Im}\,M=\{Mv:v\text{ 为尺寸合适的向量}\}.
```

它的维数等于矩阵的秩。若一个矩阵的列空间包含于另一个矩阵的列空间，前者的秩就不超过后者。

乘积矩阵的每一列都属于左侧矩阵的像空间，因此

```math
\mathrm{Im}(AB)\subseteq\mathrm{Im}\,A.
```

对于所有正整数幂，同样有

```math
\mathrm{Im}(A^kB)\subseteq\mathrm{Im}\,A,\qquad k\ge1.
```

### 2.5 不满行秩与左零空间

如果一个有 n 行的矩阵不满行秩，就存在非零行向量从左侧将它乘成零。因此

```math
\mathrm{rank}[A\ B]\lt n
```

等价于存在 $`q\ne0`$，使

```math
q^T[A\ B]=0,
```

即

```math
q^TA=0,\qquad q^TB=0.
```

这意味着某个状态组合既不受自然动态改变，也不受输入改变。

## 三、证明方法一：比较列空间

### 3.1 可控性矩阵的全部列都落在拼接矩阵的像空间中

第一块输入矩阵的列显然满足

```math
\mathrm{Im}\,B\subseteq\mathrm{Im}[A\ B].
```

对其余各块，注意

```math
A^kB=A(A^{k-1}B),\qquad k\ge1.
```

所以

```math
\mathrm{Im}(A^kB)\subseteq\mathrm{Im}\,A\subseteq\mathrm{Im}[A\ B].
```

于是整个可控性矩阵的列空间满足

```math
\mathrm{Im}\,\mathcal C\subseteq\mathrm{Im}[A\ B].
```

因此

```math
\boxed{\mathrm{rank}\,\mathcal C\le\mathrm{rank}[A\ B]\le n.}
```

### 3.2 使用完全可控的假设

若系统完全可控，由 Kalman 判据有

```math
\mathrm{rank}\,\mathcal C=n.
```

代入不等式得

```math
n\le\mathrm{rank}[A\ B]\le n.
```

故

```math
\boxed{\mathrm{rank}[A\ B]=n.}
```

必要性得证。

## 四、证明方法二：找到无法改变的状态组合

这是一种直接使用可控性定义的证明，更能说明秩不足的后果。

采用逆否命题，假设

```math
\mathrm{rank}[A\ B]\lt n.
```

则存在非零向量，使

```math
q^TA=0,\qquad q^TB=0.
```

定义标量状态组合

```math
z(t)=q^Tx(t).
```

求导得

```math
\begin{aligned}
\dot z(t)&=q^T\dot x(t)\\ &=q^TAx(t)+q^TBu(t)\\ &=0.
\end{aligned}
```

因此该量始终不变：

```math
z(t)=z(t_0),\qquad\forall t\ge t_0.
```

选择初态

```math
x(t_0)=q,
```

则

```math
z(t_0)=q^Tq\gt0.
```

如果存在输入能在有限时刻将状态驱到零，就应有

```math
x(t_1)=0\Longrightarrow z(t_1)=0,
```

与该量恒定且非零矛盾。因此系统不可控。

其逆否命题就是：系统可控时，拼接矩阵必定满行秩。

这个证明找到了一个输入永远无法消除的非零初始信息，解释了为什么所给条件是必要的。

## 五、反例：满行秩不保证可控

### 5.1 输入非零的二阶反例

取

```math
A=I_2=\begin{bmatrix}1&0\\0&1\end{bmatrix},\qquad B=\begin{bmatrix}1\\0\end{bmatrix},\qquad C=I_2.
```

先检查题目条件：

```math
[A\ B]=\begin{bmatrix}1&0&1\\0&1&0\end{bmatrix}.
```

前两列组成单位矩阵，所以

```math
\mathrm{rank}[A\ B]=2=n.
```

再检查可控性。由于 $`AB=B`$，有

```math
\mathcal C=[B\ AB]=\begin{bmatrix}1&1\\0&0\end{bmatrix},\qquad\mathrm{rank}\,\mathcal C=1\lt2.
```

所以系统不完全可控。

标量方程为

```math
\dot x_1=x_1+u,\qquad\dot x_2=x_2.
```

第二个状态不受输入影响，其非零初态响应

```math
x_2(t)=e^{t-t_0}x_2(t_0)
```

不可能在有限时间变为零。

因此这个例子确实满足题目秩条件，却不完全可控，证明该条件不充分。

### 5.2 最简的一阶反例

也可取

```math
A=[2],\qquad B=[0],\qquad C=[1].
```

则

```math
\mathrm{rank}[A\ B]=\mathrm{rank}[2\ 0]=1=n.
```

但系统没有有效输入，方程为

```math
\dot x=2x,
```

非零初态响应

```math
x(t)=e^{2(t-t_0)}x(t_0)
```

不能在有限时间到零，所以不可控。

这是有效且简短的反例。如果希望避免“没有输入作用太特殊”的直觉疑惑，可以使用上一节输入矩阵非零的例子。

## 六、为什么这个条件这么弱

如果系统矩阵本身可逆，便有

```math
\mathrm{rank}\,A=n,
```

从而不论输入矩阵是什么，都有

```math
\mathrm{rank}[A\ B]=n.
```

即使输入矩阵全为零，也满足该条件。

这是因为系统矩阵描述的是已有状态怎样自然演化，而不是输入能够产生哪些独立作用。自然动态映射的列空间满维，不代表输入可以操纵全部方向。

可控性必须从输入方向出发，检查动态传播所产生的方向，这就是 Kalman 矩阵以输入矩阵为起点的原因。

## 七、PBH 解释：只检查了一个检验点

PBH 判据要求

```math
\mathrm{rank}[\lambda I-A\ B]=n,\qquad\forall\lambda\in\mathbb C.
```

实际只需检查系统矩阵的各个特征值，因为其他位置的前半块已经可逆。

将检验参数取为零，得到

```math
\mathrm{rank}[-A\ B]=n.
```

前半块整体乘以负号不改变秩，所以这等价于题目条件。

因此题目条件只是完整 PBH 判据在一个特定位置的条件，不能替代全部特征值处的检查。它排除了零特征值处的不可控障碍，却可能漏掉其他特征值处的不可控模态。如果零本来就不是特征值，该条件自动成立。

在二阶反例中，真正的障碍出现在检验参数为 1 时：

```math
[I_2-A\ B]=\begin{bmatrix}0&0&1\\0&0&0\end{bmatrix},
```

秩只有 1，不能通过完整 PBH 检验。

## 八、常见错误

1. 把拼接矩阵误认为可控性矩阵。前者满秩只是必要条件。
2. 认为系统矩阵可逆就可以控制任意状态。输入能力与自然动态映射不是同一件事。
3. 反例只写参数，不同时验证所给秩条件与不可控性。
4. 把渐近趋零当成有限时间到零。没有输入的稳定系统也不因此可控。
5. 只检查 PBH 的一个点就宣布完全可控。

## 九、可以直接用于作业的证明

**证明：**令

```math
\mathcal C=[B\ AB\ \cdots\ A^{n-1}B].
```

输入矩阵的列属于 $`\mathrm{Im}[A\ B]`$；对每个正整数幂，由

```math
A^kB=A(A^{k-1}B)
```

可知其列属于系统矩阵的像空间，也属于上述拼接矩阵的像空间。因此

```math
\mathrm{rank}\,\mathcal C\le\mathrm{rank}[A\ B]\le n.
```

若系统可控，Kalman 判据给出 $`\mathrm{rank}\,\mathcal C=n`$，从而 $`\mathrm{rank}[A\ B]=n`$，必要性成立。

反之，取

```math
A=I_2,\qquad B=\begin{bmatrix}1\\0\end{bmatrix}.
```

有

```math
\mathrm{rank}[A\ B]=2,
```

但

```math
\mathrm{rank}[B\ AB]=\mathrm{rank}\begin{bmatrix}1&1\\0&0\end{bmatrix}=1\lt2.
```

故系统不完全可控，说明该秩条件不是可控性的充分条件。证毕。
