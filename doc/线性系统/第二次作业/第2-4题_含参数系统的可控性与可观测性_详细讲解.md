## 一、题目与结论

考虑线性系统

```math
\dot x=\begin{bmatrix}1&0&0\\0&a&1\\0&-1&a\end{bmatrix}x+\begin{bmatrix}b\\0\\1\end{bmatrix}u,\qquad y=\begin{bmatrix}1&c&0\end{bmatrix}x.
```

求保证系统可控、可观测的参数条件。

记

```math
A=\begin{bmatrix}1&0&0\\0&a&1\\0&-1&a\end{bmatrix},\quad B=\begin{bmatrix}b\\0\\1\end{bmatrix},\quad C=\begin{bmatrix}1&c&0\end{bmatrix}.
```

结论为：

| 所要求的性质 | 参数条件 |
|---|---|
| 完全可控 | 输入参数非零，即 $`b\ne0`$ |
| 完全可观测 | 输出参数非零，即 $`c\ne0`$ |
| 同时完全可控、完全可观测 | $`b\ne0`$ 且 $`c\ne0`$ |

对任意实数 $`a`$，上述结论成立；不需要限制 $`a`$ 的正负，也不需要排除 $`a=1`$。

最关键的计算结果是

```math
\det\mathcal C=-b\bigl[(a-1)^2+1\bigr],\qquad \det\mathcal O=c^2\bigl[(a-1)^2+1\bigr].
```

由于对实数参数始终有

```math
(a-1)^2+1\gt0,
```

所以两个行列式是否为零，分别只由输入参数和输出参数决定。

下面解释这些矩阵从哪里来，以及每一步怎样计算。

## 二、前置知识：先识别系统，再选择判据

### 2.1 参数未知不等于系统时变

本题的参数是未知常数，不是时间函数。对每一组固定参数，系统矩阵、输入矩阵和输出矩阵都不随时间变化，因此这是一个**线性时不变系统**。

这与第 2-3 题中含有时间变量、指数时间函数的系统不同。本题可以直接使用普通 Kalman 秩判据，不需要引入输入矩阵或输出矩阵的时间导数。

### 2.2 状态、输入和输出的维数

系统有三个状态、一个输入和一个输出：

```math
x=\begin{bmatrix}x_1\\x_2\\x_3\end{bmatrix}\in\mathbb R^3,\qquad u\in\mathbb R,\qquad y\in\mathbb R.
```

矩阵尺寸为

```math
A\in\mathbb R^{3\times3},\qquad B\in\mathbb R^{3\times1},\qquad C\in\mathbb R^{1\times3}.
```

输入只有一个，并不表示只能控制一个状态；输出只有一个，也不表示只能辨认一个状态。系统内部的动态耦合可以把输入作用、输出信息传播到多个状态方向。

### 2.3 可控性：输入能否操纵全部状态方向

系统完全可控，指任意初态都可以通过合适的容许输入在有限时间内被驱到零。对于连续时间 LTI 系统，也等价于能够完成任意初态到任意目标状态的转移。

可控性只取决于矩阵对 $`(A,B)`$，与输出矩阵无关。

对三阶系统，定义可控性矩阵

```math
\mathcal C=\begin{bmatrix}B&AB&A^2B\end{bmatrix}.
```

本题只有一个输入，因此该矩阵是三阶方阵，判据为

```math
\boxed{\text{系统完全可控}\iff\mathrm{rank}\,\mathcal C=3\iff\det\mathcal C\ne0.}
```

直观理解：输入直接作用于方向 $`B`$；系统动态进一步传播后形成 $`AB,A^2B`$ 等方向。如果这些方向能够张成整个三维状态空间，系统就完全可控。

### 2.4 可观测性：输出能否区分全部初态

系统完全可观测，指已知一段时间内的输入和输出，可以唯一确定初始状态。

在标准的已知输入问题中，可观测性只取决于矩阵对 $`(A,C)`$，与输入矩阵无关。因为已知输入造成的输出贡献可以剔除，所以可以通过零输入响应讨论。

三阶系统的可观测性矩阵为

```math
\mathcal O=\begin{bmatrix}C\\CA\\CA^2\end{bmatrix}.
```

本题只有一个输出，因此它同样是三阶方阵：

```math
\boxed{\text{系统完全可观测}\iff\mathrm{rank}\,\mathcal O=3\iff\det\mathcal O\ne0.}
```

在零输入下，输出及其导数满足

```math
y=Cx,\qquad \dot y=CAx,\qquad \ddot y=CA^2x.
```

所以它们提供了关于三个未知状态的三组线性关系。矩阵满秩，就意味着这些关系足以区分全部状态。

这是理论上的解释；有噪声的测量中通常使用状态估计方法，而不是直接进行高阶数值微分。

### 2.5 为什么只计算到平方项

根据 Cayley–Hamilton 定理，三阶矩阵的三次幂以及更高次幂都能由单位矩阵、一次幂和二次幂线性表示。

因此，如果 $`B,AB,A^2B`$ 已经无法覆盖全部状态方向，继续计算更高次幂也不会补出缺失的方向。可观测性也有对应结论。

### 2.6 本题会用到的行列式技巧

对一列加上另一列的若干倍，不改变行列式；对一行加上另一行的若干倍，也不改变行列式。

本题特别适合先作差，再沿第一行或第一列展开，这样比直接使用三阶行列式的六项展开更清楚。

## 三、先把系统写成标量方程

矩阵方程等价于

```math
\begin{cases}
\dot x_1=x_1+bu,\\ \dot x_2=ax_2+x_3,\\ \dot x_3=-x_2+ax_3+u,\\ y=x_1+cx_2.
\end{cases}
```

这个结构已经给出两条重要线索：

1. 第一个状态与后两个状态没有动态耦合，输入只能通过系数 $`b`$ 影响它。因此若该系数为零，第一个状态显然不可控。
2. 第一个状态直接出现在输出中。后两个状态的信息要通过 $`cx_2`$ 进入输出，因此若该系数为零，后两个状态都不会被输出反映。

不过，这些观察目前主要说明必要条件。即使系数非零，也还要证明不存在隐藏的方向重合或信息抵消。下面的秩计算给出完整的充分必要条件。

## 四、可控性的完整计算

### 4.1 第一步：计算 AB

输入矩阵为

```math
B=\begin{bmatrix}b\\0\\1\end{bmatrix}.
```

逐行相乘：

```math
AB=\begin{bmatrix}1&0&0\\0&a&1\\0&-1&a\end{bmatrix}\begin{bmatrix}b\\0\\1\end{bmatrix}=\begin{bmatrix}b\\1\\a\end{bmatrix}.
```

具体来说：第一项为 $`b`$；第二项来自第三个状态方向的耦合，为 1；第三项为 $`a`$。

### 4.2 第二步：计算平方项

不必先计算整个平方矩阵，直接再乘一次即可：

```math
A^2B=A(AB)=\begin{bmatrix}1&0&0\\0&a&1\\0&-1&a\end{bmatrix}\begin{bmatrix}b\\1\\a\end{bmatrix}=\begin{bmatrix}b\\2a\\a^2-1\end{bmatrix}.
```

第二项为 $`a\cdot1+1\cdot a=2a`$，第三项为 $`-1\cdot1+a\cdot a=a^2-1`$。

### 4.3 第三步：构造可控性矩阵

横向拼接三列：

```math
\mathcal C=\begin{bmatrix}B&AB&A^2B\end{bmatrix}=\begin{bmatrix}b&b&b\\0&1&2a\\1&a&a^2-1\end{bmatrix}.
```

### 4.4 第四步：计算行列式

用第二列减去第一列，第三列也减去第一列，行列式不变：

```math
\det\mathcal C=\det\begin{bmatrix}b&0&0\\0&1&2a\\1&a-1&a^2-2\end{bmatrix}.
```

沿第一行展开：

```math
\begin{aligned}
\det\mathcal C&=b\det\begin{bmatrix}1&2a\\a-1&a^2-2\end{bmatrix}\\ &=b\bigl[(a^2-2)-2a(a-1)\bigr]\\ &=b(-a^2+2a-2)\\ &=-b\bigl[(a-1)^2+1\bigr].
\end{aligned}
```

对实数参数，平方非负，所以

```math
(a-1)^2+1\ge1\gt0.
```

由此

```math
\det\mathcal C\ne0\iff b\ne0.
```

最终得到

```math
\boxed{\text{系统完全可控的充分必要条件是 }b\ne0.}
```

输出系数没有出现在这个条件中，这是合理的：更换传感器不会改变执行器能够影响哪些状态方向。

### 4.5 输入系数为零时，到底缺少哪个方向

若 $`b=0`$，第一个状态满足

```math
\dot x_1=x_1,\qquad x_1(t)=e^{t-t_0}x_1(t_0).
```

它完全不受输入影响。只要初始值非零，任何有限时刻都不可能恰好变成零。

这不仅说明“矩阵不满秩”，也明确找到了不可控状态方向：第一个坐标轴。

后两个状态的子系统仍然可控。记

```math
A_2=\begin{bmatrix}a&1\\-1&a\end{bmatrix},\qquad B_2=\begin{bmatrix}0\\1\end{bmatrix}.
```

则

```math
[B_2\ A_2B_2]=\begin{bmatrix}0&1\\1&a\end{bmatrix},\qquad \det[B_2\ A_2B_2]=-1.
```

所以，无论实数参数取何值，该二维子系统都可控。当 $`b=0`$ 时，整个系统的可控维数恰好为 2，而不是完全没有控制能力。

## 五、可观测性的完整计算

### 5.1 第一步：计算 CA

输出矩阵为

```math
C=\begin{bmatrix}1&c&0\end{bmatrix}.
```

相乘得到

```math
CA=\begin{bmatrix}1&c&0\end{bmatrix}\begin{bmatrix}1&0&0\\0&a&1\\0&-1&a\end{bmatrix}=\begin{bmatrix}1&ac&c\end{bmatrix}.
```

尤其注意最后一项是 $`c`$。虽然第三个状态没有直接出现在输出中，但它会通过第二个状态的动态影响输出变化率。

### 5.2 第二步：计算平方项

```math
CA^2=(CA)A=\begin{bmatrix}1&ac&c\end{bmatrix}\begin{bmatrix}1&0&0\\0&a&1\\0&-1&a\end{bmatrix}=\begin{bmatrix}1&(a^2-1)c&2ac\end{bmatrix}.
```

第二项为 $`ac\cdot a-c=(a^2-1)c`$，第三项为 $`ac+ac=2ac`$。

### 5.3 第三步：构造可观测性矩阵

纵向堆叠三行：

```math
\mathcal O=\begin{bmatrix}C\\CA\\CA^2\end{bmatrix}=\begin{bmatrix}1&c&0\\1&ac&c\\1&(a^2-1)c&2ac\end{bmatrix}.
```

### 5.4 第四步：计算行列式

用第二行减去第一行，第三行也减去第一行：

```math
\det\mathcal O=\det\begin{bmatrix}1&c&0\\0&(a-1)c&c\\0&(a^2-2)c&2ac\end{bmatrix}.
```

沿第一列展开：

```math
\begin{aligned}
\det\mathcal O&=\det\begin{bmatrix}(a-1)c&c\\(a^2-2)c&2ac\end{bmatrix}\\ &=2a(a-1)c^2-(a^2-2)c^2\\ &=(a^2-2a+2)c^2\\ &=c^2\bigl[(a-1)^2+1\bigr].
\end{aligned}
```

由于括号内对所有实数参数都严格为正，因此

```math
\det\mathcal O\ne0\iff c\ne0.
```

最终得到

```math
\boxed{\text{系统完全可观测的充分必要条件是 }c\ne0.}
```

输入系数没有出现在这个条件中，这是合理的：在输入已知的标准可观测性问题中，输入贡献可以剔除，状态信息是否可辨认由系统动态和输出通道决定。

### 5.5 输出系数为零时，哪些状态看不见

若 $`c=0`$，输出变成

```math
y=x_1.
```

第一个状态的动态不受后两个状态影响，因此后两个初始状态无论如何变化，都不会影响任何未来输出。

此时

```math
\mathcal O=\begin{bmatrix}1&0&0\\1&0&0\\1&0&0\end{bmatrix},\qquad \mathrm{rank}\,\mathcal O=1.
```

不可观测子空间为

```math
\mathscr N=\mathrm{span}\{e_2,e_3\}.
```

例如，零输入下，初态 $`(0,1,0)^T`$ 与零初态都产生恒为零的输出，所以仅靠输出不能区分它们。

### 5.6 输出系数非零时，为什么能间接观测第三个状态

虽然输出矩阵的第三项为零，但这只表示第三个状态没有直接出现在输出里，不能据此断言它不可观测。

零输入下，

```math
\dot y=x_1+acx_2+cx_3.
```

只要输出系数非零，第三个状态就会出现在输出变化率中。继续考虑二阶导数，还能提供另一条独立关系，从而与输出本身一起区分三个状态。

也可以只看后两个状态子系统。其输出矩阵是

```math
C_2=\begin{bmatrix}c&0\end{bmatrix}.
```

对应可观测性矩阵为

```math
\begin{bmatrix}C_2\\C_2A_2\end{bmatrix}=\begin{bmatrix}c&0\\ac&c\end{bmatrix},
```

行列式等于 $`c^2`$，所以系数非零时该二维子系统可观测。

不过，“各子系统分别可观测”在一般情况下并不自动保证把它们的输出相加后整个系统仍可观测，还要排除不同部分的信息重合。本题完整的三阶行列式已经完成了这一步。

## 六、合并条件与参数分类

两个判据分别得到

```math
\text{完全可控}\iff b\ne0,
```

```math
\text{完全可观测}\iff c\ne0.
```

因此，系统同时具有两种性质的条件是

```math
\boxed{a\in\mathbb R\text{ 任意},\qquad b\ne0,\qquad c\ne0.}
```

可以进一步列出所有情形：

| 输入系数 | 输出系数 | 可控性矩阵秩 | 可观测性矩阵秩 | 结论 |
|---|---|---|---|---|
| 非零 | 非零 | 3 | 3 | 完全可控、完全可观测 |
| 零 | 非零 | 2 | 3 | 不完全可控、完全可观测 |
| 非零 | 零 | 3 | 1 | 完全可控、不完全可观测 |
| 零 | 零 | 2 | 1 | 两种完全性都不满足 |

这些结论都适用于任意实数参数 $`a`$。

## 七、参数 a 为什么没有额外限制：模态解释

这是理解本题结构的关键补充。

系统矩阵具有分块形式

```math
A=\begin{bmatrix}1&0\\0&A_2\end{bmatrix},\qquad A_2=\begin{bmatrix}a&1\\-1&a\end{bmatrix}.
```

其特征多项式为

```math
\det(\lambda I-A)=(\lambda-1)\bigl[(\lambda-a)^2+1\bigr].
```

因此特征值是

```math
\lambda_1=1,\qquad\lambda_2=a+i,\qquad\lambda_3=a-i.
```

对实数参数，后两个特征值是一对共轭复数，永远不会与实特征值 1 相等。

这说明第一个状态的指数模式与后两个状态的振荡模式不同。输入参数非零时，第一个模态能受到输入作用；后两个模态本来就能被输入激励。输出参数非零时，后两个模态可以进入输出，第一个模态则始终直接可见。

行列式中的因子

```math
(a-1)^2+1
```

反映了这组动态之间不存在导致退化的模态重合。特别地，即使 $`a=1`$，后两个特征值仍是 $`1+i`$ 和 $`1-i`$，并不是 1。

### 7.1 可选的 PBH 核对：可控性

PBH 的特征向量形式指出，不可控意味着存在非零左特征向量行，使其与输入矩阵相乘为零。

对特征值 1，可取左特征向量

```math
w_1^T=\begin{bmatrix}1&0&0\end{bmatrix},\qquad w_1^TB=b.
```

因此，第一模态被输入接入的条件是输入系数非零。

对另外两个特征值，分别取左特征向量行

```math
w_+^T=\begin{bmatrix}0&1&-i\end{bmatrix},\qquad w_-^T=\begin{bmatrix}0&1&i\end{bmatrix}.
```

它们满足

```math
w_+^TA=(a+i)w_+^T,\qquad w_-^TA=(a-i)w_-^T,
```

并且

```math
w_+^TB=-i\ne0,\qquad w_-^TB=i\ne0.
```

对实数参数，三个特征值互不相同，每个左特征空间都是一维。上述检查因此覆盖了所有左特征向量方向，得到与 Kalman 判据一致的结论。

这里用转置上标表示给出的复数行向量，直接验证其左特征方程即可；不需要把它误认为某个未说明的实向量的转置。

### 7.2 可选的 PBH 核对：可观测性

不可观测意味着存在非零右特征向量，其经过输出矩阵后为零。

对应特征值 1 的右特征向量为

```math
v_1=\begin{bmatrix}1\\0\\0\end{bmatrix},\qquad Cv_1=1\ne0.
```

因此第一个模态始终可观测。

另外两个右特征向量可取

```math
v_+=\begin{bmatrix}0\\1\\i\end{bmatrix},\qquad v_-=\begin{bmatrix}0\\1\\-i\end{bmatrix}.
```

它们满足

```math
Av_+=(a+i)v_+,\qquad Av_-=(a-i)v_-,
```

而

```math
Cv_+=c,\qquad Cv_-=c.
```

因此这两个模态均可观测，当且仅当输出系数非零。

## 八、两个具体例子帮助理解

### 8.1 取 a=1、b=1、c=1

此时

```math
\mathcal C=\begin{bmatrix}1&1&1\\0&1&2\\1&1&0\end{bmatrix},\qquad\det\mathcal C=-1,
```

```math
\mathcal O=\begin{bmatrix}1&1&0\\1&1&1\\1&0&2\end{bmatrix},\qquad\det\mathcal O=1.
```

所以系统完全可控、完全可观测。这说明不应该额外排除 $`a=1`$。

### 8.2 输入系数为零、输出系数非零

例如取 $`a=0,b=0,c=1`$。第一个状态不能被输入改变，所以系统不完全可控；但输出仍然可以区分三个初态，所以系统完全可观测。

这展示了可控性与可观测性的独立性：能看到一个状态，不等于能控制它。

反过来，取 $`a=0,b=1,c=0`$，系统完全可控，但输出只看到第一个状态，后两个状态不可观测。能控制一个状态，也不等于传感器一定能看到它。

## 九、与传递函数、最小实现的联系（补充）

零初态下，第一部分的传递函数是

```math
\frac{b}{s-1}.
```

后两个状态构成的子系统满足

```math
(sI-A_2)^{-1}B_2=\frac1{(s-a)^2+1}\begin{bmatrix}1\\s-a\end{bmatrix}.
```

因此其输出贡献是

```math
\frac{c}{(s-a)^2+1}.
```

总传递函数为

```math
G(s)=\frac{b}{s-1}+\frac{c}{(s-a)^2+1}=\frac{b\bigl[(s-a)^2+1\bigr]+c(s-1)}{(s-1)\bigl[(s-a)^2+1\bigr]}.
```

这有助于理解隐藏模态：

- 输入系数为零时，第一个模态不能由输入激励，传递函数中不再有它的贡献。
- 输出系数为零时，后两个模态不能被输出反映，传递函数中不再有它们的贡献。
- 两个系数都非零时，对实数参数不存在上述极点的约消，原三阶实现同时可控、可观测，是最小实现。

最后一条也可直接检查分子：在 $`s=1`$ 时，分子为 $`b[(1-a)^2+1]`$；在 $`s=a\pm i`$ 时，分子为 $`c(a\pm i-1)`$。两个系数非零且参数为实数时，这些值都非零。

这里“没有额外限制”仅针对可控性、可观测性，不表示系统稳定性与参数无关。后两个模态的实部是 $`a`$；而完整开环系统还始终具有特征值 1。稳定性是需要单独判断的另一种性质。

## 十、常见错误与避免方法

### 10.1 把未知参数当成时间函数

本题参数是常数，不需要计算矩阵对时间的导数。使用普通 LTI 秩判据即可。

### 10.2 只看输入矩阵有没有零元素

第二个状态没有直接输入，但输入可以先影响第三个状态，再通过第三个状态对第二个状态的耦合影响它。因此输入矩阵的某一行为零，不等于对应状态不可控。

### 10.3 只看输出矩阵有没有零元素

第三个状态没有直接出现在输出里，但它会影响第二个状态，再影响输出及其导数。因此输出矩阵的某一列为零，不等于对应状态不可观测。

### 10.4 认为两个子系统分别可控就一定整体可控

多个子系统共享一个输入时，若动态相同或输入方向重合，整体可能仍不可控。不能只看各块，必须确认完整系统的独立性。本题的三阶行列式和不同模态解释正好补上了这一步。

对于多个子系统的输出相加，也有类似的可观测性问题。

### 10.5 漏掉输出行列式中的平方

输出矩阵的后两列都带有参数因子，因此行列式包含 $`c^2`$。这不要求参数必须为正，只要求它非零。

### 10.6 看到行列式为负就误判

满秩只要求行列式不为零，不要求行列式为正。可控性矩阵不是需要检查正定性的 Gram 矩阵。

### 10.7 不说明参数的数域

本题默认参数为实数，才可以使用 $`(a-1)^2+1\gt0`$。

如果题目明确允许复数参数，则应保留完整条件：

```math
\text{可控}\iff b\ne0\text{ 且 }(a-1)^2+1\ne0,
```

```math
\text{可观测}\iff c\ne0\text{ 且 }(a-1)^2+1\ne0.
```

也就是还需要排除 $`a=1+i`$ 与 $`a=1-i`$。原题通常按实数系统理解，不必把这个额外情况混入主答案。

## 十一、可以直接用于作业的证明

**解：**设

```math
A=\begin{bmatrix}1&0&0\\0&a&1\\0&-1&a\end{bmatrix},\quad B=\begin{bmatrix}b\\0\\1\end{bmatrix},\quad C=\begin{bmatrix}1&c&0\end{bmatrix}.
```

先计算

```math
AB=\begin{bmatrix}b\\1\\a\end{bmatrix},\qquad A^2B=\begin{bmatrix}b\\2a\\a^2-1\end{bmatrix}.
```

于是可控性矩阵为

```math
\mathcal C=[B\ AB\ A^2B]=\begin{bmatrix}b&b&b\\0&1&2a\\1&a&a^2-1\end{bmatrix},
```

其行列式为

```math
\det\mathcal C=-b(a^2-2a+2)=-b\bigl[(a-1)^2+1\bigr].
```

对任意实数参数，括号内严格为正，因此系统完全可控当且仅当 $`b\ne0`$。

再计算

```math
CA=\begin{bmatrix}1&ac&c\end{bmatrix},\qquad CA^2=\begin{bmatrix}1&(a^2-1)c&2ac\end{bmatrix}.
```

可观测性矩阵为

```math
\mathcal O=\begin{bmatrix}C\\CA\\CA^2\end{bmatrix}=\begin{bmatrix}1&c&0\\1&ac&c\\1&(a^2-1)c&2ac\end{bmatrix},
```

其行列式为

```math
\det\mathcal O=c^2(a^2-2a+2)=c^2\bigl[(a-1)^2+1\bigr].
```

因此系统完全可观测当且仅当 $`c\ne0`$。

综上，系统同时完全可控、完全可观测的条件是

```math
\boxed{a\in\mathbb R\text{ 任意},\qquad b\ne0,\qquad c\ne0.}
```
