> 对应课程讲义：[线性系统可控性与可观测性：初学者讲义](../课程讲义/线性系统可控性与可观测性_初学者讲义.md)。

## 一、结论与解题路线

| 小题 | 系统类型 | 可控性 | 可观测性 |
|---|---|---|---|
| ① | 线性时不变系统 | 完全可控 | 完全可观测 |
| ③ | 线性时变系统 | 完全可控 | 完全可观测 |
| ④ | 线性时变系统 | 不完全可控 | 完全可观测 |

第③、④题的结论对任意起始时刻和任意正长度时间区间成立。

这组题最重要的区别是：**第①题可以用普通 Kalman 秩判据；第③、④题不能把时变矩阵直接当成常矩阵来判断。**

## 二、前置知识

### 2.1 可控与可观测分别研究什么

考虑系统

```math
\dot x(t)=A(t)x(t)+B(t)u(t),\qquad y(t)=C(t)x(t).
```

可控性研究：能否通过选择输入，把任意初态在有限时间内驱到零？它只取决于矩阵对 $`(A(t),B(t))`$。

可观测性研究：已知一段时间内的输入和输出，能否唯一确定初始状态？它只取决于矩阵对 $`(A(t),C(t))`$。

研究可观测性时，可以考虑零输入响应。因为已知输入产生的输出贡献可以剔除；或者将两个相同输入下的轨迹相减，输入项自然抵消。

因此，判断可控性是在看输入能否影响全部状态方向；判断可观测性是在看输出能否区分全部初始状态。

### 2.2 时不变系统：Kalman 秩判据

如果 $`A,B,C`$ 都是常矩阵，系统是线性时不变系统。设状态维数为 $`n`$，定义可控性矩阵

```math
\mathcal C=\begin{bmatrix}B&AB&A^2B&\cdots&A^{n-1}B\end{bmatrix}.
```

则

```math
\boxed{(A,B)\text{ 完全可控}\iff\mathrm{rank}\,\mathcal C=n.}
```

定义可观测性矩阵

```math
\mathcal O=\begin{bmatrix}C\\CA\\CA^2\\\vdots\\CA^{n-1}\end{bmatrix}.
```

则

```math
\boxed{(A,C)\text{ 完全可观测}\iff\mathrm{rank}\,\mathcal O=n.}
```

注意，可控性矩阵横向拼接，可观测性矩阵纵向堆叠。

**技巧一：已经找到足够多的独立方向，就可以停止。**例如三维系统，只要证明 $`\mathrm{rank}[B\ AB]=3`$，就不必继续计算 $`A^2B`$。

**技巧二：非方阵不能直接求行列式，但可以选方形子矩阵。**一个三行四列的矩阵，如果其中某个三阶子矩阵行列式非零，则它的秩至少为 3；它只有 3 行，所以秩恰好为 3。

### 2.3 时变系统：为什么需要导数项

如果矩阵随时间变化，不能直接凭

```math
[B(t)\ A(t)B(t)]
```

或

```math
\begin{bmatrix}C(t)\\C(t)A(t)\end{bmatrix}
```

来判断时变系统。原因是输入作用方向和输出测量方向自己也在变化，正确判据必须计入这些变化率。

对二阶系统，可控性的导数充分判据使用

```math
M_0(t)=B(t),\qquad M_1(t)=\dot B(t)-A(t)B(t).
```

若所研究区间内存在某个时刻 $`t_*`$，使

```math
\mathrm{rank}\begin{bmatrix}M_0(t_*)&M_1(t_*)\end{bmatrix}=2,
```

则系统在该区间完全可控。

可观测性的导数充分判据使用

```math
N_0(t)=C(t),\qquad N_1(t)=\dot C(t)+C(t)A(t).
```

若某个时刻满足

```math
\mathrm{rank}\begin{bmatrix}N_0(t_*)\\N_1(t_*)\end{bmatrix}=2,
```

则系统在该区间完全可观测。

需要记住符号与乘法顺序：

```math
\boxed{M_1=\dot B-AB,\qquad N_1=\dot C+CA.}
```

这些一般是**充分条件**：满秩可以下肯定结论；不满秩一般不能直接下否定结论。第④题尤其需要注意这一点。

### 2.4 时变系统的充要判据：函数线性无关

状态响应公式为

```math
x(t)=\Phi(t,t_0)x(t_0)+\int_{t_0}^{t}\Phi(t,\tau)B(\tau)u(\tau)\,d\tau.
```

其中 $`\Phi(t,s)`$ 是状态转移矩阵。在固定区间上：

- 系统完全可控，当且仅当 $`\Phi(t_0,t)B(t)`$ 的各行作为时间函数线性无关。
- 系统完全可观测，当且仅当 $`C(t)\Phi(t,t_0)`$ 的各列作为时间函数线性无关。

函数线性无关是指：不存在一组不全为零的**常数系数**，使函数的线性组合在整个区间恒为零。

例如，$`1`$ 与 $`t^2`$ 在任意正长度区间上线性无关；$`e^{-t}`$ 与 $`e^{-3t}`$ 也线性无关；两个非零常数函数则线性相关。

## 三、第①题：时不变系统

题目为

```math
\dot x=\begin{bmatrix}0&1&0\\0&0&1\\-1&3&-3\end{bmatrix}x+\begin{bmatrix}0&1\\0&0\\1&-1\end{bmatrix}u,
```

```math
y=\begin{bmatrix}0&0&1\\1&2&1\end{bmatrix}x.
```

所以

```math
A=\begin{bmatrix}0&1&0\\0&0&1\\-1&3&-3\end{bmatrix},\quad B=\begin{bmatrix}0&1\\0&0\\1&-1\end{bmatrix},\quad C=\begin{bmatrix}0&0&1\\1&2&1\end{bmatrix}.
```

状态有 3 个，输入有 2 个，输出有 2 个。

### 3.1 可控性：先计算 AB

把输入矩阵的两列记为

```math
b_1=\begin{bmatrix}0\\0\\1\end{bmatrix},\qquad b_2=\begin{bmatrix}1\\0\\-1\end{bmatrix}.
```

分别计算

```math
Ab_1=\begin{bmatrix}0\\1\\-3\end{bmatrix},\qquad Ab_2=\begin{bmatrix}0\\-1\\2\end{bmatrix}.
```

因此

```math
AB=\begin{bmatrix}0&0\\1&-1\\-3&2\end{bmatrix}.
```

拼接得到

```math
[B\ AB]=\begin{bmatrix}0&1&0&0\\0&0&1&-1\\1&-1&-3&2\end{bmatrix}.
```

取第 1、2、3 列组成方阵

```math
Q=\begin{bmatrix}0&1&0\\0&0&1\\1&-1&-3\end{bmatrix}.
```

其行列式为

```math
\det Q=-\begin{vmatrix}0&1\\1&-3\end{vmatrix}=1\ne0.
```

所以

```math
\mathrm{rank}[B\ AB]=3.
```

状态维数就是 3，因此完整可控性矩阵也满秩，得到

```math
\boxed{\text{第①题完全可控。}}
```

这里无须继续计算 $`A^2B`$。

**直观理解：**输入矩阵的两个列向量只能直接张成二维空间，但经过系统动态传播，$`Ab_1`$ 又提供了一个独立方向。向量 $`b_1,b_2,Ab_1`$ 已能张成整个三维状态空间。

### 3.2 可观测性：计算 CA

输出矩阵第一行给出

```math
[0,0,1]A=[-1,3,-3].
```

第二行给出

```math
[1,2,1]A=[0,1,0]+2[0,0,1]+[-1,3,-3]=[-1,4,-1].
```

因此

```math
CA=\begin{bmatrix}-1&3&-3\\-1&4&-1\end{bmatrix}.
```

堆叠得到

```math
\begin{bmatrix}C\\CA\end{bmatrix}=\begin{bmatrix}0&0&1\\1&2&1\\-1&3&-3\\-1&4&-1\end{bmatrix}.
```

取前三行组成方阵

```math
P=\begin{bmatrix}0&0&1\\1&2&1\\-1&3&-3\end{bmatrix}.
```

其行列式为

```math
\det P=\begin{vmatrix}1&2\\-1&3\end{vmatrix}=5\ne0.
```

因此

```math
\mathrm{rank}\begin{bmatrix}C\\CA\end{bmatrix}=3,
```

从而

```math
\boxed{\text{第①题完全可观测。}}
```

同样，无须继续计算 $`CA^2`$。

### 3.3 用直接恢复状态的方法理解可观测性

两个输出分别是

```math
y_1=x_3,\qquad y_2=x_1+2x_2+x_3.
```

根据状态方程第三行，

```math
\dot y_1=-x_1+3x_2-3x_3+u_1-u_2.
```

输入已知，所以可以计算

```math
a=y_2-y_1=x_1+2x_2,
```

```math
b=\dot y_1+3y_1-u_1+u_2=-x_1+3x_2.
```

两式相加得到 $`a+b=5x_2`$，因此

```math
x_2=\frac{a+b}{5},\qquad x_1=\frac{3a-2b}{5},\qquad x_3=y_1.
```

全部状态确实能够由输入、输出信息恢复。

使用输出导数是理论上的解释。实际测量含噪声时，通常不直接对测量数据进行粗糙的数值微分，而采用适当的状态估计方法。

## 四、第③题：时变系统的导数判据

题目为

```math
\dot x=\begin{bmatrix}-1&t\\0&-1\end{bmatrix}x+\begin{bmatrix}e^{-t}\\e^{-t}\end{bmatrix}u,
```

```math
y=\begin{bmatrix}e^t&e^t\end{bmatrix}x.
```

因此

```math
A(t)=\begin{bmatrix}-1&t\\0&-1\end{bmatrix},\quad B(t)=\begin{bmatrix}e^{-t}\\e^{-t}\end{bmatrix},\quad C(t)=\begin{bmatrix}e^t&e^t\end{bmatrix}.
```

三个矩阵都含时间，因此必须按时变系统处理。

### 4.1 用导数判据判断可控性

二阶系统只需构造

```math
M_0=B,\qquad M_1=\dot B-AB.
```

首先

```math
\dot B(t)=\begin{bmatrix}-e^{-t}\\-e^{-t}\end{bmatrix}.
```

其次

```math
A(t)B(t)=\begin{bmatrix}-1&t\\0&-1\end{bmatrix}\begin{bmatrix}e^{-t}\\e^{-t}\end{bmatrix}=\begin{bmatrix}(t-1)e^{-t}\\-e^{-t}\end{bmatrix}.
```

相减得到

```math
M_1(t)=\begin{bmatrix}-te^{-t}\\0\end{bmatrix}.
```

所以

```math
[M_0\ M_1]=\begin{bmatrix}e^{-t}&-te^{-t}\\e^{-t}&0\end{bmatrix},
```

其行列式为

```math
\det[M_0\ M_1]=te^{-2t}.
```

指数函数始终非零，因此只要 $`t\ne0`$，这个矩阵就满秩。任意正长度时间区间中都能选到非零时刻，所以

```math
\boxed{\text{第③题在任意正长度区间上完全可控。}}
```

**为什么零时刻的行列式为零不影响结论？**判据只要求区间内存在某个时刻满秩，不要求每个时刻都满秩。即使从零时刻开始，也能在后面的区间内选取一个正时刻。

不能把“初始瞬间不满秩”理解为“整个时间区间不可控”。

### 4.2 用导数判据判断可观测性

构造

```math
N_0=C,\qquad N_1=\dot C+CA.
```

首先

```math
\dot C(t)=\begin{bmatrix}e^t&e^t\end{bmatrix}.
```

其次

```math
C(t)A(t)=\begin{bmatrix}e^t&e^t\end{bmatrix}\begin{bmatrix}-1&t\\0&-1\end{bmatrix}=\begin{bmatrix}-e^t&(t-1)e^t\end{bmatrix}.
```

相加得到

```math
N_1(t)=\begin{bmatrix}0&te^t\end{bmatrix}.
```

于是

```math
\begin{bmatrix}N_0\\N_1\end{bmatrix}=\begin{bmatrix}e^t&e^t\\0&te^t\end{bmatrix},
```

行列式为

```math
\det\begin{bmatrix}N_0\\N_1\end{bmatrix}=te^{2t}.
```

当 $`t\ne0`$ 时非零，而任意正长度区间都包含非零时刻，因此

```math
\boxed{\text{第③题在任意正长度区间上完全可观测。}}
```

### 4.3 为什么一个输出能区分两个状态

原输出为

```math
y=e^t(x_1+x_2).
```

状态方程为

```math
\dot x_1=-x_1+tx_2+e^{-t}u,\qquad \dot x_2=-x_2+e^{-t}u.
```

对输出求导，代入状态方程：

```math
\begin{aligned}
\dot y&=e^t(x_1+x_2)+e^t(\dot x_1+\dot x_2)\\ &=te^t x_2+2u.
\end{aligned}
```

当 $`t\ne0`$ 时，

```math
x_2(t)=\frac{\dot y(t)-2u(t)}{te^t},\qquad x_1(t)=e^{-t}y(t)-x_2(t).
```

输出本身给出一个状态组合，输出变化率提供另一个独立信息。在非零时刻恢复当前状态后，利用可逆状态转移关系和已知输入，就能恢复初态。

零时刻不能使用这个瞬时除法公式，不意味着从一段输出中无法恢复状态。

### 4.4 用状态转移矩阵进一步验证

这一部分用于理解一般判据，不是完成本题必须重复进行的计算。

先考虑齐次方程。第二个状态满足

```math
\dot x_2=-x_2,\qquad x_2(t)=e^{-(t-s)}x_2(s).
```

第一个状态满足

```math
\dot x_1+x_1=tx_2.
```

乘积分因子后，

```math
\frac d{dt}(e^t x_1)=te^t x_2.
```

又因为 $`e^t x_2(t)=e^s x_2(s)`$，积分得到

```math
x_1(t)=e^{-(t-s)}\left[x_1(s)+\frac{t^2-s^2}{2}x_2(s)\right].
```

因此状态转移矩阵为

```math
\boxed{\Phi(t,s)=e^{-(t-s)}\begin{bmatrix}1&\dfrac{t^2-s^2}{2}\\0&1\end{bmatrix}.}
```

#### 可控性验证

计算

```math
\Phi(t_0,t)B(t)=e^{-t_0}\begin{bmatrix}1+\dfrac{t_0^2-t^2}{2}\\1\end{bmatrix}.
```

忽略共同的非零常数因子，两行函数为

```math
f_1(t)=1+\frac{t_0^2-t^2}{2},\qquad f_2(t)=1.
```

假设常数 $`\alpha,\beta`$ 使 $`\alpha f_1+\beta f_2\equiv0`$，则

```math
-\frac{\alpha}{2}t^2+\alpha\left(1+\frac{t_0^2}{2}\right)+\beta\equiv0.
```

多项式在正长度区间上恒为零，所有系数必须为零，所以 $`\alpha=\beta=0`$。两行函数线性无关，故可控。

#### 可观测性验证

计算

```math
C(t)\Phi(t,t_0)=e^{t_0}\begin{bmatrix}1&1+\dfrac{t^2-t_0^2}{2}\end{bmatrix}.
```

两列函数分别是常数函数和含非零二次项的函数，线性无关，故可观测。

## 五、第④题：不可控但可观测

题目为

```math
\dot x=\begin{bmatrix}-1&0\\0&-2\end{bmatrix}x+\begin{bmatrix}e^{-t}\\e^{-2t}\end{bmatrix}u,
```

```math
y=\begin{bmatrix}1&e^{-t}\end{bmatrix}x.
```

即

```math
A=\begin{bmatrix}-1&0\\0&-2\end{bmatrix},\quad B(t)=\begin{bmatrix}e^{-t}\\e^{-2t}\end{bmatrix},\quad C(t)=\begin{bmatrix}1&e^{-t}\end{bmatrix}.
```

虽然系统矩阵是常矩阵，输入和输出矩阵却随时间变化，因此整个系统仍是时变系统。

### 5.1 先看导数矩阵，但不能立即下否定结论

有

```math
\dot B=\begin{bmatrix}-e^{-t}\\-2e^{-2t}\end{bmatrix},\qquad AB=\begin{bmatrix}-e^{-t}\\-2e^{-2t}\end{bmatrix}.
```

因此

```math
M_1=\dot B-AB=0,
```

从而

```math
[M_0\ M_1]=\begin{bmatrix}e^{-t}&0\\e^{-2t}&0\end{bmatrix}
```

的秩为 1。

不能仅凭一般导数充分判据失败，就直接宣布不可控。还应使用充要判据，或者直接找出输入无法改变的状态组合。

### 5.2 方法一：状态转移矩阵与函数独立性

系统矩阵是对角常矩阵，因此

```math
\Phi(t,s)=\begin{bmatrix}e^{-(t-s)}&0\\0&e^{-2(t-s)}\end{bmatrix}.
```

可控性函数判据需要的是反向时间参数顺序：

```math
\Phi(t_0,t)=\begin{bmatrix}e^{t-t_0}&0\\0&e^{2(t-t_0)}\end{bmatrix}.
```

乘以输入矩阵后，

```math
\Phi(t_0,t)B(t)=\begin{bmatrix}e^{t-t_0}&0\\0&e^{2(t-t_0)}\end{bmatrix}\begin{bmatrix}e^{-t}\\e^{-2t}\end{bmatrix}=\begin{bmatrix}e^{-t_0}\\e^{-2t_0}\end{bmatrix}.
```

该向量与当前时间无关。第二行始终是第一行的固定倍数，两行作为时间函数线性相关。因此

```math
\boxed{\text{第④题不完全可控。}}
```

也可使用 Gram 矩阵。令

```math
v=\begin{bmatrix}e^{-t_0}\\e^{-2t_0}\end{bmatrix},
```

则

```math
W_c=\int_{t_0}^{t_1}vv^T\,dt=(t_1-t_0)vv^T.
```

该矩阵秩为 1，不可能可逆。

### 5.3 方法二：找出输入无法改变的量

定义新状态

```math
z_1=e^t x_1,\qquad z_2=e^{2t}x_2.
```

分别求导：

```math
\begin{aligned}
\dot z_1&=e^t x_1+e^t\dot x_1\\ &=e^t x_1+e^t(-x_1+e^{-t}u)\\ &=u,
\end{aligned}
```

```math
\begin{aligned}
\dot z_2&=2e^{2t}x_2+e^{2t}\dot x_2\\ &=2e^{2t}x_2+e^{2t}(-2x_2+e^{-2t}u)\\ &=u.
\end{aligned}
```

所以

```math
\dot z_1=u,\qquad\dot z_2=u.
```

相减得到

```math
\boxed{\frac d{dt}(z_1-z_2)=0.}
```

因此两者之差恒定，输入无法改变它。

若希望最终两个原状态都等于零，则两个新状态也必须同时等于零，因此初态必须满足

```math
\boxed{e^{t_0}x_1(t_0)-e^{2t_0}x_2(t_0)=0.}
```

不是每个初态都满足这个条件，所以系统不完全可控。

例如取初始时刻为零，且

```math
x(0)=\begin{bmatrix}1\\0\end{bmatrix},
```

则初始差值为 1，并且永远保持为 1，不可能让两个新状态同时到零。

上述初态条件也是这个系统中特定状态可以驱到零的充分条件：若两个新状态的初值相等，选择输入使共同的值降到零即可。

### 5.4 可观测性：使用时变导数判据

构造

```math
N_0=C,\qquad N_1=\dot C+CA.
```

分别计算

```math
\dot C(t)=\begin{bmatrix}0&-e^{-t}\end{bmatrix},
```

```math
C(t)A=\begin{bmatrix}1&e^{-t}\end{bmatrix}\begin{bmatrix}-1&0\\0&-2\end{bmatrix}=\begin{bmatrix}-1&-2e^{-t}\end{bmatrix}.
```

所以

```math
N_1(t)=\begin{bmatrix}-1&-3e^{-t}\end{bmatrix}.
```

堆叠后得到

```math
\begin{bmatrix}N_0\\N_1\end{bmatrix}=\begin{bmatrix}1&e^{-t}\\-1&-3e^{-t}\end{bmatrix}.
```

其行列式为

```math
\det\begin{bmatrix}N_0\\N_1\end{bmatrix}=-3e^{-t}+e^{-t}=-2e^{-t}\ne0.
```

因此

```math
\boxed{\text{第④题完全可观测。}}
```

### 5.5 为什么不可控却可以观测

不可控说的是输入不能独立操纵全部状态方向；可观测说的是输出能够区分不同初态，两者不是同一个问题。

在零输入条件下，

```math
x_1(t)=e^{-(t-t_0)}x_1(t_0),\qquad x_2(t)=e^{-2(t-t_0)}x_2(t_0).
```

所以输出为

```math
y(t)=e^{-(t-t_0)}x_1(t_0)+e^{-3t+2t_0}x_2(t_0).
```

两个初态分别对应不同的时间变化规律，去掉固定非零系数后就是 $`e^{-t}`$ 与 $`e^{-3t}`$。这两个函数线性无关，所以一段时间的输出能区分两种初态贡献。

也可以直接计算输出导数：

```math
y=x_1+e^{-t}x_2,
```

```math
\dot y=-x_1-3e^{-t}x_2+(e^{-t}+e^{-3t})u.
```

令已知量

```math
r=\dot y-(e^{-t}+e^{-3t})u,
```

则

```math
r=-x_1-3e^{-t}x_2.
```

与输出方程相加，得到

```math
y+r=-2e^{-t}x_2.
```

所以

```math
x_2=-\frac{e^t}{2}(y+r),\qquad x_1=y-e^{-t}x_2.
```

全部状态能够恢复，因此可观测。

## 六、第④题最容易出现的错误

如果错误地使用时不变系统的可控性矩阵，会得到

```math
[B(t)\ AB(t)]=\begin{bmatrix}e^{-t}&-e^{-t}\\e^{-2t}&-2e^{-2t}\end{bmatrix},
```

而其行列式为

```math
\det[B\ AB]=-e^{-3t}\ne0.
```

如果据此宣布“可控”，就会得到错误答案。

这个计算判断的是：把某个时刻的输入矩阵固定住后构造出来的另一个时不变系统。它没有判断真实的时变系统。

真实系统满足

```math
\dot B=AB,\qquad M_1=\dot B-AB=0.
```

输入作用方向随时间的变化，恰好抵消了看似能够产生新控制方向的自然动态。在新坐标中，两个状态都满足同样的方程 $`\dot z_1=\dot z_2=u`$，因此输入只能同步推动两者，不能改变它们的差。

## 七、可以用于作业的精简解答

### 第①题

计算

```math
AB=\begin{bmatrix}0&0\\1&-1\\-3&2\end{bmatrix}.
```

矩阵 $`[B\ AB]`$ 的第 1、2、3 列组成的三阶子式为 1，因此秩为 3，系统完全可控。

又有

```math
CA=\begin{bmatrix}-1&3&-3\\-1&4&-1\end{bmatrix}.
```

矩阵 $`\begin{bmatrix}C\\CA\end{bmatrix}`$ 的前三行组成的三阶子式为 5，因此秩为 3，系统完全可观测。

### 第③题

计算

```math
M_1=\dot B-AB=\begin{bmatrix}-te^{-t}\\0\end{bmatrix},\qquad \det[B\ M_1]=te^{-2t}.
```

任意正长度区间都存在非零时刻使该行列式非零，故系统完全可控。

又有

```math
N_1=\dot C+CA=\begin{bmatrix}0&te^t\end{bmatrix},\qquad \det\begin{bmatrix}C\\N_1\end{bmatrix}=te^{2t}.
```

同理，系统完全可观测。

### 第④题

状态转移矩阵为

```math
\Phi(t,s)=\begin{bmatrix}e^{-(t-s)}&0\\0&e^{-2(t-s)}\end{bmatrix}.
```

因此

```math
\Phi(t_0,t)B(t)=\begin{bmatrix}e^{-t_0}\\e^{-2t_0}\end{bmatrix}.
```

两行作为时间函数线性相关，故系统不完全可控。

另外，

```math
N_1=\dot C+CA=\begin{bmatrix}-1&-3e^{-t}\end{bmatrix},\qquad \det\begin{bmatrix}C\\N_1\end{bmatrix}=-2e^{-t}\ne0.
```

所以系统完全可观测。
