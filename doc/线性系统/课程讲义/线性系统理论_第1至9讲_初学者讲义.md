## 0. 先看全局：这九讲要解决什么

想象你在控制一辆小车：你能施加推力，但只能测量位置。你会依次遇到四个问题：

1. **怎样描述小车？** 位置和速度共同决定未来，只有位置通常不够。
2. **给定推力后，它怎样运动？** 这需要解微分方程。
3. **推力能否实现任意位置和速度的调整？** 这是可控性。
4. **只测量一段时间的位置，能否推断初始位置和速度？** 这是可观测性。

如果模型里有一些状态，既不影响输入输出关系，或根本不能被输入激励，那么为了描述零状态输入输出关系，可以进一步缩小模型。这就引出结构分解与最小实现。

本讲义的主线可以写成：

```math
\text{物理规律}
\longrightarrow (A,B,C,D)
\longrightarrow \text{状态与输出的解}
\longrightarrow \text{可控、可观}
\longrightarrow \text{分解与最小实现}.
```

### 0.1 全文统一的符号

```math
\boxed{\dot x(t)=A(t)x(t)+B(t)u(t),\qquad
y(t)=C(t)x(t)+D(t)u(t)}
```

| 符号 | 维数 | 含义 |
|---|---|---|
| $`x(t)`$ | $`n\times1`$ | 状态，系统内部的记忆 |
| $`u(t)`$ | $`p\times1`$ | 输入，可以施加的作用 |
| $`y(t)`$ | $`q\times1`$ | 输出，可以测量或关心的量 |
| $`A(t)`$ | $`n\times n`$ | 状态自身怎样演化 |
| $`B(t)`$ | $`n\times p`$ | 输入怎样进入状态 |
| $`C(t)`$ | $`q\times n`$ | 状态怎样反映到输出 |
| $`D(t)`$ | $`q\times p`$ | 输入到输出的直接通道 |
| $`\Phi(t,t_0)`$ | $`n\times n`$ | 零输入下，从 $`t_0`$ 到 $`t`$ 的状态转移 |
| $`G(s)`$ | $`q\times p`$ | 传递函数矩阵 |
| $`\mathcal C`$ | $`n\times np`$ | 可控性矩阵，课件中也记作 $`U`$ |
| $`\mathcal O`$ | $`nq\times n`$ | 可观测性矩阵，课件中也记作 $`V`$ |

本文默认实系数系统，$`T`$ 表示转置。涉及复特征值时用 $`*`$ 表示共轭转置，相关秩在复数域计算。

**约定：全文统一使用新坐标 $`z=Px`$。** 因此 $`x=P^{-1}z`$。构造“新基底的列向量矩阵”时，得到的是 $`P^{-1}`$，不是 $`P`$。

### 0.2 建议怎样读

- **第一遍抓主线：** 读第 1—7 章的基本概念和低阶例题，再读第 9—10 章的分解与最小实现。
- **第二遍做计算：** 重点练矩阵指数、$`\mathcal C`$、$`\mathcal O`$、PBH、选基和坐标变换。
- **第三遍补证明：** 回看 Gram 矩阵、Cayley–Hamilton 定理、几何不变性和最小实现证明。

多变量零极点、一般时变系统、Luenberger 标准形可以在主线掌握后再细读。它们仍在本文中保留，避免知识范围只剩常系数单输入系统。

本讲义不系统展开课件后续课程中的稳定性理论、状态反馈设计和观测器设计；出现相关词语时，只解释它与这九讲的联系。

## 1. 数学准备：先把后面会用的工具补齐

### 1.1 向量与矩阵：先理解“线性组合”

设

```math
A=\begin{bmatrix}a_1&a_2&\cdots&a_n\end{bmatrix},\qquad
x=\begin{bmatrix}x_1&\cdots&x_n\end{bmatrix}^T.
```

则

```math
Ax=x_1a_1+\cdots+x_na_n.
```

所以，矩阵乘法可以理解为：**用 $`x`$ 中的数作为系数，对 $`A`$ 的列向量做线性组合。** 后面的 $`Bu`$、$`\operatorname{Im}B`$、可控性矩阵，都会反复用到这一解释。

例如

```math
B=\begin{bmatrix}1\\0\end{bmatrix},\quad Bu=\begin{bmatrix}u\\0\end{bmatrix}
```

说明输入只能直接影响第一个状态的变化率。但第二个状态能否被间接影响，还要看 $`A`$，不能只看 $`B`$。

矩阵乘法一般不交换：$`AB\ne BA`$。做乘法前先检查维数，例如 $`CB`$ 是 $`q\times p`$，而 $`BC`$ 通常甚至没有定义。

### 1.2 线性无关、基与维数

向量 $`v_1,\dots,v_k`$ 线性无关，是指

```math
\alpha_1v_1+\cdots+\alpha_kv_k=0
\quad\Longrightarrow\quad
\alpha_1=\cdots=\alpha_k=0.
```

若某个向量可由其他向量组合出来，它就没有提供新的方向。

- $`\operatorname{span}\{v_1,\dots,v_k\}`$：这些向量能组合出的所有向量。
- 基：既能生成整个空间，又线性无关的一组向量。
- 维数：一组基中向量的个数。
- $`\operatorname{rank}M`$：矩阵列空间的维数，也等于行空间的维数。

例如

```math
M=\begin{bmatrix}1&2&0\\0&0&1\end{bmatrix}
```

的第二列是第一列的两倍，而第一、三列无关，所以 $`\operatorname{rank}M=2`$。

**计算方法：** 用初等行变换把矩阵化为阶梯形，主元数就是秩。若要从原矩阵选列空间的一组基，应取原矩阵中对应主元位置的列，不能把化简后的列直接当作原空间中的基。

### 1.3 像空间、核空间与秩零化度公式

对 $`M\in\mathbb R^{m\times n}`$：

```math
\operatorname{Im}M=\{Mx:x\in\mathbb R^n\},
```

```math
\ker M=\{x\in\mathbb R^n:Mx=0\}.
```

像空间在输出所在的 $`\mathbb R^m`$ 中；核空间在输入所在的 $`\mathbb R^n`$ 中。

```math
\boxed{\dim\ker M+\operatorname{rank}M=n}.
```

**补充例：** $`M=[1\ 1]`$。则 $`\ker M=\operatorname{span}\{(1,-1)^T\}`$，因为这一方向的两个分量在求和后完全抵消。

这正是不可观测性的雏形：某些非零状态通过测量矩阵后，输出却是零。

### 1.4 内积、正交补与直和

实向量内积为 $`x^Ty`$。若 $`x^Ty=0`$，称二者正交。子空间 $`\mathcal S`$ 的正交补是

```math
\mathcal S^\perp=\{v:v^Ts=0,\ \forall s\in\mathcal S\}.
```

两个常用关系：

```math
\boxed{(\operatorname{Im}M)^\perp=\ker M^T},\qquad
\boxed{(\ker M)^\perp=\operatorname{Im}M^T}.
```

证明第一式，只需注意 $`v^TMx=0`$ 对所有 $`x`$ 成立，等价于 $`M^Tv=0`$。

若 $`\mathcal S\cap\mathcal T=\{0\}`$，二者之和记为直和 $`\mathcal S\oplus\mathcal T`$，其中每个向量都有唯一的分解。直和不要求正交；正交直和只是其中一种特殊情况。

特别地，$`\mathbb R^n=\mathcal S\oplus\mathcal S^\perp`$。

### 1.5 逆矩阵、换基与相似变换

对方阵 $`P`$，以下条件等价：可逆、$`\det P\ne0`$、$`\operatorname{rank}P=n`$、列向量构成一组基。

若新基底为 $`q_1,\dots,q_n`$，令

```math
T=[q_1\ \cdots\ q_n],\qquad x=Tz.
```

这里 $`z`$ 是同一个状态在新基底下的坐标。由于本文用 $`z=Px`$，所以 $`P=T^{-1}`$。

原方程 $`\dot x=Ax`$ 变成

```math
\dot z=PAP^{-1}z.
```

$`A`$ 和 $`PAP^{-1}`$ 相似。相似变换保留特征值、特征多项式与秩，也保留系统的可控性、可观测性；它只是更换状态坐标。

### 1.6 特征值、特征向量与 Jordan 块

若 $`Av=\lambda v`$，且 $`v\ne0`$，则 $`\lambda`$ 是特征值，$`v`$ 是对应的右特征向量。求解步骤为

```math
\det(\lambda I-A)=0,\qquad (A-\lambda I)v=0.
```

沿特征向量出发，零输入运动为 $`x(t)=e^{\lambda t}v`$，所以特征值控制着一种基本运动模式。

若能找到 $`n`$ 个线性无关特征向量，则

```math
A=T\Lambda T^{-1},\qquad \Lambda=\operatorname{diag}(\lambda_1,\dots,\lambda_n).
```

有重复特征值不一定不能对角化。例如 $`2I`$ 可以对角化；但

```math
J=\begin{bmatrix}\lambda&1\\0&\lambda\end{bmatrix}
```

只有一个独立特征向量，不能对角化。这种矩阵称为一个 Jordan 块，课件称“若当块”。

对 $`J=\lambda I+N`$，$`N`$ 是幂零矩阵；若块大小为 $`m`$，则 $`N^m=0`$。这使得

```math
e^{Jt}=e^{\lambda t}\left(I+tN+\frac{t^2N^2}{2!}+\cdots+
\frac{t^{m-1}N^{m-1}}{(m-1)!}\right).
```

所以重根对应的运动中可能出现 $`te^{\lambda t},t^2e^{\lambda t}`$，不能只想到单独的 $`e^{\lambda t}`$。

### 1.7 Cayley–Hamilton 定理与最小多项式

设 $`A`$ 的特征多项式为

```math
\Delta(s)=s^n+a_1s^{n-1}+\cdots+a_n.
```

Cayley–Hamilton 定理说：

```math
\boxed{\Delta(A)=A^n+a_1A^{n-1}+\cdots+a_nI=0}.
```

例如

```math
A=\begin{bmatrix}0&1\\-2&-3\end{bmatrix},\quad
\Delta(s)=s^2+3s+2,
```

于是 $`A^2=-3A-2I`$。更高次幂也能写成 $`I,A`$ 的组合。

**它在本课程中的作用：** 无穷多个 $`B,AB,A^2B,\dots`$ 的新方向，最多查看到 $`A^{n-1}B`$ 就够了。可观测性也有同样的有限化过程。

最小多项式 $`m_A(s)`$ 是满足 $`m_A(A)=0`$ 的最低次数首一多项式，其次数 $`d\le n`$。若已知它，通常只需检查到 $`A^{d-1}`$。

### 1.8 微分方程与初始条件

标量方程

```math
\dot x=ax+bu,\qquad x(0)=x_0
```

乘以积分因子 $`e^{-at}`$ 后，有

```math
\frac{d}{dt}(e^{-at}x)=e^{-at}bu.
```

积分得到

```math
\boxed{x(t)=e^{at}x_0+\int_0^t e^{a(t-\tau)}bu(\tau)\,d\tau}.
```

第一项来自初始状态；第二项来自后续输入。这就是后面矩阵公式的原型。

对于二阶方程 $`\ddot y+a_1\dot y+a_2y=u`$，通常需要两个初始数 $`y(0),\dot y(0)`$ 才能确定唯一解。

全文在通常的连续或分段连续系数、容许输入条件下讨论有限区间的解；不把奇异微分方程混入普通状态空间模型。

### 1.9 Laplace 变换、卷积与脉冲

单边 Laplace 变换定义为

```math
F(s)=\mathcal L\{f(t)\}=\int_0^\infty e^{-st}f(t)\,dt,
```

在积分收敛的区域内使用。它把微分关系转化为代数关系：

```math
\mathcal L\{\dot x\}=sX(s)-x(0).
```

| 时间函数（$`t\ge0`$） | Laplace 变换 |
|---|---|
| $`1`$ | $`1/s`$ |
| $`e^{at}`$ | $`1/(s-a)`$ |
| $`te^{at}`$ | $`1/(s-a)^2`$ |
| $`t^ke^{at}`$ | $`k!/(s-a)^{k+1}`$ |
| $`\cos\omega t`$ | $`s/(s^2+\omega^2)`$ |
| $`\sin\omega t`$ | $`\omega/(s^2+\omega^2)`$ |

卷积定义为

```math
(g*u)(t)=\int_0^t g(t-\tau)u(\tau)\,d\tau,
```

并有 $`\mathcal L\{g*u\}=G(s)U(s)`$。

Dirac 脉冲 $`\delta`$ 应理解为广义函数，不是普通的“某点等于无穷大”的函数。它最重要的性质是

```math
\int_{-\infty}^{\infty}f(t)\delta(t-\tau)\,dt=f(\tau).
```

它把“在某一时刻施加单位冲击”理想化。由脉冲叠加推导积分响应时，还隐含了使极限和系统作用能够交换的适当连续性条件；单凭有限项叠加原理不能无条件推出无穷叠加。

### 1.10 正定矩阵与 Gram 矩阵

实对称矩阵 $`W`$ 若满足 $`v^TWv\ge0`$，称半正定；若对每个非零 $`v`$ 都有 $`v^TWv>0`$，称正定，记作 $`W\succ0`$。

设 $`F(t)\in\mathbb R^{n\times p}`$ 连续，定义

```math
W=\int_a^bF(t)F(t)^T\,dt.
```

则

```math
v^TWv=\int_a^b\|F(t)^Tv\|^2\,dt\ge0.
```

右边是一个非负函数的积分。若为零，连续性保证 $`F(t)^Tv=0`$ 在整个区间成立。因此

```math
\boxed{W\text{ 可逆}\iff W\succ0\iff F(t)\text{ 的行作为函数在 }[a,b]\text{ 上线性无关}}.
```

**这里的线性组合系数必须是常数，而且等式要对整个区间成立。** 这不同于逐时刻的矩阵满秩。

例如 $`F(t)=[t\ t^2]^T`$ 在每个时刻都只有一列，但其两行函数在 $`[0,1]`$ 上无关：

```math
W=\begin{bmatrix}1/3&1/4\\1/4&1/5\end{bmatrix},\qquad
\det W=\frac1{240}>0.
```

时间积累可以提供单个时刻没有的独立信息。

## 2. 输入输出描述：先看系统的外部行为

### 2.1 系统与算子

输入输出描述把系统看作映射 $`y=Hu`$。$`H`$ 是作用在信号上的算子，不一定是一个普通数或有限维矩阵。

- SISO：单输入、单输出，$`p=q=1`$。
- 多变量系统：输入数或输出数大于 1。

一个 SISO 系统也可以有很多状态。输入输出数量与内部状态维数是不同的概念。

### 2.2 为什么要引入“松弛”

考虑 $`\dot x=-x+u,\ y=x`$。其解为

```math
y(t)=e^{-t}x(0)+\int_0^t e^{-(t-\tau)}u(\tau)\,d\tau.
```

同一个输入，如果初态不同，输出就不同。因此在只讨论 $`u\mapsto y`$ 时，需要规定初始条件。

在标准状态模型中，取 $`x(t_0)=0`$ 是实现 $`t_0`$ 时刻松弛的常用充分条件，此时没有初态引起的响应。一般输入输出意义上的松弛强调过去对未来输出没有残留影响；若有不可观测内部状态，仅由输出不能反推出所有内部状态都为零。

对纯延迟 $`y(t)=u(t-1)`$，未来输出还需要过去一秒的输入历史。这说明系统的“记忆”未必是几个数。

### 2.3 线性：可加性与齐次性缺一不可

```math
\boxed{H(\alpha u_1+\beta u_2)=\alpha Hu_1+\beta Hu_2}.
```

一个快速必要检查是 $`H0=0`$，但只满足这一点不够。

| 系统 | 线性？ | 原因 |
|---|---|---|
| $`y=3u`$ | 是 | 满足叠加 |
| $`y=tu`$ | 是 | 时间系数不破坏叠加 |
| $`y=u^2`$ | 否 | $`(u_1+u_2)^2`$ 有交叉项 |
| $`y=u+1`$ | 否 | 零输入输出不为零 |
| $`\dot x=-x+u,\ x(0)=0,\ y=x`$ | 是 | 零状态响应对输入线性 |

**非零初态的细节：** 固定 $`x(0)\ne0`$ 时，$`u\mapsto y`$ 通常是仿射映射；但 $`(x(0),u)\mapsto(x,y)`$ 仍是线性的。因此这个状态空间模型仍称为线性系统。

### 2.4 因果性：现在不依赖未来输入

系统因果，是指 $`t`$ 时刻输出只依赖 $`t`$ 及以前的输入。

- $`y(t)=u(t-1)`$：因果。
- $`y(t)=u(t)`$：因果。
- $`y(t)=u(t+1)`$：非因果。

若 $`P_T`$ 表示保留 $`t\le T`$ 信号、截去其后的截断算子，则因果性也可写成

```math
P_TH=P_THP_T.
```

对脉冲响应核而言，因果性意味着 $`g(t,\tau)=0`$ 当 $`t<\tau`$：冲击尚未发生，响应不能先出现。

### 2.5 时不变性：整体延迟不改变规律

定义延迟算子 $`Q_\alpha u(t)=u(t-\alpha)`$。时不变性为

```math
HQ_\alpha=Q_\alpha H.
```

检验时，要分别计算“先延迟输入再通过系统”与“先通过系统再延迟输出”。例如 $`Hu(t)=tu(t)`$：

```math
H(Q_\alpha u)(t)=tu(t-\alpha),
```

```math
Q_\alpha(Hu)(t)=(t-\alpha)u(t-\alpha).
```

二者不等，所以它线性但时变。

对固定零初态起始时刻的模型，讨论延迟还需相应处理起始时刻或信号的零延拓，不能把初始条件的改变误判为系统规律的改变。

### 2.6 从脉冲响应到卷积

一般线性系统的响应核依赖两个时刻：

```math
y(t)=\int_{-\infty}^{\infty}g(t,\tau)u(\tau)\,d\tau.
```

$`\tau`$ 是施加冲击的时刻，$`t`$ 是观测时刻。若系统因果且在 $`t_0`$ 松弛，积分改为 $`\int_{t_0}^t`$。

时不变意味着核只依赖间隔 $`t-\tau`$：

```math
\boxed{y(t)=\int_{t_0}^t g(t-\tau)u(\tau)\,d\tau}.
```

对多输入多输出系统，$`g`$ 换成 $`q\times p`$ 的矩阵。其第 $`(i,j)`$ 个元素表示第 $`j`$ 个输入端施加单位冲击后，第 $`i`$ 个输出端的响应。

若有直接通道 $`D`$，最好把输出写成“普通积分 $`+Du(t)`$”，避免在积分端点对脉冲作不必要的普通函数解释。

### 2.7 传递函数

在线性时不变、零初态条件下，卷积经 Laplace 变换后得到

```math
\boxed{Y(s)=G(s)U(s)}.
```

**例：** $`\ddot y+3\dot y+2y=u`$，零初态时

```math
G(s)=\frac1{s^2+3s+2}=\frac1{s+1}-\frac1{s+2},
```

所以 $`g(t)=e^{-t}-e^{-2t}`$（$`t\ge0`$）。

**纯延迟补充：** $`y(t)=u(t-\alpha)`$、$`\alpha>0`$ 的传递函数是 $`e^{-\alpha s}`$。若冲击本身还在 $`\tau`$ 时刻才施加，输出变换为 $`e^{-(\tau+\alpha)s}`$；后者包含输入的延迟因子，不应与系统传递函数混淆。

**课件定位：** 第 1 讲第 21—39 页；第 2 讲第 2—33 页。

## 3. 状态空间：把系统的记忆写成变量

### 3.1 状态究竟是什么

在 $`t_0`$ 给出状态 $`x(t_0)`$，再给出此后的输入，就能唯一确定此后的状态和输出。状态是对过去影响的概括。

以小车为例，只有位置不够：同一位置可能向左运动，也可能向右运动。位置和速度一起才能预测接下来的运动。

常见选法包括电容电压、电感电流、物体位移和速度。状态坐标不唯一，也不一定直接可测。

在无额外代数约束的常见集中参数模型中，独立储能变量通常提供状态；不能机械地把所有储能元件数量当作状态维数。状态空间模型还可能为输入输出关系引入冗余状态，最小性要在后面另外检查。

### 3.2 从二阶方程建立状态模型

考虑

```math
\ddot y+3\dot y+2y=u.
```

取 $`x_1=y,\ x_2=\dot y`$，则

```math
\dot x_1=x_2,\qquad \dot x_2=-2x_1-3x_2+u.
```

因此

```math
A=\begin{bmatrix}0&1\\-2&-3\end{bmatrix},\quad
B=\begin{bmatrix}0\\1\end{bmatrix},\quad
C=\begin{bmatrix}1&0\end{bmatrix},\quad D=0.
```

读矩阵时，先按行还原微分方程，再按列理解变量怎样影响其他状态。

### 3.3 从物理规律建立状态模型：串联 RLC 电路

输入为电压 $`u`$，输出为电容电压 $`v_C`$，取 $`x_1=v_C,x_2=i`$。由

```math
C_{\rm cap}\dot v_C=i,\qquad L\dot i=u-Ri-v_C
```

得到

```math
A=\begin{bmatrix}0&1/C_{\rm cap}\\-1/L&-R/L\end{bmatrix},\quad
B=\begin{bmatrix}0\\1/L\end{bmatrix},\quad C=[1\ 0].
```

课件例子 $`R=3,L=1,C_{\rm cap}=0.5`$ 对应

```math
A=\begin{bmatrix}0&2\\-1&-3\end{bmatrix},\quad
G(s)=\frac2{s^2+3s+2}.
```

这里 $`i=C_{\rm cap}\dot y`$，所以 $`\dot y`$ 与电流成比例；若直接选 $`\dot y`$ 为第二状态，也完全可以，只是矩阵随坐标变化。

### 3.4 更高阶方程及输入导数的陷阱

对

```math
y^{(n)}+a_1y^{(n-1)}+\cdots+a_ny=u,
```

取 $`x=(y,\dot y,\dots,y^{(n-1)})^T`$，得到上方为移位结构、最后一行为 $`[-a_n,\dots,-a_1]`$ 的状态矩阵。

如果右端含 $`\dot u,\ddot u`$，直接这样选状态会让状态方程里出现输入导数，未必符合 $`\dot x=Ax+Bu`$ 的标准形式。通常应通过传递函数实现重新选取内部变量，而不是随意把输入导数当成独立输入。

### 3.5 有限维与无限维

纯延迟系统需要保存一段输入历史；一般不能用有限个实数完整表示其状态。后面讨论的 $`(A,B,C,D)`$ 实现，特指有限维普通状态空间实现。

**本章自检：** 为什么一个只有一个输入、一个输出的弹簧质量系统，仍可能需要两个状态？答：因为位移与速度都是决定未来运动所需的信息。

**课件定位：** 第 3 讲第 7—24 页。

## 4. 系统的解：矩阵指数与状态转移矩阵

### 4.1 为什么需要矩阵指数

标量方程 $`\dot x=ax`$ 的解是 $`e^{at}x_0`$。对于向量方程 $`\dot x=Ax`$，相应的对象是

```math
\boxed{e^{At}=I+At+\frac{A^2t^2}{2!}+\cdots}.
```

矩阵指数不是对每个元素分别取指数。例如 $`A=0`$ 时，$`e^{At}=I`$，而不是全 1 矩阵。

常数矩阵 $`A`$ 满足

```math
e^{A0}=I,\quad \frac{d}{dt}e^{At}=Ae^{At}=e^{At}A,
```

```math
e^{At}e^{A\tau}=e^{A(t+\tau)},\qquad (e^{At})^{-1}=e^{-At}.
```

特别地，**即使 $`A`$ 不可逆，$`e^{At}`$ 也总可逆。**

对两个不同矩阵，$`e^{(A+B)t}=e^{At}e^{Bt}`$ 一般不成立；$`AB=BA`$ 是保证它成立的常用充分条件。

### 4.2 矩阵指数的四种计算方法

**方法一：利用幂零性。** 若

```math
A=\begin{bmatrix}0&1\\0&0\end{bmatrix},\quad A^2=0,
```

则级数直接截断：

```math
\boxed{e^{At}=I+tA=\begin{bmatrix}1&t\\0&1\end{bmatrix}}.
```

**方法二：对角化或 Jordan 分解。** 若 $`A=TJT^{-1}`$，则

```math
e^{At}=Te^{Jt}T^{-1}.
```

例如 $`J=\begin{bmatrix}-1&1\\0&-1\end{bmatrix}`$，则

```math
e^{Jt}=e^{-t}\begin{bmatrix}1&t\\0&1\end{bmatrix}.
```

**方法三：预解矩阵。** 在相应的收敛半平面中，

```math
\boxed{\mathcal L\{e^{At}\}=(sI-A)^{-1}}.
```

先求逆矩阵，再对每个元素作 Laplace 反变换，适合低阶题。

**方法四：Cayley–Hamilton 降幂。** 将矩阵指数写为

```math
e^{At}=\alpha_0(t)I+\cdots+\alpha_{n-1}(t)A^{n-1}.
```

若两个特征值 $`\lambda_1\ne\lambda_2`$，二维情形有

```math
e^{At}=\frac{A-\lambda_2I}{\lambda_1-\lambda_2}e^{\lambda_1t}
+\frac{A-\lambda_1I}{\lambda_2-\lambda_1}e^{\lambda_2t}.
```

### 4.3 完整例题：二阶系统的矩阵指数

对 $`A=\begin{bmatrix}0&1\\-2&-3\end{bmatrix}`$，特征值为 $`-1,-2`$，所以

```math
e^{At}=(A+2I)e^{-t}-(A+I)e^{-2t}
```

```math
=\begin{bmatrix}
2e^{-t}-e^{-2t}&e^{-t}-e^{-2t}\\
-2e^{-t}+2e^{-2t}&-e^{-t}+2e^{-2t}
\end{bmatrix}.
```

用两个检查防止算错：

1. 代入 $`t=0`$ 应得到 $`I`$。
2. 求导后应满足 $`\frac{d}{dt}e^{At}=Ae^{At}`$。

这比只对照某一个元素可靠。

### 4.4 LTI 系统的完整解与推导

LTI 指线性时不变，即 $`A,B,C,D`$ 均为常量矩阵。

由乘积求导，

```math
\frac{d}{dt}\left(e^{-At}x(t)\right)=e^{-At}Bu(t).
```

从 $`t_0`$ 积分到 $`t`$，再左乘 $`e^{At}`$，得到

```math
\boxed{x(t)=e^{A(t-t_0)}x_0+
\int_{t_0}^t e^{A(t-\tau)}Bu(\tau)\,d\tau}.
```

输出为

```math
\boxed{y(t)=Ce^{A(t-t_0)}x_0+
\int_{t_0}^t Ce^{A(t-\tau)}Bu(\tau)\,d\tau+Du(t)}.
```

- **零输入响应：** 输入取零，保留初态影响。
- **零状态响应：** 初态取零，保留输入影响。
- **完整响应：** 两者相加。

“零输入”不等于“状态为零”；“零状态”也不等于“输出始终为零”。

**例：** 上一节的二阶系统取 $`x_0=0,u(t)=1`$，则

```math
y(t)=\int_0^t(e^{-r}-e^{-2r})\,dr
=\frac12-e^{-t}+\frac12e^{-2t}.
```

检查 $`y(0)=0`$，稳态值为 $`1/2`$，也与常值平衡关系 $`2y=u`$ 相符。

### 4.5 时变系统：基本解矩阵

对 $`\dot x=A(t)x`$，取 $`n`$ 个线性无关的解作为列，构成

```math
\Psi(t)=[\psi_1(t)\ \cdots\ \psi_n(t)].
```

它满足 $`\dot\Psi(t)=A(t)\Psi(t)`$，并且在讨论区间内可逆。任意解可写成 $`x(t)=\Psi(t)c`$。

**为什么一直可逆？** 如果某时刻列向量相关，就有非零常数 $`c`$ 使 $`\Psi(t)c`$ 在该时刻为零。由齐次微分方程解的唯一性，这个解在整个区间都为零，违背所选解的独立性。

不同基本解矩阵只相差右侧一个可逆常量矩阵：$`\Psi_2(t)=\Psi_1(t)R`$。

### 4.6 状态转移矩阵

定义

```math
\boxed{\Phi(t,t_0)=\Psi(t)\Psi(t_0)^{-1}}.
```

它不依赖具体选择哪一个基本解矩阵，且满足

```math
\Phi(t_0,t_0)=I,
```

```math
\Phi(t_2,t_0)=\Phi(t_2,t_1)\Phi(t_1,t_0),
```

```math
\Phi(t,t_0)^{-1}=\Phi(t_0,t),
```

```math
\frac{\partial\Phi(t,t_0)}{\partial t}=A(t)\Phi(t,t_0),\qquad
\frac{\partial\Phi(t,t_0)}{\partial t_0}=-\Phi(t,t_0)A(t_0).
```

前一个时间是“到哪里”，后一个时间是“从哪里”。这能帮助记住乘法顺序。

LTI 是其特例：$`\Phi(t,t_0)=e^{A(t-t_0)}`$。

### 4.7 时变系统的完整解

令 $`x(t)=\Phi(t,t_0)\xi(t)`$，代入微分方程并消去齐次项，得到变常数公式：

```math
\boxed{x(t)=\Phi(t,t_0)x_0+
\int_{t_0}^t\Phi(t,\tau)B(\tau)u(\tau)\,d\tau}.
```

相应输出为

```math
y(t)=C(t)\Phi(t,t_0)x_0+
\int_{t_0}^t C(t)\Phi(t,\tau)B(\tau)u(\tau)\,d\tau+D(t)u(t).
```

**不能普遍使用** $`\Phi(t,t_0)=\exp(\int_{t_0}^tA(\tau)\,d\tau)`$。一个常用充分条件是不同时间的矩阵两两交换：$`A(t_1)A(t_2)=A(t_2)A(t_1)`$。

对角时变矩阵满足这一条件。例如 $`A(t)=\operatorname{diag}(t,-1)`$ 时，

```math
\Phi(t,t_0)=\operatorname{diag}\left(e^{(t^2-t_0^2)/2},e^{-(t-t_0)}\right).
```

**课件定位：** 第 3 讲第 24—33 页；第 4 讲第 2—22 页。

## 5. 两种描述的关系与实现

### 5.1 从状态方程求传递函数

令 $`t_0=0`$，Laplace 变换得到

```math
sX-x_0=AX+BU,
```

```math
X=(sI-A)^{-1}x_0+(sI-A)^{-1}BU.
```

代入输出方程：

```math
Y=C(sI-A)^{-1}x_0+
\underbrace{[C(sI-A)^{-1}B+D]}_{G(s)}U.
```

所以

```math
\boxed{G(s)=C(sI-A)^{-1}B+D}.
```

这个式子表示零状态输入输出关系。非零初态时，不能直接把全部输出写成 $`Y=GU`$。

对应的因果脉冲响应为

```math
g(t)=Ce^{At}B\,\mathbf1_{t\ge0}+D\delta(t).
```

**计算技巧：** 只需要 $`(sI-A)^{-1}B`$ 时，可以解 $`(sI-A)X=B`$，不必先求整个逆矩阵。

### 5.2 坐标变换不改变传递函数

若 $`z=Px`$，其中 $`P`$ 为可逆常量矩阵，则

```math
\boxed{\bar A=PAP^{-1},\quad \bar B=PB,\quad
\bar C=CP^{-1},\quad\bar D=D}.
```

利用

```math
(sI-PAP^{-1})^{-1}=P(sI-A)^{-1}P^{-1},
```

代入即可验证 $`\bar G(s)=G(s)`$。这种关系称为代数等价。

若 $`P=P(t)`$ 随时间变化，必须额外求导：

```math
\boxed{\bar A=(\dot P+PA)P^{-1},\quad
\bar B=PB,\quad\bar C=CP^{-1},\quad\bar D=D}.
```

状态转移矩阵变为

```math
\bar\Phi(t,t_0)=P(t)\Phi(t,t_0)P(t_0)^{-1}.
```

### 5.3 零状态等价比代数等价弱

两个系统传递函数相同，称为零状态等价。它们的状态维数可能不同，也可能具有不同的隐藏内部动态。

例如一维系统

```math
\dot x=-x+u,\quad y=x
```

与二维系统

```math
\begin{bmatrix}\dot z_1\\\dot z_2\end{bmatrix}
=\begin{bmatrix}-1&0\\0&2\end{bmatrix}
\begin{bmatrix}z_1\\z_2\end{bmatrix}+
\begin{bmatrix}1\\0\end{bmatrix}u,\qquad y=z_1
```

都有 $`G(s)=1/(s+1)`$。但第二个系统还有 $`z_2(t)=e^{2t}z_2(0)`$，输入与输出都不反映它。

因此，传递函数不能普遍反映全部内部行为；两个同维、同传递函数的非最小系统也不一定代数等价。

### 5.4 正则、严格正则与有限维实现

为避免课件不同位置用语宽窄不一致，本讲义采用以下清晰约定：

- **真有理（proper，广义“正则”）：** 每个有理函数元素的分子次数不高于分母次数，$`G(\infty)`$ 有限。
- **严格真有理（strictly proper，严格正则）：** 每个元素在无穷远趋于零，$`G(\infty)=0`$。
- 真有理而非严格真有理时，$`D=G(\infty)\ne0`$。

```math
\boxed{G(s)\text{ 存在有限维普通 LTI 实现}
\iff G(s)\text{ 是真有理矩阵}}.
```

必要性来自 $`(sI-A)^{-1}=\operatorname{adj}(sI-A)/\det(sI-A)`$ 且在无穷远趋零；充分性可以通过伴随矩阵构造证明。

| $`G(s)`$ | 是否有这种有限维实现 | 理由 |
|---|---|---|
| $`1/(s+1)`$ | 有 | 严格真有理 |
| $`(s+2)/(s+1)`$ | 有 | $`D=1`$，剩余项为 $`1/(s+1)`$ |
| $`s`$ | 没有 | 非真有理，理想微分不属于此普通模型 |
| $`e^{-s}`$ | 没有精确实现 | 非有理，纯延迟需要无限维记忆 |

这里没有讨论含代数约束的描述系统，也没有说纯延迟不能做有限维近似。

### 5.5 用伴随结构构造一个实现

先把 SISO 真有理函数拆为

```math
G(s)=d+\frac{b_0+b_1s+\cdots+b_{n-1}s^{n-1}}
{s^n+a_1s^{n-1}+\cdots+a_n}.
```

取

```math
A_c=\begin{bmatrix}
0&1&0&\cdots&0\\
0&0&1&\cdots&0\\
\vdots&&&\ddots&\vdots\\
0&0&0&\cdots&1\\
-a_n&-a_{n-1}&-a_{n-2}&\cdots&-a_1
\end{bmatrix},\quad B_c=e_n,
```

```math
C_c=[b_0\ b_1\ \cdots\ b_{n-1}],\qquad D=d.
```

因为

```math
(sI-A_c)^{-1}B_c=\frac{[1\ s\ \cdots\ s^{n-1}]^T}{\Delta(s)},
```

代入即可验证传递函数。**输出系数按常数项到高次项排列。** 若分子分母尚有公因子，构造出来的系统可能不是最小的。

**例：**

```math
G(s)=\frac{2s+3}{s^2+3s+2}
```

可取 $`A_c=\begin{bmatrix}0&1\\-2&-3\end{bmatrix}, B_c=(0,1)^T,C_c=[3\ 2],D=0`$。

多变量时，将严格真有理部分的各元素统一到首一公分母 $`g(s)`$，设其次数为 $`r`$：

```math
G(s)=D+\frac{G_0+G_1s+\cdots+G_{r-1}s^{r-1}}{g(s)},
```

其中 $`G_i\in\mathbb R^{q\times p}`$。把上面的标量移位结构换成 $`p\times p`$ 单位块，令

```math
A=\begin{bmatrix}
0&I_p&&0\\
&&\ddots&\\
0&&0&I_p\\
-g_0I_p&-g_1I_p&\cdots&-g_{r-1}I_p
\end{bmatrix},\quad
B=\begin{bmatrix}0\\\vdots\\0\\I_p\end{bmatrix},\quad
C=[G_0\ G_1\ \cdots\ G_{r-1}].
```

其中 $`g(s)=s^r+g_{r-1}s^{r-1}+\cdots+g_0`$。这给出 $`rp`$ 维实现，保证存在，但不保证最小。

### 5.6 时变核的可实现性：为什么出现有限项分离

先分离直接通道。若因果核的普通部分能写成

```math
g(t,\tau)=M(t)N(\tau),\qquad t\ge\tau,
```

其中 $`M(t)`$ 为 $`q\times n`$、$`N(\tau)`$ 为 $`n\times p`$，且满足课件所需连续性条件，则可构造

```math
\dot x=N(t)u,\qquad y=M(t)x+D(t)u.
```

零初态下 $`x(t)=\int_{t_0}^tN(\tau)u(\tau)d\tau`$，代回即得原核。

反过来，已有实现的普通核为

```math
C(t)\Phi(t,\tau)B(\tau)
=\underbrace{C(t)\Psi(t)}_{M(t)}
\underbrace{\Psi(\tau)^{-1}B(\tau)}_{N(\tau)}.
```

所以有限维实现与这样的有限维分离形式联系起来。该构造允许时变矩阵，即使原输入输出规律时不变，也未必直接得到常系数实现。

### 5.7 多变量传递矩阵的秩、极点与零点

这一节对应第 2、3 讲的难点，初读可先理解计算规则。

**正常秩** $`r`$ 是 $`G(s)`$ 在有理函数域上的秩，也等于避开特殊点时的最大数值秩；不是任意选一个 $`s`$ 代入后的秩。

**$`k`$ 阶子式** 是任选 $`k`$ 行、$`k`$ 列所得子矩阵的行列式。

按课件定义：

1. 求所有不恒为零的各阶子式，并分别约分。
2. 取这些既约分母的首一最小公倍式，得到极点多项式 $`p_G(s)`$。
3. 对所有不恒为零的 $`r`$ 阶子式，把分母统一成 $`p_G(s)`$。
4. 取这些分子的首一最大公因式，得到零点多项式 $`z_G(s)`$。

最小公倍式对每个因子取最大次数；最大公因式取共同因子的最小次数。“首一”表示最高次系数为 1。

不能只看每个元素分母，也不能只看 $`\det G`$：矩阵可能非方阵，或者行列式恒为零。

**课件例子重算：**

```math
G(s)=\begin{bmatrix}
\dfrac1{s+1}&0&\dfrac{s-1}{(s+1)(s+2)}\\[4pt]
-\dfrac1{s-1}&\dfrac1{s+2}&\dfrac1{s+2}
\end{bmatrix}.
```

三个二阶子式（按列组 $`12,13,23`$）为

```math
\frac1{(s+1)(s+2)},\quad
\frac2{(s+1)(s+2)},\quad
-\frac{s-1}{(s+1)(s+2)^2}.
```

一阶子式的分母还含 $`s-1`$，所以

```math
p_G(s)=(s+1)(s-1)(s+2)^2.
```

把三个二阶子式的分母统一后，分子依次为

```math
(s-1)(s+2),\quad 2(s-1)(s+2),\quad -(s-1)^2.
```

故 $`z_G(s)=s-1`$。本例中 $`s=1`$ 同时出现为零点和极点，这在多变量系统中可以发生，不能直接套用约分后 SISO 分子分母互素的直觉。

**另一个重要例子：**

```math
G_1(s)=\frac1{s+1}\begin{bmatrix}1&1\\1&1\end{bmatrix},\qquad
G_2(s)=\frac1{s+1}\begin{bmatrix}1.0001&1\\1&1\end{bmatrix}.
```

$`G_1`$ 正常秩为 1，极点多项式为 $`s+1`$。$`G_2`$ 的二阶子式为 $`0.0001/(s+1)^2`$，所以极点多项式为 $`(s+1)^2`$。精确代数秩与“数值上几乎相关”必须分开看。

### 5.8 左右矩阵分式：矩阵除法有方向

课件写法为

```math
G(s)=D_L(s)^{-1}N_L(s)=N_R(s)D_R(s)^{-1}.
```

这里 $`D_L,D_R`$ 是多项式分母矩阵，与状态空间中的直接通道 $`D`$ 不同。

上例可直接用行公分母构造

```math
D_L=\operatorname{diag}((s+1)(s+2),(s-1)(s+2)),
```

```math
N_L=\begin{bmatrix}s+2&0&s-1\\-(s+2)&s-1&s-1\end{bmatrix}.
```

也可按列公分母构造

```math
D_R=\operatorname{diag}((s+1)(s-1),s+2,(s+1)(s+2)),
```

```math
N_R=\begin{bmatrix}s-1&0&s-1\\-(s+1)&1&s+1\end{bmatrix}.
```

这样的简单构造不自动保证互素。只有满足相应左、右互素条件后，才能直接用分母行列式识别极点多项式。上例的左分式为既约形式；右分式仅展示了“存在一种分式写法”。

**课件定位：** 第 2 讲第 34—41 页；第 3 讲第 2—6、23—29 页；第 4 讲第 23—47 页；第 5 讲第 2—6 页。

## 6. 可控性：输入能把状态推到哪里

### 6.1 定义及三个关键词

课件的定义是：对任意初态 $`x(t_0)`$，存在有限时刻 $`t_1>t_0`$ 和容许输入，使 $`x(t_1)=0`$，称系统在 $`t_0`$ 可控。

三个关键词是 **任意初态、有限时间、存在输入**。通常假设输入为分段连续等容许信号，且没有幅值约束。

如果要求 $`|u|\le1`$、限定能耗，或者限定状态始终在某个集合内，就已经是带约束的另一个问题，不能只凭秩满就保证所有要求。

可控性取决于 $`(A,B)`$，与测量矩阵 $`C`$ 无关。

**反例：** $`\dot x_1=-x_1+u,\dot x_2=-x_2`$。虽然 $`x_2`$ 会趋于零，但若 $`x_2(0)\ne0`$，有限时间内 $`x_2(t)=e^{-t}x_2(0)`$ 仍不为零。因此不可控；渐近衰减不等于有限时间可控。

### 6.2 可达与可控：要看时间区间

课件把“在 $`t_0`$ 可达”定义为：存在过去的 $`t_1<t_0`$，能够从 $`x(t_1)=0`$ 达到任意 $`x(t_0)`$。

- 在 $`t_0`$ 可控：使用未来的 $`[t_0,t_1]`$。
- 在 $`t_0`$ 可达：使用过去的 $`[t_1,t_0]`$。

对于 LTI 连续时间系统，两者等价。对一般时变系统，以同一个 $`t_0`$ 为参照时不能直接等同，因为它们使用的时间段不同。

在**同一个固定区间** $`[a,b]`$ 内，连续时间状态转移矩阵可逆，因此“任意初态可控到零”和“从零可达到任意终态”的完全性等价。

### 6.3 从状态解推导一般判据

由 $`x(t_1)=0`$，左乘 $`\Phi(t_0,t_1)`$ 得

```math
0=x_0+\int_{t_0}^{t_1}\Phi(t_0,\tau)B(\tau)u(\tau)\,d\tau.
```

令 $`F(\tau)=\Phi(t_0,\tau)B(\tau)`$。要能抵消任意 $`x_0`$，这些输入作用方向随时间的组合必须覆盖整个状态空间。

定义课件形式的可控 Gram 矩阵

```math
\boxed{W_c(t_0,t_1)=\int_{t_0}^{t_1}
\Phi(t_0,\tau)B(\tau)B(\tau)^T\Phi(t_0,\tau)^T\,d\tau}.
```

则以下三条等价：

1. 系统在该区间上完全可控。
2. $`F(\tau)`$ 的 $`n`$ 个行函数在该区间线性无关。
3. $`W_c\succ0`$，等价于 $`W_c`$ 非奇异。

为什么不满秩就不行？若存在 $`v\ne0`$ 使 $`v^TF(\tau)\equiv0`$，则任意输入产生的状态变化都无法覆盖 $`v`$ 所检测到的那个方向。

### 6.4 Gram 判据还能直接构造控制

若 $`W_c`$ 可逆，取

```math
\boxed{u(\tau)=-B(\tau)^T\Phi(t_0,\tau)^TW_c^{-1}x_0}.
```

代入积分有

```math
\int_{t_0}^{t_1}F(\tau)u(\tau)d\tau=-W_cW_c^{-1}x_0=-x_0,
```

因此确实把初态送到零。这也说明可控性定理不只是判断，还提供了存在性的具体证明。

另一种常见定义把各时刻作用统一搬到终点：

```math
W_r=\int_{t_0}^{t_1}\Phi(t_1,\tau)B(\tau)B(\tau)^T\Phi(t_1,\tau)^T\,d\tau.
```

两者满足

```math
W_r=\Phi(t_1,t_0)W_c\Phi(t_1,t_0)^T,
```

所以同时可逆，但数值一般不同。不要把一套 Gram 矩阵与另一套控制公式拼接使用。

**补充：任意端点控制。** 令 $`d=x_1-\Phi(t_1,t_0)x_0`$，则

```math
u(\tau)=B(\tau)^T\Phi(t_1,\tau)^TW_r^{-1}d
```

把 $`x_0`$ 送到 $`x_1`$。在平方可积输入、无约束条件下，它还最小化 $`\int u^Tu\,dt`$，最小值为 $`d^TW_r^{-1}d`$。

要理解最小性，设另一个可行输入为 $`u+v`$，则 $`\int\Phi(t_1,\tau)B(\tau)v(\tau)d\tau=0`$，所以 $`\int u^Tv=0`$，能量增加量恰为 $`\int v^Tv\ge0`$。

### 6.5 LTI 系统的 Kalman 秩判据

定义

```math
\boxed{\mathcal C=[B\ AB\ A^2B\ \cdots\ A^{n-1}B]}.
```

则

```math
\boxed{(A,B)\text{ 可控}\iff\operatorname{rank}\mathcal C=n}.
```

直觉是：$`B`$ 给出输入直接作用的方向，$`AB`$ 给出经内部动态传播一次后的方向，$`A^2B`$ 再传播一次。要判断这些方向总共能覆盖多少维。

证明的关键不是“离散地过了一步”，而是 $`e^{At}B`$ 的展开包含这些矩阵幂，Cayley–Hamilton 定理又把所有高次幂归入前 $`n`$ 项的张成空间。

对 LTI 连续系统，若可控，则任何长度大于零的时间区间上均可控；时间越短，所需输入可能越大。这一结论依赖无幅值限制。

### 6.6 贯穿例：位置与速度组成的二重积分器

```math
A=\begin{bmatrix}0&1\\0&0\end{bmatrix},\quad
B=\begin{bmatrix}0\\1\end{bmatrix},\quad C=[1\ 0].
```

这里 $`\dot x_1=x_2,\dot x_2=u`$，输入是加速度。虽然 $`B`$ 第一行为零，输入仍通过速度间接改变位置。

```math
AB=\begin{bmatrix}1\\0\end{bmatrix},\quad
\mathcal C=\begin{bmatrix}0&1\\1&0\end{bmatrix},\quad\det\mathcal C=-1.
```

因此系统可控。

在 $`[0,T]`$ 上，

```math
e^{A(T-\tau)}B=\begin{bmatrix}T-\tau\\1\end{bmatrix},
```

```math
W_r=\begin{bmatrix}T^3/3&T^2/2\\T^2/2&T\end{bmatrix},\qquad
\det W_r=T^4/12>0.
```

**实际构造：** 用 1 秒把 $`x(0)=(1,0)^T`$ 送到零。此时

```math
d=(-1,0)^T,\quad W_r^{-1}=\begin{bmatrix}12&-6\\-6&4\end{bmatrix},
```

得到 $`u(t)=12t-6`$。积分可验证

```math
x_2(t)=6t^2-6t,\qquad x_1(t)=1+2t^3-3t^2,
```

所以 $`x(1)=0`$。这把“秩满”的抽象结论变成了一条具体输入。

### 6.7 算到什么时候可以停止

令 $`\mathcal C_k=[B\ AB\ \cdots\ A^{k-1}B]`$。

若某次加入完整新块后秩不再增加，即

```math
\operatorname{rank}\mathcal C_{k+1}=\operatorname{rank}\mathcal C_k,
```

则以后也不再增加。因为新块 $`A^kB`$ 已在已有空间内，再乘 $`A`$ 也仍落在这个空间内。

若系统可控，定义最小的 $`\nu_c`$ 使 $`\operatorname{rank}\mathcal C_{\nu_c}=n`$，称为这里采用的可控性指数。若 $`r_B=\operatorname{rank}B`$、最小多项式次数为 $`d`$，则

```math
\nu_c\le\min(n-r_B+1,d).
```

课件把从 $`U_0=B`$ 开始的下标与指数同时使用，阅读时要注意差 1；本文始终按矩阵块数量计数。

### 6.8 时变系统的微分充分判据

为避免显式求 $`\Phi`$，定义

```math
M_0=B,\qquad M_{k+1}=\dot M_k-AM_k.
```

因为

```math
\frac{d}{dt}[\Phi(t_0,t)M_k(t)]
=\Phi(t_0,t)M_{k+1}(t),
```

若在未来区间某点 $`t_*`$ 有

```math
\operatorname{rank}[M_0(t_*)\ M_1(t_*)\ \cdots\ M_{n-1}(t_*)]=n,
```

在相应可微条件下，即可推出区间上的可控性。

**一般时变情况下，它只是充分条件。** 某点不满秩不能直接宣判不可控。常量情形 $`M_k=(-A)^kB`$ 才回到等价的 Kalman 秩判据。

**反例说明不必要性：** 在 $`[-1,1]`$ 上取 $`A=0,B(t)=(t^3,|t|^3)^T`$。两个分量函数在整个区间线性无关，所以区间可控；但 $`[B(t),\dot B(t)]`$ 在每个点的秩都小于 2。

**不能逐点“冻结”判断：** 取

```math
A=\operatorname{diag}(-1,-2),\quad B(t)=(e^{-t},e^{-2t})^T.
```

每个冻结的 $`[B(t),AB(t)]`$ 都满秩，但

```math
\Phi(t_0,t)B(t)=(e^{-t_0},e^{-2t_0})^T
```

方向始终不变，实际时变系统不可控。时变性必须作为整体处理。

**课件定位：** 第 5 讲第 7—11、27—41 页；第 6 讲第 2—31、40—46 页；第 7 讲第 47 页。

## 7. 可观测性：输出能告诉我们多少

### 7.1 可观测不是“每个状态都装了传感器”

若知道有限时间内的输入和输出，就能唯一确定初态 $`x(t_0)`$，称系统可观测。

对二重积分器，测量只有 $`y=x_1`$。零输入下

```math
y(t)=x_1(0)+tx_2(0).
```

虽然没有直接测速度，但一段时间的位置变化反映了速度，所以两个初态都能确定。

另一个等价视角是**不可区分初态**：给两个初态施加相同输入，若输出始终相同，它们的差就无法被测量识别。可观测要求这样的初态差只能是零。

### 7.2 为什么只研究 $`(A,C)`$

完整输出为

```math
y(t)=C(t)\Phi(t,t_0)x_0+
\int_{t_0}^tC(t)\Phi(t,\tau)B(\tau)u(\tau)d\tau+D(t)u(t).
```

输入与模型已知，因此把后两项减掉，定义

```math
\tilde y(t)=y(t)-D(t)u(t)
-\int_{t_0}^tC(t)\Phi(t,\tau)B(\tau)u(\tau)d\tau.
```

于是 $`\tilde y(t)=C(t)\Phi(t,t_0)x_0`$。能否确定 $`x_0`$ 只取决于 $`(A,C)`$。

因此判别时可令 $`u=0`$；这是扣除已知输入影响后的等价分析，不是说实际系统必须停止施加输入。

### 7.3 可观 Gram 矩阵与初态恢复

定义

```math
\boxed{W_o(t_0,t_1)=\int_{t_0}^{t_1}
\Phi(t,t_0)^TC(t)^TC(t)\Phi(t,t_0)\,dt}.
```

系统在该区间可观测，当且仅当 $`W_o\succ0`$，也当且仅当 $`C(t)\Phi(t,t_0)`$ 的列函数在区间上线性无关。

两侧左乘 $`\Phi(t,t_0)^TC(t)^T`$ 再积分，得到恢复公式

```math
\boxed{x_0=W_o^{-1}\int_{t_0}^{t_1}
\Phi(t,t_0)^TC(t)^T\tilde y(t)\,dt}.
```

这是把一段输出积累起来，形成关于初态的独立方程。可观测性是无噪声数学模型下的唯一性；若 $`W_o`$ 接近奇异，实际测量误差仍可能被明显放大。

### 7.4 LTI 的可观测性矩阵

定义

```math
\boxed{\mathcal O=\begin{bmatrix}
C\\CA\\CA^2\\\vdots\\CA^{n-1}
\end{bmatrix}}.
```

则

```math
\boxed{(A,C)\text{ 可观测}\iff\operatorname{rank}\mathcal O=n}.
```

在零输入、足够光滑时，

```math
y(0)=Cx_0,\quad\dot y(0)=CAx_0,\quad y^{(k)}(0)=CA^kx_0.
```

堆叠后就是 $`\mathcal O x_0`$。这是秩判据的直观来源；实际有噪声时，直接反复求输出导数往往不适合作为估计方法。

对二重积分器：

```math
\mathcal O=\begin{bmatrix}1&0\\0&1\end{bmatrix},
```

所以只测位置仍可观。若改为只测速度 $`C=[0\ 1]`$，则

```math
\mathcal O=\begin{bmatrix}0&1\\0&0\end{bmatrix}.
```

初始位置不影响速度输出，因而不可观。

### 7.5 贯穿例：不用微分，恢复初始位置与速度

在 $`[0,T]`$ 内已减去输入贡献，$`\tilde y(t)=a+bt`$。则

```math
W_o=\begin{bmatrix}T&T^2/2\\T^2/2&T^3/3\end{bmatrix},\qquad
\det W_o=T^4/12>0.
```

取 $`T=1`$，若测得 $`\tilde y(t)=2+3t`$，有

```math
\begin{bmatrix}\int_0^1\tilde y(t)dt\\\int_0^1t\tilde y(t)dt\end{bmatrix}
=\begin{bmatrix}7/2\\2\end{bmatrix},
```

```math
\begin{bmatrix}a\\b\end{bmatrix}
=\begin{bmatrix}4&-6\\-6&12\end{bmatrix}
\begin{bmatrix}7/2\\2\end{bmatrix}
=\begin{bmatrix}2\\3\end{bmatrix}.
```

这说明一个标量输出随时间积累后，完全可能包含多个状态的信息。

### 7.6 时变微分判据、可重构性与指数

定义

```math
N_0=C,\qquad N_{k+1}=\dot N_k+N_kA.
```

若未来区间某点 $`t_*`$ 满足

```math
\operatorname{rank}\begin{bmatrix}N_0(t_*)\\N_1(t_*)\\\vdots\\N_{n-1}(t_*)\end{bmatrix}=n,
```

在相应可微条件下，可推出可观测。一般时变情形仍只是充分条件。注意与可控递推的符号区别：可控为 $`\dot M-AM`$，可观为 $`\dot N+NA`$。

**可重构**使用过去区间 $`[t_1,t_0]`$ 的输入输出来确定当前 $`x(t_0)`$；**可观测**使用未来区间 $`[t_0,t_1]`$ 来确定初态 $`x(t_0)`$。LTI 连续系统中两者等价，一般时变系统要保留时间方向。

LTI 情形，最少堆叠多少块 $`C,CA,\dots`$ 才满列秩，就是本文定义的可观测性指数 $`\nu_o`$。若 $`r_C=\operatorname{rank}C`$，则

```math
\nu_o\le\min(n-r_C+1,d).
```

连续加入一整块后秩停止增长，后续也不会恢复增长。

### 7.7 对偶：把可控结论转成可观结论

对常系数系统，

```math
\boxed{(A,B)\text{ 可控}\iff(A^T,B^T)\text{ 可观测}},
```

```math
\boxed{(A,C)\text{ 可观测}\iff(A^T,C^T)\text{ 可控}}.
```

右侧矩阵对按相应角色理解：例如 $`(A^T,C^T)`$ 中 $`C^T`$ 是输入矩阵。

理由直接来自

```math
[B\ AB\ \cdots]^T=
\begin{bmatrix}B^T\\B^TA^T\\\vdots\end{bmatrix}.
```

**与课件时变对偶的区别：** 第 7 讲用

```math
\dot z=-A(t)^Tz+C(t)^Tv,\qquad
\gamma=B(t)^Tz+D(t)^Tv
```

定义时变对偶系统，负号使其转移矩阵等于原系统转移矩阵的逆转置，从而对应课件的同一时间方向定义。常系数秩判据中，$`A^T`$ 换成 $`-A^T`$ 只使各矩阵幂交替变号，不改变秩；所以常见的 LTI 对偶表述不必带负号。

**课件定位：** 第 7 讲第 3—31 页。

## 8. PBH、模态与 Jordan 形判据

### 8.1 PBH 判据的形式

可控性：

```math
\boxed{\operatorname{rank}[\lambda I-A\ \ B]=n,
\quad\forall\lambda\in\sigma(A)}.
```

可观测性：

```math
\boxed{\operatorname{rank}\begin{bmatrix}\lambda I-A\\C\end{bmatrix}=n,
\quad\forall\lambda\in\sigma(A)}.
```

$`\sigma(A)`$ 表示 $`A`$ 的特征值集合。也可要求对所有复数 $`\lambda`$ 成立，但非特征值处 $`\lambda I-A`$ 已可逆，所以只需检验特征值。

这是两个矩形矩阵的**秩**判据，不要给它们直接写行列式。

### 8.2 左特征向量解释可控，右特征向量解释可观

若存在非零行向量 $`w^*`$ 使

```math
w^*A=\lambda w^*,\qquad w^*B=0,
```

则

```math
\frac{d}{dt}(w^*x)=\lambda w^*x.
```

这一状态组合完全不受输入影响，所以系统不可控。这就是可控 PBH 的等价形式。

若存在右特征向量 $`v\ne0`$ 使

```math
Av=\lambda v,\qquad Cv=0,
```

从 $`x_0=v`$ 出发，零输入输出为 $`Ce^{At}v=e^{\lambda t}Cv=0`$，故不可观。

**记忆法：** 输入矩阵 $`B`$ 在右侧，检查左特征向量能否把它消掉；输出矩阵 $`C`$ 在左侧，检查右特征向量能否被它消掉。

### 8.3 一个完整 PBH 例子

设

```math
A=\begin{bmatrix}0&1\\0&0\end{bmatrix},\quad
B=\begin{bmatrix}0\\1\end{bmatrix},\quad C=[1\ 0].
```

唯一特征值为 $`0`$，

```math
[-A\ B]=\begin{bmatrix}0&-1&0\\0&0&1\end{bmatrix},
```

```math
\begin{bmatrix}-A\\C\end{bmatrix}
=\begin{bmatrix}0&-1\\0&0\\1&0\end{bmatrix}.
```

二者秩都是 2，故可控且可观。与前面 Kalman 判据一致。

### 8.4 模态、重根与“隐藏”

课件把 $`A`$ 的特征值称为模态，对应运动可能包含 $`t^ke^{\lambda t}`$。

- 不可控模态又称输入解耦零点。
- 不可观测模态又称输出解耦零点。

它们是某个状态实现的结构性质，不能不加区分地等同于传递函数矩阵的零点。

若 $`\lambda`$ 是重特征值，PBH 在它处降秩，只能说明至少存在该特征值的不可控或不可观方向；**不能把所有同值模态都判为隐藏，也不能只由一次 PBH 秩亏确定隐藏状态的总数。**

例如 $`J=\lambda I+N`$ 为 4 阶单个上 Jordan 块。对 $`B=e_3,e_2,e_1`$，三个 $`[\lambda I-J\ B]`$ 的秩都为 3，但可控性矩阵的秩分别为 3、2、1。隐藏状态数分别是 1、2、3。

### 8.5 Jordan 形的快速判据

以下均使用**超对角线为 1** 的上 Jordan 块。若更换 Jordan 形式方向，第一、最后位置也随之变化。

对于每个相同特征值 $`\lambda`$：

- 从 $`B`$ 中取该特征值各 Jordan 块对应的**最后一行**，堆成矩阵；这些行必须线性无关，才能可控。
- 从 $`C`$ 中取该特征值各 Jordan 块对应的**第一列**，并成矩阵；这些列必须线性无关，才能可观。

为什么是这些位置？对上 Jordan 块，输入要从链尾进入，才能沿耦合影响整条链；输出要能看到链首，才能反映整条链的信息。

对一个二阶块

```math
J=\begin{bmatrix}\lambda&1\\0&\lambda\end{bmatrix},\quad
B=\begin{bmatrix}b_1\\b_2\end{bmatrix},\quad C=[c_1\ c_2],
```

可控当且仅当 $`b_2\ne0`$，可观当且仅当 $`c_1\ne0`$。

若同一个特征值对应两个块，则每个选取行非零仍不够，它们还必须互相独立。例如 $`A=\lambda I_2,B=(1,1)^T`$ 中，两个状态都直接接收输入，但输入只能共同推动它们，可控性矩阵秩仅为 1。

这也说明单输入可控系统对每个特征值只能有一个 Jordan 块；单输出可观系统同理。

### 8.6 预解矩阵的函数独立性不等于正常秩

课件还给出 $`(sI-A)^{-1}B`$ 的行作为函数线性无关这一等价判据。这里的系数是**常数**。

例如二重积分器有

```math
(sI-A)^{-1}B=\begin{bmatrix}1/s^2\\1/s\end{bmatrix}.
```

两个函数不存在非零常数 $`\alpha,\beta`$ 使 $`\alpha/s^2+\beta/s\equiv0`$，因此按课件的函数意义行无关。但是这个 $`2\times1`$ 有理矩阵的正常秩只有 1。两种“线性无关”的系数域不同，不可混淆。

**课件定位：** 第 6 讲第 11—39 页；第 7 讲第 22—27、30—47 页。

## 9. 几何观点与结构分解

### 9.1 可控子空间

定义

```math
\boxed{\mathcal R=\operatorname{Im}\mathcal C
=\operatorname{Im}B+A\operatorname{Im}B+\cdots+A^{n-1}\operatorname{Im}B}.
```

课件记作 $`\langle A\mid B\rangle`$。对 LTI 连续系统，$`\mathcal R`$ 同时是从零可到达的状态集合，以及能够被驱动到零的初态集合。

为什么是子空间？两个可达状态由两个输入产生，输入按同样系数相加，状态也按同样系数组合。

它还满足 $`A\mathcal R\subseteq\mathcal R`$，称为 **$`A`$ 不变子空间**。这里“不变”指作用 $`A`$ 后仍在空间里，不是向量本身不动。

更准确地说，$`\mathcal R`$ 是包含 $`\operatorname{Im}B`$ 的最小 $`A`$ 不变子空间。

```math
\boxed{\text{系统可控}\iff\mathcal R=\mathbb R^n}.
```

### 9.2 不可观测子空间

定义

```math
\boxed{\mathcal N=\ker\mathcal O
=\bigcap_{k=0}^{n-1}\ker(CA^k)}.
```

课件也用 $`\eta`$。若 $`x_0\in\mathcal N`$，则 $`Ce^{At}x_0\equiv0`$，其零输入运动永远看不见。

$`\mathcal N`$ 是包含在 $`\ker C`$ 中的最大 $`A`$ 不变子空间，且

```math
\boxed{\text{系统可观测}\iff\mathcal N=\{0\}}.
```

注意可控判据使用**像空间**，不可观判据使用**核空间**。它们的几何形式不是简单把一个字替换掉。

### 9.3 正交补的常见误解

一般有 $`\mathbb R^n=\mathcal R\oplus\mathcal R^\perp`$，但**所有不可控状态的集合不是 $`\mathcal R^\perp`$**。

例如 $`\mathcal R=\operatorname{span}\{(1,0)^T\}`$，向量 $`(1,1)^T`$ 不在可控子空间中，所以不能被驱动到零，但它也不在 $`\mathcal R^\perp`$ 中。

所有不可控状态实际上是 $`\mathbb R^n\setminus\mathcal R`$，这个集合一般不是子空间，且不含零。分解时所称“不可控部分”通常指选定补空间上的坐标或商空间动态，不能与这个集合混为一谈。

类似地，$`x\notin\mathcal N`$ 只说明它产生非零输出，不代表 $`x\in\mathcal N^\perp`$；而 $`\mathcal N^\perp`$ 也一般不是 $`A`$ 不变子空间。

### 9.4 可控性分解：怎么选基、为什么有零块

设 $`r=\dim\mathcal R<n`$。

1. 从 $`\mathcal C`$ 的原始列中选一组独立列 $`q_1,\dots,q_r`$。
2. 补充向量，使 $`T=[q_1\ \cdots\ q_n]`$ 可逆。
3. 令 $`x=Tz`$，即 $`P=T^{-1}`$。
4. 计算 $`\bar A=T^{-1}AT,\bar B=T^{-1}B,\bar C=CT`$。

得到

```math
\begin{bmatrix}\dot z_c\\\dot z_u\end{bmatrix}
=\begin{bmatrix}A_c&A_{12}\\0&A_u\end{bmatrix}
\begin{bmatrix}z_c\\z_u\end{bmatrix}
+\begin{bmatrix}B_c\\0\end{bmatrix}u,
```

```math
y=[C_c\ C_u]\begin{bmatrix}z_c\\z_u\end{bmatrix}+Du.
```

左下角为零，来自 $`A\mathcal R\subseteq\mathcal R`$；$`B`$ 下方为零，来自 $`\operatorname{Im}B\subseteq\mathcal R`$。

零初态时 $`z_u(t)\equiv0`$，故

```math
G(s)=C_c(sI-A_c)^{-1}B_c+D.
```

但是非零 $`z_u(0)`$ 可能通过 $`A_{12}`$ 或 $`C_u`$ 影响输出。因此删除不可控部分保持的是零状态输入输出关系，不是任意初态的全部行为。

### 9.5 可控分解的手算例子

取

```math
A=-I_2,\quad B=\begin{bmatrix}1\\1\end{bmatrix},\quad C=[1\ 1],\quad D=0.
```

$`\mathcal R=\operatorname{span}\{(1,1)^T\}`$。补一个 $`(1,-1)^T`$，得到

```math
T=\begin{bmatrix}1&1\\1&-1\end{bmatrix},\quad
P=\frac12\begin{bmatrix}1&1\\1&-1\end{bmatrix}.
```

于是

```math
z_1=(x_1+x_2)/2,\quad z_2=(x_1-x_2)/2,
```

```math
\bar A=-I_2,\quad\bar B=\begin{bmatrix}1\\0\end{bmatrix},\quad
\bar C=[2\ 0].
```

新坐标中，一眼就能看到 $`z_1`$ 可控且被测量，$`z_2`$ 既不能被输入改变，也不反映到输出。

对应的一维输入输出模型为 $`\dot z_1=-z_1+u,y=2z_1`$，传递函数为 $`2/(s+1)`$。

### 9.6 可观测性分解

设 $`o=\operatorname{rank}\mathcal O`$，则 $`\dim\mathcal N=n-o`$。

先求 $`\mathcal N`$ 的基，把它们放在基底矩阵 $`T`$ 的**最后** $`n-o`$ 列，再补齐前 $`o`$ 列。变换后为

```math
\begin{bmatrix}\dot z_o\\\dot z_n\end{bmatrix}
=\begin{bmatrix}A_o&0\\A_{21}&A_n\end{bmatrix}
\begin{bmatrix}z_o\\z_n\end{bmatrix}
+\begin{bmatrix}B_o\\B_n\end{bmatrix}u,
```

```math
y=[C_o\ 0]\begin{bmatrix}z_o\\z_n\end{bmatrix}+Du.
```

右上角为零，说明不可观部分不能再绕道影响可观部分；否则它就可能间接反映到输出，违背不可观定义。

另一种做法是从 $`\mathcal O`$ 中选 $`o`$ 个独立**行**作为 $`P`$ 的前 $`o`$ 行，再补齐。不要把“可控选列构造 $`T`$”和“可观选行构造 $`P`$”混在一起。

保留 $`(A_o,B_o,C_o,D)`$ 就保持相同传递函数，但这个子系统还可能不可控。

### 9.7 Kalman 四部分分解

按课件顺序选择四组坐标：

| 坐标 | 可控性 | 可观测性 |
|---|---|---|
| $`z_1`$ | 可控 | 可观 |
| $`z_2`$ | 可控 | 不可观 |
| $`z_3`$ | 不可控 | 可观 |
| $`z_4`$ | 不可控 | 不可观 |

选基的核心步骤：

```math
\mathcal X_2=\mathcal R\cap\mathcal N,
```

```math
\mathcal R=\mathcal X_1\oplus\mathcal X_2,\qquad
\mathcal N=\mathcal X_2\oplus\mathcal X_4,
```

```math
\mathbb R^n=\mathcal X_1\oplus\mathcal X_2\oplus\mathcal X_3\oplus\mathcal X_4.
```

这些补空间不唯一，也不要求都正交。$`\mathcal R,\mathcal N,\mathcal R\cap\mathcal N`$ 是 $`A`$ 不变的，但所选 $`\mathcal X_1,\mathcal X_3,\mathcal X_4`$ 不一定各自 $`A`$ 不变，所以四部分通常并非四个互不耦合的独立系统。

按这四组基排列 $`T`$，得到

```math
\bar A=\begin{bmatrix}
A_{11}&0&A_{13}&0\\
A_{21}&A_{22}&A_{23}&A_{24}\\
0&0&A_{33}&0\\
0&0&A_{43}&A_{44}
\end{bmatrix},\quad
\bar B=\begin{bmatrix}B_1\\B_2\\0\\0\end{bmatrix},\quad
\bar C=[C_1\ 0\ C_3\ 0].
```

零初态时，输入不能激励 $`z_3,z_4`$；虽然能激励 $`z_2`$，输出又看不到它。因此

```math
\boxed{G(s)=C_1(sI-A_{11})^{-1}B_1+D}.
```

设 $`r=\dim\mathcal R,o=n-\dim\mathcal N,k=\dim(\mathcal R\cap\mathcal N)`$，四块维数为

```math
\dim\mathcal X_1=r-k,\quad\dim\mathcal X_2=k,
```

```math
\dim\mathcal X_3=o-r+k,\quad\dim\mathcal X_4=n-o-k.
```

仅知道 $`r,o`$ 还不够确定最小维数；还要知道交集维数 $`k`$。

### 9.8 课件四维例题：把抽象分解算到底

第 9 讲例 2-16 为

```math
A=\begin{bmatrix}
1&0&0&0\\0&2&0&0\\-6&-2&3&0\\-3&-2&0&4
\end{bmatrix},\quad
B=\begin{bmatrix}1\\0\\3\\2\end{bmatrix},\quad C=[-4\ {-3}\ 1\ 1],\quad D=0.
```

计算得到

```math
\mathcal C=\begin{bmatrix}1&1&1&1\\0&0&0&0\\3&3&3&3\\2&5&17&65\end{bmatrix},
```

```math
\mathcal N=\operatorname{span}\left\{
\begin{bmatrix}1\\0\\3\\1\end{bmatrix},
\begin{bmatrix}0\\1\\2\\1\end{bmatrix}\right\}.
```

取

```math
t_1=\begin{bmatrix}0\\0\\0\\1\end{bmatrix},\quad
t_2=\begin{bmatrix}1\\0\\3\\1\end{bmatrix},\quad
t_3=\begin{bmatrix}3\\2\\-1\\0\end{bmatrix},\quad
t_4=\begin{bmatrix}1\\-1\\1\\0\end{bmatrix}.
```

其中 $`t_2`$ 张成 $`\mathcal R\cap\mathcal N`$。令 $`T=[t_1\ t_2\ t_3\ t_4]`$，则

```math
\bar A=T^{-1}AT=\begin{bmatrix}
4&0&-5&0\\0&1&-8&-1\\0&0&3&0\\0&0&2&2
\end{bmatrix},\quad
\bar B=\begin{bmatrix}1\\1\\0\\0\end{bmatrix},\quad
\bar C=[1\ 0\ -19\ 0].
```

**核算提示：** 课件第 13 页把 $`\bar A_{13},\bar A_{23}`$ 印为 $`5,8`$；按第 5 页原矩阵和第 12 页基底直接计算，它们应为 $`-5,-8`$。例如原矩阵 $`At_3=(3,4,-25,-13)^T`$，恰等于 $`-5t_1-8t_2+3t_3+2t_4`$。这里采用与 $`AT=T\bar A`$ 一致的结果；最小实现结论不受这两处符号影响。

因此四个部分各为一维，而最小输入输出部分只有

```math
\dot z_1=4z_1+u,\qquad y=z_1,\qquad G(s)=\frac1{s-4}.
```

初态非零时，$`z_3`$ 仍可能影响输出；最小实现只是消除了对零状态传递关系不必要的状态。

**课件定位：** 第 8 讲第 2—54 页；第 9 讲第 2—13 页。

## 10. 不可简约系统与最小实现

### 10.1 最小性的定义

给定 $`G(s)`$，若一个实现的状态维数已经不能再降低，同时保持相同传递函数，则称为最小实现，课件也称不可简约动态方程。

“最小”说的是状态数，不是输入数、输出数或参数绝对值，也不表示系统一定稳定或控制效果最好。

核心定理：

```math
\boxed{(A,B,C,D)\text{ 最小}\iff(A,B)\text{ 可控且 }(A,C)\text{ 可观测}}.
```

### 10.2 为什么不可控或不可观就能降阶

前面的可控分解、可观分解分别告诉我们：

- 不可控部分不能由零初态输入激励，可以从传递关系中删除。
- 不可观部分不会反映到输出，可以从传递关系中删除。

因此只要存在任何一种缺陷，原实现就不是最小的。

### 10.3 为什么可控且可观就不能再降阶

预解矩阵在足够大的 $`|s|`$ 下展开为

```math
(sI-A)^{-1}=\frac Is+\frac A{s^2}+\frac{A^2}{s^3}+\cdots.
```

于是

```math
G(s)=D+\frac{CB}s+\frac{CAB}{s^2}+\frac{CA^2B}{s^3}+\cdots.
```

$`CB,CAB,CA^2B,\dots`$ 称为 Markov 参数。两个实现零状态等价，当且仅当它们的 $`D`$ 相同，且所有这些参数相同。

构造块 Hankel 矩阵

```math
H_n=\begin{bmatrix}
CB&CAB&\cdots&CA^{n-1}B\\
CAB&CA^2B&\cdots&CA^nB\\
\vdots&\vdots&&\vdots\\
CA^{n-1}B&CA^nB&\cdots&CA^{2n-2}B
\end{bmatrix}=\mathcal O\mathcal C.
```

**补充数学：Sylvester 秩不等式。** 若 $`F`$ 有 $`n`$ 列、$`K`$ 有 $`n`$ 行，则

```math
\operatorname{rank}F+\operatorname{rank}K-n
\le\operatorname{rank}(FK)
\le\min(\operatorname{rank}F,\operatorname{rank}K).
```

若原系统可控且可观，$`\mathcal C`$ 满行秩、$`\mathcal O`$ 满列秩，故 $`\operatorname{rank}H_n=n`$。

假设存在 $`m<n`$ 维的相同传递函数实现，那么相同 Markov 参数组成的 $`H_n`$ 又能分解为“$`nq\times m`$ 矩阵乘 $`m\times np`$ 矩阵”，其秩最多为 $`m`$，矛盾。因此不能再降维。

这个证明把“状态数”与“输入输出数据中独立信息的数量”联系起来。

### 10.4 最小实现不是唯一矩阵，但只差坐标变换

同一传递函数的任意两个最小实现维数相同，并存在唯一的状态坐标对应 $`z=Px`$，使

```math
\bar A=PAP^{-1},\quad\bar B=PB,\quad
\bar C=CP^{-1},\quad\bar D=D.
```

存在性是课件定理的关键；给定两个具体最小实现后，满足全部关系的 $`P`$ 也由可控性唯一确定。

若为 SISO 且两个实现都可控，$`\mathcal C`$ 为可逆方阵，可由

```math
P=\bar{\mathcal C}\mathcal C^{-1}
```

求候选变换，再核查 $`PA=\bar AP,PB=\bar B,\bar CP=C`$。

多输入时，$`\mathcal C`$ 不是方阵，可用满行秩右逆

```math
\mathcal C^\dagger=\mathcal C^T(\mathcal C\mathcal C^T)^{-1},\qquad
P=\bar{\mathcal C}\mathcal C^\dagger,
```

但使用这条结论需要双方是同一传递函数的最小实现，不能给任意两套矩阵套公式后就宣布等价。

### 10.5 极零相消与隐藏模态

**补充例：**

```math
A=\operatorname{diag}(-1,-2),\quad B=(1,1)^T,\quad C=[1\ 0].
```

系统可控，因为 $`\det[B\ AB]=-1`$；但不可观，因为第二个状态完全不影响输出。

```math
G(s)=\frac1{s+1}=\frac{s+2}{(s+1)(s+2)}.
```

状态矩阵的特征值 $`-2`$ 从传递函数中消失，正对应一个隐藏的内部模态。

对 SISO 真有理函数，先约分后，最小状态维数等于分母次数。对 MIMO 系统，在本课程的极点多项式定义下，最小维数等于极点多项式的次数，称 McMillan 次数；不能只看各元素分母的最小公倍式次数。

若 $`G(s)=D`$ 是纯常数矩阵，则没有动态记忆，允许使用零维状态的实现。

### 10.6 实际求最小实现的步骤

1. 计算 $`\mathcal C`$，若不满秩，做可控分解并保留可控部分。
2. 对保留后的系统重新计算 $`\mathcal O`$。
3. 若不可观，做可观分解并保留可观部分。
4. 检查最终系统可控且可观，并核对传递函数。

直接做四部分分解也可以，但对初学者，先做两次较小分解更容易检查。删除状态前先换坐标；通常不能凭原矩阵某一行的外观就把该状态删掉。

**课件定位：** 第 9 讲第 14—25 页。

## 11. 标准形：把模型整理成便于计算的样子

### 11.1 为什么同一系统还要换一种写法

标准形把某种结构变得明显，方便检查可控、可观和进行后续设计。标准形有多种约定，使用时应先看矩阵布局，再看“第一”“第二”的名称。

以下令

```math
\Delta(s)=s^n+a_1s^{n-1}+\cdots+a_n,
```

并继续使用 $`z=Px`$。

### 11.2 第二可控标准形：积分链结构

课件的第二可控标准形就是第 5.5 节使用的

```math
A_c=\begin{bmatrix}
0&1&0&\cdots&0\\
0&0&1&\cdots&0\\
\vdots&&&\ddots&\vdots\\
0&0&0&\cdots&1\\
-a_n&-a_{n-1}&-a_{n-2}&\cdots&-a_1
\end{bmatrix},\quad B_c=e_n.
```

这对 $`(A_c,B_c)`$ 一定可控，但配上任意 $`C_c`$ 后，不保证可观。因此“可控标准形”不等于“最小实现”。

#### 从已有可控 SISO 系统求变换

1. 计算 $`\mathcal C=[B\ AB\ \cdots\ A^{n-1}B]`$。
2. 取 $`h`$ 为 $`\mathcal C^{-1}`$ 的最后一行。
3. 构造

```math
\boxed{P=\begin{bmatrix}h\\hA\\\vdots\\hA^{n-1}\end{bmatrix}}.
```

4. 用 $`\bar A=PAP^{-1},\bar B=PB,\bar C=CP^{-1}`$ 计算变换后系统。

为什么成立？因为

```math
hB=hAB=\cdots=hA^{n-2}B=0,\qquad hA^{n-1}B=1,
```

所以 $`PB=e_n`$；前 $`n-1`$ 行的移位关系来自 $`hA^kA=hA^{k+1}`$，最后一行来自 Cayley–Hamilton 定理。

**也可以先构造基底矩阵：**

```math
q_n=B,\quad q_{n-1}=AB+a_1B,\quad
q_{n-2}=A^2B+a_1AB+a_2B,
```

依此类推，取 $`T=[q_1\ \cdots\ q_n]`$，然后 $`P=T^{-1}`$。两种方法得到同一个目标标准形。

### 11.3 二维完整例题：从对角模型变成积分链

设

```math
A=\begin{bmatrix}-1&0\\0&-2\end{bmatrix},\quad
B=\begin{bmatrix}1\\1\end{bmatrix},\quad C=[1\ 1],\quad D=0.
```

第一步：

```math
\mathcal C=\begin{bmatrix}1&-1\\1&-2\end{bmatrix},\qquad
\mathcal C^{-1}=\begin{bmatrix}2&-1\\1&-1\end{bmatrix}.
```

第二步：$`h=[1\ {-1}]`$，所以

```math
P=\begin{bmatrix}1&-1\\-1&2\end{bmatrix},\quad
P^{-1}=\begin{bmatrix}2&1\\1&1\end{bmatrix}.
```

第三步：

```math
\bar A=\begin{bmatrix}0&1\\-2&-3\end{bmatrix},\quad
\bar B=\begin{bmatrix}0\\1\end{bmatrix},\quad
\bar C=[3\ 2].
```

第四步：验证

```math
G(s)=\frac1{s+1}+\frac1{s+2}
=\frac{2s+3}{s^2+3s+2}.
```

原模型和新模型的矩阵看起来不同，但它们只是同一系统的两种状态坐标。

### 11.4 第一可控标准形：以可控性矩阵作基底

对 SISO 可控系统，直接令 $`T=\mathcal C`$，即 $`z=\mathcal C^{-1}x`$，可得

```math
A_{c1}=\begin{bmatrix}
0&0&\cdots&0&-a_n\\
1&0&\cdots&0&-a_{n-1}\\
0&1&\cdots&0&-a_{n-2}\\
\vdots&&\ddots&&\vdots\\
0&0&\cdots&1&-a_1
\end{bmatrix},\quad B_{c1}=e_1.
```

理由是前 $`n-1`$ 个基向量经 $`A`$ 作用后，恰好移动到下一个基向量；最后一个由特征多项式关系表示。

$`C_{c1}=C\mathcal C`$，不要把第二可控标准形中“分子系数直接排入 $`C`$”的规则原样套到这里。

### 11.5 第二可观标准形及变换

它是第二可控标准形的转置对偶：

```math
A_o=A_c^T,\qquad C_o=e_n^T.
```

若严格真有理分子按升幂排列为 $`b_0+b_1s+\cdots+b_{n-1}s^{n-1}`$，可取

```math
B_o=[b_0\ b_1\ \cdots\ b_{n-1}]^T.
```

例如

```math
G(s)=\frac{2s+3}{s^2+3s+2}
```

的一个可观标准形实现是

```math
A_o=\begin{bmatrix}0&-2\\1&-3\end{bmatrix},\quad
B_o=\begin{bmatrix}3\\2\end{bmatrix},\quad C_o=[0\ 1],\quad D=0.
```

直接计算可得 $`C_o(sI-A_o)^{-1}=[1\ s]/(s^2+3s+2)`$。

对已有可观 SISO 模型：

1. 计算 $`\mathcal O`$ 并求逆。
2. 取 $`h`$ 为 $`\mathcal O^{-1}`$ 的最后一列。
3. 构造 $`T=[h\ Ah\ \cdots\ A^{n-1}h]`$。
4. 令 $`P=T^{-1}`$ 并变换。

这里选的是“最后一列”，构造的是 $`T=P^{-1}`$；与可控标准形的“最后一行构造 $`P`$”正好对偶。

### 11.6 多输入：Luenberger 标准形的入门理解

SISO 可控系统只有一条长度为 $`n`$ 的链。多输入系统可以有多条链：不同输入带来新的独立方向，随后由 $`A`$ 继续传播。

设链长为 $`\mu_1,\dots,\mu_r`$，则

```math
\sum_{i=1}^r\mu_i=n.
```

冗余输入可对应零长度链；不要在 $`\operatorname{rank}B<p`$ 时强行要求每个输入都有正长度链。

Luenberger 第二可控标准形的特点是：每条链内部具有

```math
\dot z_{i,1}=z_{i,2},\quad\dots,\quad
\dot z_{i,\mu_i-1}=z_{i,\mu_i}
```

这样的移位结构；每条链的最后一行可以包含各链状态与输入的组合。不同链之间仍可能耦合，单靠状态变换不能把任意可控系统都变成完全独立的纯积分链。

课件的块形式中：$`A_{ii}`$ 除最后一行外为移位结构；$`A_{ij}`$（$`i\ne j`$）除最后一行外为零；$`B_i`$ 也只在链末行出现输入，经过适当排列具有阶梯式主元结构。$`C`$ 一般没有特殊形式。

**用秩增长理解链长：** 令

```math
r_k=\operatorname{rank}[B\ AB\ \cdots\ A^{k-1}B],\qquad r_0=0,
```

则增量 $`r_k-r_{k-1}`$ 等于长度至少为 $`k`$ 的链数。最大链长就是前面定义的可控性指数 $`\nu_c`$。

**补充例：**

```math
A=\begin{bmatrix}0&1&0\\0&0&0\\0&0&0\end{bmatrix},\quad
B=\begin{bmatrix}0&0\\1&0\\0&1\end{bmatrix}.
```

两个输入分别控制二重积分链 $`(x_1,x_2)`$ 和单积分链 $`x_3`$。有 $`r_1=2,r_2=3`$，增量为 $`2,1`$，因此链长为 $`2,1`$，可控性指数为 2。

**课件定位：** 第 9 讲第 26—49 页。课件末尾主要给出了多变量标准形结构；本节以秩增长解释其含义，没有把后续完整构造算法当作本次九讲已讲完的内容。

## 12. 练习、答案与复习清单

以下题目是配套自测题，不冒充教材作业题。建议先遮住答案计算，再逐步核对。

### 12.1 基础练习

**题 1：线性与时不变。** 判断 $`y=2u+1`$、$`y=tu`$、$`y(t)=u(t-2)`$ 的线性、因果性和时不变性。

**题 2：像与核。** 对 $`M=\begin{bmatrix}1&1\\2&2\end{bmatrix}`$，求秩、像空间、核空间和像空间的正交补。

**题 3：建立模型。** 对 $`\ddot y+4\dot y+3y=2u`$，取 $`x=(y,\dot y)^T`$，求 $`A,B,C,D`$ 和 $`G(s)`$。

**题 4：矩阵指数。** 求 $`A=\begin{bmatrix}-2&1\\0&-2\end{bmatrix}`$ 的 $`e^{At}`$，并求 $`x(0)=(0,1)^T`$ 时的零输入状态。

**题 5：可控性含参数。** $`A=\begin{bmatrix}0&1\\0&0\end{bmatrix},B=(1,b)^T`$，何时可控？

**题 6：可观性含参数。** 同样的 $`A`$，令 $`C=[c\ 1]`$，何时可观？

### 12.2 综合练习

**题 7：PBH 与隐藏模态。** 设 $`A=\operatorname{diag}(-1,2),B=(1,0)^T,C=[1\ 1]`$。判断可控与可观，求 $`G(s)`$，并说明非零初态下为什么可能出现增长的输出。

**题 8：Jordan 重根。** 对 $`A=\lambda I_2`$，分别取 $`B_1=(1,1)^T`$ 与 $`B_2=I_2`$，判断可控性。说明“每个状态都接收输入”为什么不够。

**题 9：最小实现。** 给定 $`G(s)=(s+2)/(s^2+3s+2)`$，先用第二可控标准形构造二维实现，再说明它能否降阶。

**题 10：一次完整坐标变换。** 对第 11.3 节系统，独立计算 $`PA,\bar AP,PB,\bar CP`$，确认四者对应关系。再求第一可控标准形。

**题 11：时变可控性。** 在 $`[0,1]`$ 上，$`A=0,B(t)=(1,t)^T`$。求可控 Gram 矩阵，判断可控性。它与每个时刻 $`B(t)`$ 秩为 1 是否矛盾？

**题 12：多变量极点多项式。** 求

```math
G(s)=\begin{bmatrix}(s+1)^{-1}&0\\0&(s+1)^{-1}\end{bmatrix}
```

的正常秩、极点多项式、零点多项式与最小实现维数。

**题 13：四部分的维数。** 一个五维系统满足 $`\operatorname{rank}\mathcal C=3`$、$`\operatorname{rank}\mathcal O=4`$、$`\dim(\mathcal R\cap\mathcal N)=1`$，求四部分维数与最小维数。

**题 14：构造控制与恢复状态。** 对二重积分器：用第 6.6 节的 $`u(t)=12t-6`$ 检查端点；另在零输入下观测到 $`y(t)=1-2t`$，求初态。

**题 15：标准形不等于最小。** 取 $`A=\begin{bmatrix}0&1\\-2&-3\end{bmatrix},B=(0,1)^T,C=[0\ 0]`$。系统可控吗？可观吗？最小实现维数是多少？

**题 16：时变状态转移。** 取 $`A(t)=\operatorname{diag}(2t,1)`$，求 $`\Phi(t,t_0)`$，并验证组合性质。

### 12.3 答案与关键步骤

**题 1。**

- $`2u+1`$：非线性、因果、时不变。
- $`tu`$：线性、因果、时变。
- $`u(t-2)`$：线性、因果、时不变。

**题 2。** 秩为 1，$`\operatorname{Im}M=\operatorname{span}\{(1,2)^T\}`$，$`\ker M=\operatorname{span}\{(1,-1)^T\}`$，$`(\operatorname{Im}M)^\perp=\operatorname{span}\{(-2,1)^T\}`$。不要把核与像的正交补直接等同；此处 $`M`$ 不对称。

**题 3。**

```math
A=\begin{bmatrix}0&1\\-3&-4\end{bmatrix},\quad B=\begin{bmatrix}0\\2\end{bmatrix},\quad C=[1\ 0],\quad D=0,
```

```math
G(s)=\frac2{s^2+4s+3}.
```

**题 4。** $`e^{At}=e^{-2t}\begin{bmatrix}1&t\\0&1\end{bmatrix}`$，故 $`x(t)=e^{-2t}(t,1)^T`$。

**题 5。** $`AB=(b,0)^T`$，$`\det[B\ AB]=-b^2`$，所以 $`b\ne0`$ 时可控。

**题 6。** $`CA=[0\ c]`$，$`\det\mathcal O=c^2`$，所以 $`c\ne0`$ 时可观。位置被测量后，速度可从其演化推断；只测速度则不能恢复初始位置。

**题 7。** 不可控，因为第二个状态没有输入通道；可观，因为

```math
\mathcal O=\begin{bmatrix}1&1\\-1&2\end{bmatrix},\quad\det\mathcal O=3.
```

$`G(s)=1/(s+1)`$，但零输入输出为 $`e^{-t}x_1(0)+e^{2t}x_2(0)`$。传递函数遗漏不可控但可观的内部模态 $`2`$，不代表该模态在非零初态下不存在。

**题 8。** $`B_1`$ 时所有 $`A^kB_1=\lambda^kB_1`$，只能张成一维，不可控；$`B_2=I_2`$ 本身满秩，可控。区别在于是否有足够独立的输入方向。

**题 9。** 二维实现取

```math
A=\begin{bmatrix}0&1\\-2&-3\end{bmatrix},\quad B=(0,1)^T,\quad C=[2\ 1].
```

$`\mathcal C`$ 满秩，但

```math
\mathcal O=\begin{bmatrix}2&1\\-2&-1\end{bmatrix}
```

秩为 1。约分得到 $`G(s)=1/(s+1)`$，最小实现为 $`\dot z=-z+u,y=z`$，维数为 1。

**题 10。** 第二可控标准形已在第 11.3 节给出。第一可控标准形取 $`T=\mathcal C`$，得到

```math
A_{c1}=\begin{bmatrix}0&-2\\1&-3\end{bmatrix},\quad B_{c1}=(1,0)^T,\quad C_{c1}=[2\ {-3}].
```

注意 $`C_{c1}`$ 与第二可控标准形的 $`[3\ 2]`$ 不同。

**题 11。** $`\Phi=I`$，

```math
W_c=\int_0^1\begin{bmatrix}1&t\\t&t^2\end{bmatrix}dt
=\begin{bmatrix}1&1/2\\1/2&1/3\end{bmatrix},\quad\det W_c=1/12>0.
```

所以区间可控。逐时刻只有一个方向，但这个方向随时间改变，积累后覆盖二维空间。

**题 12。** 正常秩为 2。二阶子式为 $`1/(s+1)^2`$，所以极点多项式为 $`(s+1)^2`$，零点多项式为 1，没有有限零点，最小维数为 2。可取 $`A=-I_2,B=C=I_2,D=0`$。

**题 13。** 依次为 $`\dim\mathcal X_1=2,\dim\mathcal X_2=1,\dim\mathcal X_3=2,\dim\mathcal X_4=0`$，最小维数为 2。总维数仍为 5。

**题 14。** $`x_2=6t^2-6t,x_1=1+2t^3-3t^2`$，在 $`t=1`$ 均为零。另一个观测问题中，$`x(0)=(1,-2)^T`$。

**题 15。** 可控但完全不可观，$`G(s)=0`$。零状态输入输出关系的最小实现没有动态状态，即维数为 0。

**题 16。**

```math
\Phi(t,t_0)=\operatorname{diag}(e^{t^2-t_0^2},e^{t-t_0}).
```

组合时，中间时刻的指数相消，例如 $`e^{t_2^2-t_1^2}e^{t_1^2-t_0^2}=e^{t_2^2-t_0^2}`$。

### 12.4 做题时的选择顺序

| 题目要求 | 首先采用的方法 | 必须检查 |
|---|---|---|
| 由微分方程建模 | 选独立状态，逐行写一阶方程 | 输入导数、变量维数 |
| 求 $`e^{At}`$ | 低阶预解矩阵、幂零性或对角/Jordan 分解 | $`e^{A0}=I`$，导数关系 |
| 求状态响应 | 状态转移公式 | 初态项与输入项分开 |
| 求 $`G(s)`$ | 解 $`(sI-A)X=B`$ 后算 $`CX+D`$ | 传递函数对应零初态 |
| LTI 可控/可观 | $`\mathcal C,\mathcal O`$ 秩判据 | 幂的顺序、行列方向 |
| 已知特征值或 Jordan 结构 | PBH 或 Jordan 快速判据 | 重根不能一概而论 |
| 一般时变可控/可观 | 转移矩阵与 Gram 判据 | 不可直接冻结系数 |
| 结构分解 | 求像、核及其基底 | 列基底是 $`T=P^{-1}`$ |
| 最小实现 | 保留可控且可观部分 | 降阶后再核对 $`G`$ |
| 标准形 | 先确认可控/可观，再构造变换 | 先认布局，后认名称 |

### 12.5 必须能默写并解释的核心公式

```math
x(t)=\Phi(t,t_0)x_0+\int_{t_0}^t\Phi(t,\tau)B(\tau)u(\tau)d\tau,
```

```math
\Phi(t,t_0)=e^{A(t-t_0)}\quad\text{（LTI）},
```

```math
G(s)=C(sI-A)^{-1}B+D,
```

```math
z=Px\Rightarrow(\bar A,\bar B,\bar C,\bar D)
=(PAP^{-1},PB,CP^{-1},D),
```

```math
\mathcal C=[B\ AB\ \cdots\ A^{n-1}B],\qquad
\mathcal O=\begin{bmatrix}C\\CA\\\vdots\\CA^{n-1}\end{bmatrix},
```

```math
\mathcal R=\operatorname{Im}\mathcal C,\qquad
\mathcal N=\ker\mathcal O,
```

```math
\operatorname{rank}[\lambda I-A\ B]=n,\qquad
\operatorname{rank}\begin{bmatrix}\lambda I-A\\C\end{bmatrix}=n,
```

```math
\text{最小实现}\iff\text{可控且可观}.
```

会默写还不够。你应该能回答：为什么检查到 $`n-1`$ 次幂就够？为什么可控看行满秩，可观看列满秩？为什么相同传递函数不能保证相同内部行为？

### 12.6 十个容易失分的判断

1. $`B`$ 有零行，不一定不可控；可能通过 $`A`$ 间接作用。
2. $`C`$ 有零列，不一定不可观；可能通过动态耦合间接测到。
3. $`B`$ 每行非零，也不一定可控；方向可能相关。
4. 渐近趋于零不等于有限时间可控到零。
5. 可控不等于稳定，可观也不等于稳定。
6. LTI 的秩判据不能直接套到一般时变系统。
7. $`e^{At}`$ 不是逐元素指数，且它总可逆。
8. 一般的 $`\mathcal R^\perp`$、$`\mathcal N^\perp`$ 不必是 $`A`$ 不变子空间。
9. 删除隐藏状态保持零状态输入输出关系，不一定保持任意初态响应。
10. 同传递函数的最小实现必代数等价；非最小实现没有这个普遍保证。

### 13.3 学完后的检查标准

完成这些内容后，你应当能够独立完成一条完整分析链：从一个二阶微分方程建立状态模型，计算响应与传递函数，判断可控和可观，解释隐藏模态，选基进行降阶，再写出一个可控或可观标准形。遇到公式时，也能说明它适用于常系数还是时变系统、是否要求零初态、是否只是充分条件。
